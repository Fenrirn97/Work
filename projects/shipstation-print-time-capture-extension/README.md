# ShipStation Print Time Capture Extension

Latest retained package: **v0.4.9**

Chrome/Edge extension used to capture ShipStation printed-label state/date-time and shipment identifiers for comparison with the desktop/local ShipStation tools.

The v0.4.9 ZIP is retained in the project Library. Its raw bytes are not currently exposed to the GitHub connector, so this repository entry records the project/version without pretending the extension source has been uploaded.
