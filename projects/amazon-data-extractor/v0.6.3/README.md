# Amazon Data Extractor v0.6.3

Local Windows Python/Flask tool for Amazon listing extraction and offline catalog comparison.

## Included workflow
- ASIN workbook input and deduplication
- Bright Data live extraction
- Amazon extraction workbook output
- Offline comparison against Category Listings reports
- Optional All Listings SKU fallback
- Bullet classifications: Exact Match, Formatting Only, Text Changed, Missing Live, Missing Catalog, Bullet Moved
- ASIN issue handling and comparison reports

## Security
The local `brightdata_api_key.txt` credential file is intentionally excluded from GitHub. The project .gitignore excludes that file.
