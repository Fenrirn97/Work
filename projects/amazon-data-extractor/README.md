# Amazon Data Extractor

Current Library package: **v0.6.3**

This project is a Python/Flask Amazon listing comparison tool. It includes live extraction, catalog/offline comparison, ASIN handling, bullet/image checks, and Excel reporting.

## GitHub archive status

The project is cataloged here. A GitHub-safe source archive was prepared with the local Bright Data key file excluded, but the current GitHub connector cannot directly ingest that generated container artifact.

## Security

Do **not** commit `brightdata_api_key.txt` or any live marketplace/API credential.
