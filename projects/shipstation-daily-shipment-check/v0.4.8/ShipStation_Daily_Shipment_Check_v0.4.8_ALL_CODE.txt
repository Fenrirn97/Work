- From / Through date pickers; both boundary dates included.
- ISO date-picker input and legacy MM/DD/YYYY input supported.
- V1 and V2 extraction filter the full range in one report run.
- Same-date selection and legacy single-date requests remain supported.

- Date range included in Excel filename, worksheet name, summary, and Read Me.

  supplying a printed status or time.

===== BEGIN FILE: README.txt =====
SHIPSTATION DAILY SHIPMENT CHECK — VERSION 0.4.8 (AUTOMATIC API FILE + DATE RANGE)

QUICK START
1. Close any older copy of the program.
2. Extract this ZIP into a new folder. Put your existing API TXT file beside
   START.cmd and name it API key.txt, then double-click START.cmd.
3. Choose From date and Through date. Both dates are included.
4. Click Open ShipStation Shipped Page. In your normal ShipStation browser,
   apply the SAME Ship Date range to the Shipments view.
5. Export Shipments > Current View for the status CSV. For displayed print time,
   clear the previous capture and use the included extension on EACH page.
6. Check that the API area says Ready, then choose your optional status CSV.
   If your API file is elsewhere, open Use a different location or choose a file.
7. Click Create Compared Excel Report. Carrier checks are optional.

AUTOMATIC API KEY FILE
The default location is the folder containing START.cmd and app.py. The program
looks only in that folder for API key.txt or API key (without an extension).
Capitalization does not matter. It does not search the entire PC or subfolders.

To use a different location:
1. Open Use a different location or choose a file in the API area.
2. Paste the full file path, for example C:\Shipping\API key.txt, or its folder,
   for example C:\Shipping. A folder must contain API key.txt or API key.
3. Click Use this location. The location is remembered on this Windows account.
   Clicking Create Compared Excel Report also applies a newly typed path.

Use program folder resets the remembered location. The optional file chooser
still works and overrides automatic loading for that report only; it does not
change the remembered location. Empty or invalid chosen files produce an error
instead of silently switching to another file.

When both API key and API key.txt exist, enter the full path to the one you want.
A missing or invalid saved location must be corrected or reset explicitly.
The program reads the current file again for each report, so replacing the key
in the file does not require restarting the program. The Ready status checks
the file format; ShipStation validates the credentials when a report runs.

The file's credential format is unchanged. For V1, use API_KEY and API_SECRET
on separate lines. For V2, use V2_API_KEY alone. See the supplied placeholder
template. The template is deliberately not named API key.txt and is never
automatically selected. Files must be at most 16 KB. Automatic local reading
accepts UTF-8 and BOM-marked UTF-16 text from Notepad.

Only the selected path is saved, at %LOCALAPPDATA%\SSC\api_key_location.json.
The program does not copy the key into settings, Excel reports, or its source.
An automatically loaded key stays on the local server and is sent to ShipStation
for API authentication; it is not returned to the browser's status display.

WHAT THE RANGE MEANS
The range filters the Ship Date recorded by ShipStation. It does not filter by
Order Date, label creation date, or the displayed print time.

From 09/29/2026 through 10/02/2026 includes September 29 and October 2 in full.
For one day, select the same date in both fields. Reversed or invalid dates are
rejected before any API extraction starts.

The program requests the range in one run. It does not run the entire report
again for each day. V1 shipment and fulfillment queries use the requested range;
order history is read once where the existing reconciliation requires it. V2
completed labels are read once and filtered by Ship Date. Larger ranges can take
longer, particularly if there are many order records or carrier checks.

An order with several packages across dates appears once in the item report.
Ship Date(s) lists its dates within the selected range. Tracking Records keeps
individual shipment/package records. Order item quantity is not proof that every
unit shipped within the range.

OUTPUT
A range report is named, for example:
  Shipped_2026-09-29_to_2026-10-02_Checked.xlsx
A single-day report keeps the previous filename style:
  Shipped_2026-10-05_Checked.xlsx

The selected dates appear in the main sheet name, the on-screen summary, and
Read Me. The workbook contains:
- Main order/item report for the range
- Tracking Records
- Print Status CSV (supplied source records)
- ShipStation Print Capture (supplied source observations)
- Carrier Tracking
- Read Me

The workbook downloads through your browser to its configured download folder,
usually Windows Downloads. Press Ctrl+J in the browser to find the download.

The supporting CSV/capture sheets preserve the supplied source data. They can
contain observations outside the range if you supplied a broader input. Only
matching extracted shipments receive those print observations in the main report.

PRINTED STATUS AND DISPLAYED TIME
This release is based on v0.4.7 and retains the normal-browser workflow and its
bundled v0.4.9 extension. It does not use the experimental v0.5 browser reader.

The API/CSV workflow remains available. ShipStation's status CSV does not provide
the displayed print time in the exports inspected for this project. The extension
reads Shipments > Label Printed from the signed-in browser page, preserving the
raw cell text and the displayed timestamp separately from capture time.

The From / Through controls set the API extraction range. They do not change
ShipStation's browser filters or automatically move the extension through pages.
Apply the same Ship Date range in ShipStation and capture every page you need.
Do not assume that capturing one page covers the entire date range.

Print time is preserved as displayed. No account timezone conversion or claim
about first print versus latest reprint is made. ShipStation's Printed status is
a document record, not independent proof of physical paper output.

EXTENSION SETUP (ONCE)
If the extension is already working, keep using it.
Otherwise:
1. Click Open Extension Folder in the program.
2. In Edge open edge://extensions, or in Chrome open chrome://extensions.
3. Enable Developer mode, click Load unpacked, and choose the included
   ShipStation_Print_Time_Extension folder.
4. Pin its icon to the browser toolbar if useful.

FOR EACH RANGE
1. Keep the local program running on its default port 8787.
2. Click Clear Capture before a new capture session.
3. In ShipStation, apply the same Ship Date range.
4. Show Shipment #, Order #, Tracking #, and Label Printed in the grid.
5. Click the extension and Capture this Shipments page.
6. Repeat for each page in the filtered list.
7. Return to the program and Refresh Capture Status, then create the report.

MATCHING
CSV print observations require an exact unique tracking match. An order number
alone cannot transfer another package's print status. Browser observations also
use exact tracking; if API tracking is missing, a single matching shipment
identifier can be used. Missing tracking remains flagged.
Multiple-package item rows are marked for review instead of inheriting one
package's print time. See Tracking Records for the individual shipments.

INSTALLATION
Windows 10/11, Python 3.11 or newer, and an installed Edge/Chrome browser are
required for the respective browser operations. Internet is needed for first
setup and live ShipStation/carrier access.

START.cmd retains v0.4.6's short per-user runtime at %LOCALAPPDATA%\SSC\v043 to
avoid the earlier Windows long-path installation issue. This version does not
require a new runtime. If browser support fails, close the app and run
REPAIR_BROWSER_TRACKING.cmd while online.

Exit Program stops the local server. Credentials are read from your chosen TXT
file and used in memory. Reports contain shipment/customer information; no API
secret is written into the workbook.

VALIDATION
See TESTING.txt for automated checks and their limits. No live account records
or shipping settings were changed while building this release.

SHIPSTATION PRINT TIME CAPTURE EXTENSION — v0.4.9
=================================================

THIS IS THE PROVEN v0.4.9 BROWSER EXTENSION BUNDLED WITH
SHIPSTATION DAILY SHIPMENT CHECK v0.4.6.

The extension logic is the same v0.4.9 reader verified against the live ShipStation diagnostic.

WHAT v0.4.9 FIXES
-----------------
The v0.4.7 diagnostic proved that ShipStation can render the Label Printed cell as
multiple nested text fragments. Trying to choose one "best" DOM element caused the
actual print value to disappear during organization.

v0.4.9 now:
- captures the row first, before normalizing it;
- finds Packing Slip Printed and Marketplace Notified as the neighboring headers;
- uses those neighbors to define the exact Label Printed column boundaries;
- combines the status/date/time fragments inside that one column;
- accepts ShipStation's bullet separator, for example:
      Printed09/17/2026•13:52
- keeps the horizontal-scroll reader only as a fallback;
- keeps detailed TXT diagnostics, including the fragments found for each row.

This prevents a Packing Slip Printed time from being mistaken for the Label Printed
time when both columns contain print information.

BUTTONS
-------
1. Capture this Shipments page
   Reads Shipment #, Order #, Tracking # and Label Printed and sends the rows to the
   local ShipStation checker at 127.0.0.1:8787.

2. Download Diagnostic TXT
   Does not require the local checker to be running. It downloads a plain TXT file
   showing what the extension detected and how each Label Printed value was rebuilt.

INSTALL / UPDATE
----------------
1. Extract this ZIP to a normal folder.
2. Open edge://extensions or chrome://extensions.
3. Turn on Developer mode.
4. Remove/reload the previous ShipStation Print Time Capture extension.
5. Click Load unpacked.
6. Select the extracted ShipStation_Print_Time_Capture_Extension_v0.4.9 folder.

TEST FIRST
----------
1. Open ShipStation -> Shipments -> Shipped / Recent.
2. Keep Shipment #, Order #, Tracking #, Packing Slip Printed, Label Printed, and
   Marketplace Notified enabled under Columns when possible.
3. Click the extension icon.
4. Click Download Diagnostic TXT first.
5. Confirm rows show short values like:
      Raw Label Printed: Printed 09/17/2026•13:52
      Parsed status: Printed
      Parsed displayed print time: 09/17/2026 13:52
6. Only after that use Capture this Shipments page.

SECURITY
--------
The diagnostic does not include your ShipStation password or API key. The capture
sends only shipment identifiers and Label Printed text to the local checker.

const captureButton = document.getElementById("capture");

const statusBox = document.getElementById("status");

async function captureShipmentsGrid() {
  const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
  const clean = (value) => String(value || "").replace(/\s+/g, " ").trim();
  const norm = (value) => clean(value).toLowerCase();
  const visible = (el) => {
    if (!el || !el.getBoundingClientRect) return false;
    const style = getComputedStyle(el);
    const box = el.getBoundingClientRect();
    return style.display !== "none" && style.visibility !== "hidden" && Number(style.opacity || 1) !== 0 && box.width > 0 && box.height > 0;
  };
  const allText = (el) => {
    if (!el) return "";
    const values = [
      el.innerText,
      el.textContent,
      el.getAttribute && el.getAttribute("aria-label"),
      el.getAttribute && el.getAttribute("title"),
      el.getAttribute && el.getAttribute("data-tooltip-content"),
      el.getAttribute && el.getAttribute("data-original-title")
    ];
    if (el.querySelectorAll) {
      for (const child of el.querySelectorAll("[aria-label],[title],[data-tooltip-content],[data-original-title],time")) {
        values.push(
          child.innerText,
          child.textContent,
          child.getAttribute("aria-label"),
          child.getAttribute("title"),
          child.getAttribute("data-tooltip-content"),
          child.getAttribute("data-original-title"),
          child.getAttribute("datetime")
        );
      }
    }
    return [...new Set(values.map(clean).filter(Boolean))].join(" | ");
  };

  const wantedHeaders = {
    shipment: ["shipment #", "shipment number"],
    order: ["order #", "order number"],
    tracking: ["tracking #", "tracking number"],
    label: ["label printed", "label print"]
  };

  const diagnostic = {
    pageUrl: location.href,
    pageTitle: document.title,
    capturedAt: new Date().toISOString(),
    viewport: {
      width: window.innerWidth,
      height: window.innerHeight,
      devicePixelRatio: window.devicePixelRatio || 1
    },
    semanticHeaderTexts: [],
    headerMap: {},
    headerRects: {},
    horizontalScroller: null,
    verticalScroller: null
  };

  function smallestExactTextElement(names) {
    const matches = [];
    for (const el of document.querySelectorAll("body *")) {
      if (!visible(el)) continue;
      const text = norm(el.innerText || el.textContent || "");
      if (!names.includes(text)) continue;
      const box = el.getBoundingClientRect();
      if (box.bottom < 0 || box.top > window.innerHeight) continue;
      matches.push({el, box, area: box.width * box.height});
    }
    matches.sort((a, b) => a.area - b.area || a.box.top - b.box.top);
    return matches.length ? matches[0].el : null;
  }

  const semanticHeaders = [...document.querySelectorAll('[role="columnheader"], thead th')].filter(visible);
  diagnostic.semanticHeaderTexts = semanticHeaders.slice(0, 60).map((el) => clean(allText(el)));
  const headerMap = {};
  if (semanticHeaders.length) {
    for (const [key, names] of Object.entries(wantedHeaders)) {
      headerMap[key] = semanticHeaders.find((el) => {
        const text = norm(allText(el));
        return names.some((name) => text === name || text.includes(name));
      }) || null;
    }
  }
  for (const [key, names] of Object.entries(wantedHeaders)) {
    if (!headerMap[key]) headerMap[key] = smallestExactTextElement(names);
  }

  // ShipStation's Label Printed cell sits between these two columns. Finding the
  // neighbors lets us define the real cell boundaries instead of guessing from
  // the widely separated Tracking # column.
  const neighborHeaders = {
    packing: smallestExactTextElement(["packing slip printed"]),
    marketplace: smallestExactTextElement(["marketplace notified"])
  };

  diagnostic.headerMap = Object.fromEntries(
    Object.entries(headerMap).map(([key, el]) => [key, el ? clean(allText(el)) : "NOT FOUND"])
  );
  for (const [key, el] of Object.entries(headerMap)) {
    if (!el) continue;
    const r = el.getBoundingClientRect();
    diagnostic.headerRects[key] = {
      left: Math.round(r.left), top: Math.round(r.top), right: Math.round(r.right), bottom: Math.round(r.bottom),
      width: Math.round(r.width), height: Math.round(r.height)
    };
  }

  const missingHeaders = Object.entries(headerMap).filter(([, el]) => !el).map(([key]) => key);
  if (missingHeaders.length) {
    return {
      ok: false,
      reason: `Could not find these ShipStation columns: ${missingHeaders.join(", ")}. Use Columns in ShipStation to enable Shipment #, Order #, Tracking # and Label Printed.`,
      diagnostic
    };
  }

  function rectsAndCenters() {
    const rects = {};
    for (const [key, el] of Object.entries(headerMap)) rects[key] = el.getBoundingClientRect();
    return {
      rects,
      centers: Object.fromEntries(Object.entries(rects).map(([key, r]) => [key, r.left + r.width / 2])),
      headerBottom: Math.max(...Object.values(rects).map((r) => r.bottom))
    };
  }

  let geometry = rectsAndCenters();
  const ordered = Object.entries(geometry.centers).sort((a, b) => a[1] - b[1]);
  const bounds = {};
  for (let i = 0; i < ordered.length; i += 1) {
    const [key, x] = ordered[i];
    const prev = i > 0 ? ordered[i - 1][1] : x - Math.max(90, (ordered[i + 1]?.[1] || x + 180) - x);
    const next = i < ordered.length - 1 ? ordered[i + 1][1] : x + Math.max(120, x - (ordered[i - 1]?.[1] || x - 180));
    bounds[key] = {left: (prev + x) / 2, right: (x + next) / 2};
  }

  function centerOf(el) {
    if (!el) return null;
    const r = el.getBoundingClientRect();
    return r.left + r.width / 2;
  }

  function currentExactLabelBounds() {
    const labelCenter = centerOf(headerMap.label);
    const packingCenter = centerOf(neighborHeaders.packing);
    const marketplaceCenter = centerOf(neighborHeaders.marketplace);
    const fallback = bounds.label;
    return {
      left: Number.isFinite(packingCenter) ? (packingCenter + labelCenter) / 2 : fallback.left,
      right: Number.isFinite(marketplaceCenter) ? (labelCenter + marketplaceCenter) / 2 : fallback.right,
      center: labelCenter
    };
  }

  diagnostic.neighborHeaders = {
    packing: neighborHeaders.packing ? clean(allText(neighborHeaders.packing)) : "NOT FOUND",
    marketplace: neighborHeaders.marketplace ? clean(allText(neighborHeaders.marketplace)) : "NOT FOUND"
  };

  function textAtPoint(x, y, kind) {
    if (!Number.isFinite(x) || !Number.isFinite(y) || x < 0 || y < 0 || x > window.innerWidth || y > window.innerHeight) return "";
    const elements = document.elementsFromPoint(x, y).filter(visible);
    const candidates = [];
    for (const el of elements) {
      const box = el.getBoundingClientRect();
      const text = allText(el);
      if (!text) continue;
      if (box.top > y + 4 || box.bottom < y - 4) continue;
      candidates.push({el, box, text, area: box.width * box.height});
    }

    const preferred = candidates.filter((item) => {
      const t = clean(item.text);
      if (kind === "shipment") return /^\d{6,12}$/.test(t);
      if (kind === "label") return /(?:^|[^A-Za-z])(?:not\s+printed|printed|created)(?=\s|\d|$)/i.test(t);
      if (kind === "tracking") return /[A-Z0-9]{8,}/i.test(t) && !/printed|created/i.test(t);
      if (kind === "order") return /[A-Z0-9][A-Z0-9-]{4,}/i.test(t) && !/printed|created/i.test(t);
      return true;
    });
    const list = preferred.length ? preferred : candidates;
    list.sort((a, b) => a.area - b.area);
    return list.length ? clean(list[0].text) : "";
  }

  function shipmentRowsInViewport() {
    const result = [];
    const seen = new Set();
    const column = bounds.shipment;
    const selectors = "a, [role='link'], span, div";
    for (const el of document.querySelectorAll(selectors)) {
      if (!visible(el)) continue;
      const text = clean(el.innerText || el.textContent || "");
      if (!/^\d{6,12}$/.test(text)) continue;
      const box = el.getBoundingClientRect();
      const cx = box.left + box.width / 2;
      const cy = box.top + box.height / 2;
      if (cy <= geometry.headerBottom + 2 || cy >= window.innerHeight - 8) continue;
      if (cx < column.left || cx > column.right) continue;
      const key = `${text}|${Math.round(cy)}`;
      if (seen.has(key)) continue;
      seen.add(key);
      result.push({shipmentNumber: text, y: cy, element: el});
    }
    result.sort((a, b) => a.y - b.y);
    return result;
  }

  function horizontalScrollableAncestor(el) {
    let node = el && el.parentElement;
    while (node && node !== document.body && node !== document.documentElement) {
      const style = getComputedStyle(node);
      if (node.scrollWidth > node.clientWidth + 60 && ["auto", "scroll", "overlay"].includes(style.overflowX)) return node;
      node = node.parentElement;
    }
    // Fallback: ShipStation's custom grid may keep the horizontal scroller beside the header.
    const candidates = [...document.querySelectorAll("body *")].filter((candidate) => {
      if (!visible(candidate)) return false;
      const style = getComputedStyle(candidate);
      const box = candidate.getBoundingClientRect();
      return candidate.scrollWidth > candidate.clientWidth + 100 &&
        ["auto", "scroll", "overlay"].includes(style.overflowX) &&
        box.top <= geometry.headerBottom + 20 && box.bottom > geometry.headerBottom + 60;
    });
    candidates.sort((a, b) => (a.getBoundingClientRect().width * a.getBoundingClientRect().height) - (b.getBoundingClientRect().width * b.getBoundingClientRect().height));
    return candidates[0] || null;
  }

  const horizontalScroller = horizontalScrollableAncestor(headerMap.label);
  const originalHorizontalLeft = horizontalScroller ? horizontalScroller.scrollLeft : 0;
  diagnostic.horizontalScroller = horizontalScroller ? {
    tag: horizontalScroller.tagName,
    className: clean(horizontalScroller.className),
    clientWidth: horizontalScroller.clientWidth,
    scrollWidth: horizontalScroller.scrollWidth,
    originalScrollLeft: originalHorizontalLeft
  } : null;

  async function revealLabelColumn() {
    geometry = rectsAndCenters();
    let labelRect = geometry.rects.label;
    const margin = 36;
    if (!horizontalScroller) return labelRect.left >= 0 && labelRect.right <= window.innerWidth;

    if (labelRect.right > window.innerWidth - margin) {
      horizontalScroller.scrollLeft = Math.min(
        horizontalScroller.scrollWidth - horizontalScroller.clientWidth,
        horizontalScroller.scrollLeft + (labelRect.right - (window.innerWidth - margin))
      );
      await sleep(120);
    } else if (labelRect.left < margin) {
      horizontalScroller.scrollLeft = Math.max(0, horizontalScroller.scrollLeft - (margin - labelRect.left));
      await sleep(120);
    }
    geometry = rectsAndCenters();
    labelRect = geometry.rects.label;
    return labelRect.left >= 0 && labelRect.right <= window.innerWidth;
  }

  async function restoreIdentifierColumns() {
    if (!horizontalScroller) return;
    if (Math.abs(horizontalScroller.scrollLeft - originalHorizontalLeft) > 1) {
      horizontalScroller.scrollLeft = originalHorizontalLeft;
      await sleep(100);
      geometry = rectsAndCenters();
    }
  }

  function rowContainerForSeed(seedElement) {
    let node = seedElement;
    let best = null;
    for (let depth = 0; node && node !== document.body && node !== document.documentElement && depth < 14; depth += 1, node = node.parentElement) {
      const box = node.getBoundingClientRect();
      if (box.width >= 600 && box.height >= 20 && box.height <= 90) {
        best = node;
      } else if (best && box.height > 120) {
        break;
      }
    }
    return best;
  }

  function textFromRowColumn(rowElement, targetX, kind) {
    if (!rowElement || !Number.isFinite(targetX)) return {text: "", rect: null, candidateCount: 0};
    const rowBox = rowElement.getBoundingClientRect();
    const rowY = rowBox.top + rowBox.height / 2;
    const candidates = [];
    const nodes = [rowElement, ...rowElement.querySelectorAll("*")];
    for (const el of nodes) {
      if (!visible(el)) continue;
      const box = el.getBoundingClientRect();
      if (box.width <= 1 || box.height <= 1 || box.height > Math.max(96, rowBox.height * 2.2)) continue;
      if (box.bottom < rowY - 7 || box.top > rowY + 7) continue;
      const text = allText(el);
      if (!text) continue;
      const centerX = box.left + box.width / 2;
      const distance = Math.abs(centerX - targetX);
      if (distance > 230) continue;

      const t = clean(text);
      let preferred = false;
      if (kind === "shipment") preferred = /^\d{6,12}$/.test(t);
      else if (kind === "label") preferred = /(?:^|[^A-Za-z])(?:not\s+printed|printed|created)(?=\s|\d|$)/i.test(t) && t.length < 180;
      else if (kind === "tracking") preferred = /[A-Z0-9]{8,}/i.test(t) && !/printed|created/i.test(t) && t.length < 120;
      else if (kind === "order") preferred = /[A-Z0-9][A-Z0-9#()\- ]{3,}/i.test(t) && !/printed|created/i.test(t) && t.length < 160;

      const giantPenalty = t.length > 240 ? 100000 : 0;
      const preferencePenalty = preferred ? 0 : (kind === "label" ? 30000 : 5000);
      const score = giantPenalty + preferencePenalty + distance * 30 + box.width * box.height * 0.002 + t.length;
      candidates.push({text: t, box, score, preferred});
    }

    candidates.sort((a, b) => a.score - b.score);
    const chosen = candidates[0];
    return {
      text: chosen ? chosen.text : "",
      rect: chosen ? {
        left: Math.round(chosen.box.left), top: Math.round(chosen.box.top),
        right: Math.round(chosen.box.right), bottom: Math.round(chosen.box.bottom),
        width: Math.round(chosen.box.width), height: Math.round(chosen.box.height)
      } : null,
      candidateCount: candidates.length
    };
  }

  function reasonableLabelText(value) {
    const text = clean(value);
    if (!text || text.length > 220) return false;
    return /(?:^|[^A-Za-z])(?:not\s+printed|printed|created)(?=\s|\d|$)/i.test(text);
  }

  // ShipStation can render "Printed" and its timestamp as separate nested spans.
  // Reading one best-matching DOM node loses half of the cell. Instead, inspect
  // every text fragment whose rectangle falls inside the real Label Printed column
  // and reconstruct the status + timestamp from those fragments.
  function labelTextFromRowFragments(rowElement) {
    if (!rowElement) return {text: "", fragmentCount: 0, fragments: [], bounds: null};
    const rowBox = rowElement.getBoundingClientRect();
    const band = currentExactLabelBounds();
    const fragments = [];
    for (const el of [rowElement, ...rowElement.querySelectorAll("*")]) {
      const box = el.getBoundingClientRect();
      if (box.width <= 0 || box.height <= 0 || box.height > Math.max(100, rowBox.height * 2.5)) continue;
      if (box.bottom <= rowBox.top + 1 || box.top >= rowBox.bottom - 1) continue;
      const overlap = Math.min(box.right, band.right) - Math.max(box.left, band.left);
      if (overlap <= 1) continue;
      const text = clean([
        el.innerText, el.textContent,
        el.getAttribute && el.getAttribute("aria-label"),
        el.getAttribute && el.getAttribute("title"),
        el.getAttribute && el.getAttribute("data-tooltip-content")
      ].filter(Boolean).join(" "));
      if (!text || text.length > 500) continue;
      if (!/printed|created|\d{1,2}\/\d{1,2}\/\d{4}|\d{1,2}:\d{2}/i.test(text)) continue;
      fragments.push({
        text, left: box.left, top: box.top, width: box.width, height: box.height,
        area: box.width * box.height
      });
    }

    // Prefer the smallest elements: parents often repeat all of their children's text.
    fragments.sort((a, b) => a.area - b.area || a.top - b.top || a.left - b.left);
    let status = "";
    let stamp = "";
    for (const item of fragments) {
      if (!status) {
        const m = item.text.match(/(?:^|[^A-Za-z])(not\s+printed|printed|created)(?=\s|\d|$)/i);
        if (m) status = m[1].replace(/\s+/g, " ");
      }
      if (!stamp) {
        const m = item.text.match(/(\d{1,2}\/\d{1,2}\/\d{4})\s*(?:[•·]|:|\s)\s*(\d{1,2}:\d{2}(?::\d{2})?(?:\s*[AP]M)?)/i);
        if (m) stamp = `${m[1]}•${m[2]}`;
      }
      if (status && stamp) break;
    }

    // A single small node may already contain the complete value.
    if (!status || !stamp) {
      for (const item of fragments) {
        const combined = item.text;
        if (!status) {
          const m = combined.match(/(?:^|[^A-Za-z])(not\s+printed|printed|created)(?=\s|\d|$)/i);
          if (m) status = m[1].replace(/\s+/g, " ");
        }
        if (!stamp) {
          const m = combined.match(/(\d{1,2}\/\d{1,2}\/\d{4})\s*(?:[•·]|:|\s)\s*(\d{1,2}:\d{2}(?::\d{2})?(?:\s*[AP]M)?)/i);
          if (m) stamp = `${m[1]}•${m[2]}`;
        }
      }
    }

    const text = clean([status, stamp].filter(Boolean).join(" "));
    return {
      text: reasonableLabelText(text) ? text : "",
      fragmentCount: fragments.length,
      fragments: fragments.slice(0, 12).map((f) => f.text),
      bounds: {left: Math.round(band.left), right: Math.round(band.right), center: Math.round(band.center)}
    };
  }

  const rowsByIdentity = new Map();

  async function collectCurrentViewport() {
    await restoreIdentifierColumns();
    geometry = rectsAndCenters();
    const rowSeeds = shipmentRowsInViewport();
    if (!rowSeeds.length) return [];

    // Read each shipment from its own row container. getBoundingClientRect() works for
    // off-screen cells too, so this avoids mistaking ShipStation's whole virtual-grid wrapper
    // for the Label Printed cell.
    const records = rowSeeds.map((seed) => {
      const rowElement = rowContainerForSeed(seed.element);
      const shipmentCell = textFromRowColumn(rowElement, geometry.centers.shipment, "shipment");
      const orderCell = textFromRowColumn(rowElement, geometry.centers.order, "order");
      const trackingCell = textFromRowColumn(rowElement, geometry.centers.tracking, "tracking");
      const labelFragments = labelTextFromRowFragments(rowElement);
      return {
        shipmentNumber: seed.shipmentNumber || shipmentCell.text || textAtPoint(geometry.centers.shipment, seed.y, "shipment"),
        orderNumber: orderCell.text || textAtPoint(geometry.centers.order, seed.y, "order"),
        tracking: trackingCell.text || textAtPoint(geometry.centers.tracking, seed.y, "tracking"),
        labelPrintedRaw: labelFragments.text,
        y: seed.y,
        rowElement,
        labelCandidateRect: labelFragments.bounds,
        labelCandidateCount: labelFragments.fragmentCount,
        labelFragments: labelFragments.fragments
      };
    });

    // Fallback: if a row-specific off-screen cell was not readable, temporarily reveal
    // Label Printed and read only that row's Y coordinate. Reject giant container text.
    const missingLabel = records.some((record) => !reasonableLabelText(record.labelPrintedRaw));
    if (missingLabel) {
      const labelVisible = await revealLabelColumn();
      if (labelVisible) {
        geometry = rectsAndCenters();
        const currentRows = [...document.querySelectorAll("[class*='grid-rows-']")].filter((el) => {
          const r = el.getBoundingClientRect();
          return r.height >= 20 && r.height <= 90 && r.width >= 500;
        });
        for (const record of records) {
          if (reasonableLabelText(record.labelPrintedRaw)) continue;
          let nearest = null;
          let nearestDistance = Infinity;
          for (const rowEl of currentRows) {
            const r = rowEl.getBoundingClientRect();
            const cy = r.top + r.height / 2;
            const d = Math.abs(cy - record.y);
            if (d < nearestDistance) { nearest = rowEl; nearestDistance = d; }
          }
          if (nearest && nearestDistance < 8) {
            const rebuilt = labelTextFromRowFragments(nearest);
            if (reasonableLabelText(rebuilt.text)) {
              record.labelPrintedRaw = rebuilt.text;
              record.labelCandidateRect = rebuilt.bounds;
              record.labelCandidateCount = rebuilt.fragmentCount;
              record.labelFragments = rebuilt.fragments;
              continue;
            }
          }
          const value = textAtPoint(geometry.centers.label, record.y, "label");
          if (reasonableLabelText(value)) record.labelPrintedRaw = value;
        }
      }
      await restoreIdentifierColumns();
    }

    for (const record of records) {
      const rowBox = record.rowElement && record.rowElement.getBoundingClientRect ? record.rowElement.getBoundingClientRect() : null;
      record.debug = {
        rowRect: rowBox ? {
          left: Math.round(rowBox.left), top: Math.round(rowBox.top), right: Math.round(rowBox.right), bottom: Math.round(rowBox.bottom),
          width: Math.round(rowBox.width), height: Math.round(rowBox.height)
        } : null,
        rowClass: record.rowElement ? clean(record.rowElement.className) : "",
        labelCandidateRect: record.labelCandidateRect || null,
        labelCandidateCount: record.labelCandidateCount || 0,
        labelFragments: record.labelFragments || []
      };
      delete record.y;
      delete record.rowElement;
      delete record.labelCandidateRect;
      delete record.labelCandidateCount;
      delete record.labelFragments;
      for (const key of ["shipmentNumber", "orderNumber", "tracking", "labelPrintedRaw"]) record[key] = clean(record[key]);
      if (!record.shipmentNumber) continue;
      const identity = record.shipmentNumber || record.tracking || record.orderNumber;
      const old = rowsByIdentity.get(identity);
      const score = (r) => [r.shipmentNumber, r.orderNumber, r.tracking, r.labelPrintedRaw].filter(Boolean).length + (/(?:^|[^A-Za-z])printed(?=\s|\d|$)/i.test(r.labelPrintedRaw || "") ? 2 : 0);
      if (!old || score(record) >= score(old)) rowsByIdentity.set(identity, record);
    }
    return rowSeeds;
  }

  let rowSeeds = await collectCurrentViewport();
  if (!rowSeeds.length) {
    return {ok: false, reason: "The columns were found, but no Shipment # rows were readable. Keep the shipment rows visible and try again.", diagnostic};
  }

  function verticalScrollableAncestor(el) {
    let node = el;
    while (node && node !== document.body && node !== document.documentElement) {
      if (node.scrollHeight > node.clientHeight + 80) {
        const style = getComputedStyle(node);
        if (["auto", "scroll", "overlay"].includes(style.overflowY)) return node;
      }
      node = node.parentElement;
    }
    const doc = document.scrollingElement || document.documentElement;
    return doc.scrollHeight > doc.clientHeight + 80 ? doc : null;
  }

  const verticalScroller = verticalScrollableAncestor(rowSeeds[0].element);
  diagnostic.verticalScroller = verticalScroller ? {
    tag: verticalScroller.tagName,
    className: clean(verticalScroller.className),
    clientHeight: verticalScroller.clientHeight,
    scrollHeight: verticalScroller.scrollHeight,
    originalScrollTop: verticalScroller.scrollTop
  } : null;
  if (verticalScroller) {
    const originalTop = verticalScroller.scrollTop;
    // Always scan the complete ShipStation grid from the top. The user may click
    // the extension while scrolled near the bottom, and starting there would miss
    // earlier shipments in ShipStation's virtualized list.
    verticalScroller.scrollTop = 0;
    await sleep(180);
    await collectCurrentViewport();

    const viewport = verticalScroller === document.scrollingElement || verticalScroller === document.documentElement ? window.innerHeight : verticalScroller.clientHeight;
    const step = Math.max(260, Math.floor(viewport * 0.72));
    let previousTop = -1;
    let stableBottom = 0;

    for (let loop = 0; loop < 220; loop += 1) {
      const maxTop = Math.max(0, verticalScroller.scrollHeight - (verticalScroller.clientHeight || window.innerHeight));
      const nextTop = Math.min(maxTop, verticalScroller.scrollTop + step);
      if (nextTop === previousTop) stableBottom += 1; else stableBottom = 0;
      previousTop = nextTop;
      verticalScroller.scrollTop = nextTop;
      await sleep(170);
      await collectCurrentViewport();
      const atBottom = verticalScroller.scrollTop >= maxTop - 4;
      if (atBottom && stableBottom >= 1) break;
      if (atBottom) stableBottom += 1;
      if (stableBottom >= 3) break;
    }

    verticalScroller.scrollTop = originalTop;
    await restoreIdentifierColumns();
    await sleep(80);
  }

  const rows = [...rowsByIdentity.values()];
  const labelReadCount = rows.filter((row) => clean(row.labelPrintedRaw)).length;
  diagnostic.finalHorizontalScrollLeft = horizontalScroller ? horizontalScroller.scrollLeft : null;
  diagnostic.rowCount = rows.length;
  diagnostic.labelReadCount = labelReadCount;

  return {
    ok: true,
    headers: Object.fromEntries(Object.entries(headerMap).map(([key, el]) => [key, clean(el.innerText || el.textContent || "")])),
    rows,
    labelReadCount,
    method: horizontalScroller ? "visible-text geometry + horizontal grid scroll" : (semanticHeaders.length ? "semantic + geometry fallback" : "visible-text geometry"),
    diagnostic
  };
}


function parseLabelForDiagnostic(rawValue) {
  const raw = String(rawValue || "").replace(/\s+/g, " ").trim();
  if (!raw) return {status: "Could not read", displayedTime: ""};
  if (/(?:^|[^A-Za-z])not\s+printed(?=\s|\d|$)/i.test(raw)) return {status: "Not Printed", displayedTime: ""};
  if (/(?:^|[^A-Za-z])printed(?=\s|\d|$)/i.test(raw)) {
    const match = raw.match(/(\d{1,2}\/\d{1,2}\/\d{4})\s*(?:[•·]|:|\s)\s*(\d{1,2}:\d{2}(?::\d{2})?(?:\s*[AP]M)?)/i);
    return {status: "Printed", displayedTime: match ? `${match[1]} ${match[2]}` : ""};
  }
  if (/(?:^|[^A-Za-z])created(?=\s|\d|$)/i.test(raw)) return {status: "Created / Not Printed", displayedTime: ""};
  return {status: "Could not read", displayedTime: ""};
}

function diagnosticText(capture, tabUrl) {
  const lines = [];
  const debug = (capture && capture.diagnostic) || {};
  lines.push("SHIPSTATION PRINT TIME CAPTURE - DIAGNOSTIC TXT");
  lines.push("Extension version: 0.4.9");
  lines.push(`Generated: ${new Date().toISOString()}`);
  lines.push(`Tab URL: ${tabUrl || debug.pageUrl || ""}`);
  lines.push(`Page title: ${debug.pageTitle || ""}`);
  lines.push(`Capture OK: ${capture && capture.ok ? "YES" : "NO"}`);
  lines.push(`Reader method: ${(capture && capture.method) || ""}`);
  lines.push(`Failure reason: ${(capture && capture.reason) || ""}`);
  lines.push("");
  lines.push("--- VIEWPORT ---");
  lines.push(`Width: ${debug.viewport?.width ?? ""}`);
  lines.push(`Height: ${debug.viewport?.height ?? ""}`);
  lines.push(`Device pixel ratio: ${debug.viewport?.devicePixelRatio ?? ""}`);
  lines.push("");
  lines.push("--- DETECTED HEADERS ---");
  const headers = (capture && capture.headers) || debug.headerMap || {};
  for (const key of ["shipment", "order", "tracking", "label"]) {
    lines.push(`${key}: ${headers[key] || "NOT FOUND"}`);
  }
  lines.push(`packing neighbor: ${debug.neighborHeaders?.packing || "NOT FOUND"}`);
  lines.push(`marketplace neighbor: ${debug.neighborHeaders?.marketplace || "NOT FOUND"}`);
  lines.push("");
  lines.push("Header rectangles (screen CSS pixels):");
  for (const [key, value] of Object.entries(debug.headerRects || {})) {
    lines.push(`${key}: ${JSON.stringify(value)}`);
  }
  lines.push("");
  lines.push("Semantic table/grid headers found by browser:");
  if ((debug.semanticHeaderTexts || []).length) {
    for (const value of debug.semanticHeaderTexts) lines.push(`- ${value}`);
  } else {
    lines.push("- NONE");
  }
  lines.push("");
  lines.push("--- SCROLLERS ---");
  lines.push(`Horizontal: ${debug.horizontalScroller ? JSON.stringify(debug.horizontalScroller) : "NOT FOUND"}`);
  lines.push(`Vertical: ${debug.verticalScroller ? JSON.stringify(debug.verticalScroller) : "NOT FOUND"}`);
  lines.push(`Final horizontal scrollLeft: ${debug.finalHorizontalScrollLeft ?? ""}`);
  lines.push("");
  const rows = (capture && capture.rows) || [];
  const labelReadCount = capture && Number.isFinite(capture.labelReadCount) ? capture.labelReadCount : 0;
  lines.push("--- SUMMARY ---");
  lines.push(`Rows captured: ${rows.length}`);
  lines.push(`Rows with nonblank Label Printed raw text: ${labelReadCount}`);
  lines.push(`Rows with blank Label Printed raw text: ${Math.max(0, rows.length - labelReadCount)}`);
  lines.push("");
  lines.push("--- ROWS ---");
  if (!rows.length) {
    lines.push("NO ROWS CAPTURED");
  } else {
    rows.forEach((row, index) => {
      const parsed = parseLabelForDiagnostic(row.labelPrintedRaw);
      lines.push(`[${index + 1}]`);
      lines.push(`Shipment #: ${row.shipmentNumber || ""}`);
      lines.push(`Order #: ${row.orderNumber || ""}`);
      lines.push(`Tracking #: ${row.tracking || ""}`);
      lines.push(`Raw Label Printed: ${row.labelPrintedRaw || "<BLANK>"}`);
      lines.push(`Parsed status: ${parsed.status}`);
      lines.push(`Parsed displayed print time: ${parsed.displayedTime || "<BLANK>"}`);
      lines.push(`Row debug: ${row.debug ? JSON.stringify(row.debug) : "<NONE>"}`);
      lines.push("");
    });
  }
  lines.push("--- END DIAGNOSTIC ---");
  return lines.join("\r\n");
}

async function downloadDiagnosticFile(capture, tabUrl) {
  const now = new Date();
  const stamp = [
    now.getFullYear(),
    String(now.getMonth() + 1).padStart(2, "0"),
    String(now.getDate()).padStart(2, "0"),
    "_",
    String(now.getHours()).padStart(2, "0"),
    String(now.getMinutes()).padStart(2, "0"),
    String(now.getSeconds()).padStart(2, "0")
  ].join("");
  const blob = new Blob([diagnosticText(capture, tabUrl)], {type: "text/plain;charset=utf-8"});
  const url = URL.createObjectURL(blob);
  try {
    await chrome.downloads.download({
      url,
      filename: `ShipStation_Print_Time_Diagnostic_${stamp}.txt`,
      saveAs: true
    });
  } finally {
    setTimeout(() => URL.revokeObjectURL(url), 5000);
  }
}

async function getActiveShipStationTab() {
  const [tab] = await chrome.tabs.query({active: true, currentWindow: true});
  if (!tab || !tab.id || !/^https:\/\/[^/]*shipstation\.com\//i.test(tab.url || "")) {
    throw new Error("Open the ShipStation Shipments page in this tab first.");
  }
  return tab;
}

async function readCurrentShipStationPage(tab) {
  const result = await chrome.scripting.executeScript({target: {tabId: tab.id}, func: captureShipmentsGrid});
  return result && result[0] && result[0].result;
}

captureButton.addEventListener("click", async () => {
  captureButton.disabled = true;
  setStatus("Reading the current ShipStation Shipments page...");
  try {
    const tab = await getActiveShipStationTab();
    const capture = await readCurrentShipStationPage(tab);
    if (!capture || !capture.ok) throw new Error((capture && capture.reason) || "Could not read the ShipStation grid.");
    if (!capture.rows.length) throw new Error("No shipment rows were found on the current page.");

    const tokenResponse = await fetch("http://127.0.0.1:8787/api/extension-token", {cache: "no-store"});
    if (!tokenResponse.ok) throw new Error("The local ShipStation checker is not running.");
    const tokenData = await tokenResponse.json();
    const capturedAt = new Date().toISOString();
    const sendResponse = await fetch("http://127.0.0.1:8787/api/shipstation-print-capture", {
      method: "POST",
      headers: {"Content-Type": "application/json", "X-ShipStation-Capture-Token": tokenData.token},
      body: JSON.stringify({rows: capture.rows, capturedAt})
    });
    const data = await sendResponse.json();
    if (!sendResponse.ok) throw new Error(data.error || "The local checker rejected the capture.");
    const warning = capture.labelReadCount < capture.rows.length
      ? `\nWarning: Label Printed was readable for ${capture.labelReadCount} of ${capture.rows.length} rows.`
      : `\nLabel Printed read for all ${capture.rows.length} rows.`;
    setStatus(`Captured ${data.received} row(s).\nLocal checker now has ${data.total} unique row(s).${warning}\nReader: ${capture.method}.`);
  } catch (error) {
    setStatus(error && error.message ? error.message : "Capture failed.");
  } finally {
    captureButton.disabled = false;
  }
});


diagnosticButton.addEventListener("click", async () => {
  captureButton.disabled = true;
  diagnosticButton.disabled = true;
  setStatus("Reading ShipStation and building diagnostic TXT...");
  try {
    const tab = await getActiveShipStationTab();
    let capture;
    try {

"""Local Windows-friendly web app for ShipStation daily shipment checks.

Version 0.4.8 deliberately keeps the old working v0.4.x workflow. ShipStation opens
in the user's normal browser session; the program does not launch a separate automated
ShipStation browser. An optional browser extension captures the Shipments -> Label
Printed cell and sends only those visible shipment fields back to this local app.

import base64
import json
import mimetypes
import os
from pathlib import Path
import secrets
import threading
import webbrowser
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

MAX_CAPTURE_BYTES = 5 * 1024 * 1024
BROWSER_SECURITY_HEADERS = {

def make_server(port=8787, root=None, extractor=extract_report, *, app_folder=None, settings_path=None):
    public_folder = Path(root or ROOT / "public").resolve()
    credential_source = CredentialSource(app_folder or ROOT, settings_path)
    export_lock = threading.Lock()
    capture_lock = threading.Lock()
    capture_rows: list[dict] = []
    capture_token = secrets.token_urlsafe(32)

    class BrowserRequestHandler(BaseHTTPRequestHandler):
        def log_message(self, format, *args):
            pass

        @property
        def origin(self):
            return f"http://127.0.0.1:{self.server.server_port}"

        def headers_ok(self):
            return self.headers.get("Host") == urlsplit(self.origin).netloc

        def reply(self, status, content, content_type="application/json"):
            if isinstance(content, dict):
                content = json.dumps(content).encode("utf-8")
            self.send_response(status)
            for key, value in BROWSER_SECURITY_HEADERS.items():
                self.send_header(key, value)
            self.send_header("Content-Type", content_type)
            self.send_header("Content-Length", str(len(content)))
            self.end_headers()
            if self.command != "HEAD":
                self.wfile.write(content)

        def _read_json(self, maximum=MAX_REQUEST_BYTES):
            if not self.headers.get("Content-Type", "").startswith("application/json"):
                raise ReportError("Expected a JSON request.")
            try:
                length = int(self.headers.get("Content-Length", "0"))
            except ValueError:
                raise ReportError("Invalid request size.") from None
            if not 1 <= length <= maximum or self.headers.get("Transfer-Encoding"):
                raise ReportError("The request is too large.")
            self.connection.settimeout(60)
            try:
                data = json.loads(self.rfile.read(length))
            except (ValueError, OSError):
                raise ReportError("Invalid JSON request.") from None
            if not isinstance(data, dict):
                raise ReportError("Invalid JSON request.")
            return data

        def do_GET(self):
            if not self.headers_ok():
                self.reply(403, {"error": "Open the displayed 127.0.0.1 address."})
                return

            path = unquote(urlsplit(self.path).path)
            if path == "/api/extension-token":
                # Edge/Chrome extension pages with localhost host permission can read this.
                self.reply(200, {"token": capture_token, "port": self.server.server_port})
                return
            if path == "/api/print-capture-status":
                with capture_lock:
                    snapshot = list(capture_rows)
                latest = max((str(row.get("capturedAt") or "") for row in snapshot), default="")
                self.reply(200, {"count": len(snapshot), "latestCapturedAt": latest})
                return

            requested_file = (
                public_folder / ("local/index.html" if path == "/" else path.lstrip("/"))
            ).resolve()
            if not requested_file.is_relative_to(public_folder) or not requested_file.is_file():
                self.reply(404, {"error": "Not found."})
                return
            content_type = {
                ".js": "text/javascript; charset=utf-8",
                ".css": "text/css; charset=utf-8",
                ".html": "text/html; charset=utf-8",
                ".svg": "image/svg+xml",
            }.get(requested_file.suffix)
            self.reply(
                200,
                requested_file.read_bytes(),
                content_type or mimetypes.guess_type(requested_file.name)[0] or "application/octet-stream",
            )

        do_HEAD = do_GET

        def do_POST(self):
            request_path = urlsplit(self.path).path

            # Extension capture is intentionally the only cross-origin POST. It requires
            # a random token obtained from this running local app, preventing ordinary
            # websites from injecting fake shipment data into the report.
            if request_path == "/api/shipstation-print-capture":
                if not self.headers_ok() or self.headers.get("X-ShipStation-Capture-Token") != capture_token:
                    self.reply(403, {"error": "Print-capture token rejected. Keep the local program open and try again."})
                    return
                try:
                    payload = self._read_json(MAX_CAPTURE_BYTES)
                    normalized = normalize_capture_rows(payload.get("rows"), payload.get("capturedAt"))
                    if not normalized:
                        raise ReportError("No ShipStation shipment rows were captured.")
                    with capture_lock:
                        capture_rows[:] = merge_capture_store(capture_rows, normalized)
                        total = len(capture_rows)
                    self.reply(200, {"ok": True, "received": len(normalized), "total": total})
                except ReportError as error:
                    self.reply(400, {"error": str(error)})
                return

            if (
                not self.headers_ok()
                or self.headers.get("Origin", self.origin) != self.origin
                or self.headers.get("Sec-Fetch-Site", "same-origin") not in ("same-origin", "none")
            ):
                self.reply(403, {"error": "Open this app directly at the displayed local address."})
                return

            if request_path == "/api/exit":
                self.reply(200, {"stopping": True})
                threading.Thread(target=self.server.shutdown, daemon=True).start()
                return

            if request_path == "/api/open-shipstation":
                opened = webbrowser.open(SHIPSTATION_SHIPPED_URL, new=2)
                self.reply(
                    200,
                    {
                        "opened": bool(opened),
                        "url": SHIPSTATION_SHIPPED_URL,
                        "message": "ShipStation opened in your normal browser. Select the date/shipments, then export Current View and/or use the Print Time Capture extension.",
                    },
                )
                return

            if request_path == "/api/open-extension-folder":
                try:
                    if os.name == "nt":
                        os.startfile(str(EXTENSION_FOLDER))  # type: ignore[attr-defined]
                        self.reply(200, {"opened": True})
                    else:
                        self.reply(400, {"error": "Open the ShipStation_Print_Time_Extension folder manually."})
                except OSError:
                    self.reply(400, {"error": "Could not open the extension folder. Open ShipStation_Print_Time_Extension manually."})
                return

            if request_path == "/api/clear-print-capture":
                with capture_lock:
                    capture_rows.clear()
                self.reply(200, {"ok": True, "count": 0})
                return

            if request_path in ("/api/credentials/status", "/api/credentials/location"):
                try:
                    data = self._read_json(65536)
                    if request_path.endswith("/location"):
                        status = credential_source.use_location(data.get("location"))
                    else:
                        status = credential_source.status()
                    # Status contains only readiness, path and API version, never keys.
                    self.reply(200, status)
                except ReportError as error:
                    self.reply(400, {"error": str(error)})
                return

            if request_path != "/api/report":
                self.reply(404, {"error": "Not found."})
                return

            payload = {}
            try:
                payload = self._read_json(MAX_REQUEST_BYTES)
                if "credentialsText" not in payload:
                    payload["credentialsText"], _ = credential_source.load()
                parse_credentials(payload.get("credentialsText"))
                payload["shipDateStart"] = payload.get("shipDateStart") or payload.get("shipDate")
                parse_ship_date_range(payload["shipDateStart"], payload.get("shipDateEnd"))
                if payload.get("printCsvText"):
                    parse_print_status_csv(payload["printCsvText"])
            except (TypeError, ReportError, OSError) as error:
                self.reply(
                    400,
                    {
                        "error": (
                            str(error)
                            if isinstance(error, ReportError)
                            else "Choose valid files and real From / Through dates."
                        )
                    },
                )
                return

            if not export_lock.acquire(blocking=False):
                self.reply(409, {"error": "An export is already running. Wait for it to finish."})
                return

            try:
                self.send_response(200)
                for key, value in BROWSER_SECURITY_HEADERS.items():
                    self.send_header(key, value)
                self.send_header("Content-Type", "application/x-ndjson; charset=utf-8")
                self.send_header("Connection", "close")
                self.end_headers()

                def send(event):
                    self.wfile.write(
                        (json.dumps(event, ensure_ascii=True, allow_nan=False) + "\n").encode("utf-8")
                    )
                    self.wfile.flush()

                def progress(update):
                    if isinstance(update, dict):
                        send({"type": "progress", **update})
                    else:
                        send({"type": "progress", "message": str(update)})

                try:
                    report = extractor(payload["credentialsText"], payload["shipDateStart"],
                                       ship_date_end=payload.get("shipDateEnd"), progress=progress)
                    payload["credentialsText"] = ""

                    # Preserve the old v0.4.x CSV comparison exactly as the first print check.
                    print_csv_text = payload.get("printCsvText") or ""
                    if print_csv_text.strip():

                    # Add the exact Shipments-grid Label Printed state/time only when the
                    # user captured it from their normal logged-in browser.

                        captured = [dict(row) for row in capture_rows]
                    if captured:
                        progress("Matching ShipStation Label Printed date/time capture...")
                        merge_shipstation_print_capture(report, captured)
                    else:
                        mark_no_shipstation_print_capture(report)

                    if payload.get("checkCarriers"):
                        progress("Opening carrier tracking pages in Microsoft Edge / Chrome...")
                        add_carrier_tracking(
                            report,
                            progress=progress,
                            visible_browser=bool(payload.get("showCarrierBrowser", True)),
                        )
                    else:
                        mark_carrier_check_disabled(report)

                    progress("Creating the combined Excel report...")
                    workbook = build_excel(report)
                    summary = {
                        key: report.get(key)
                        for key in (
                            "version",
                            "shipDate",
                            "shipDateStart",
                            "shipDateEnd",
                            "displayDate",
                            "rangeDays",
                            "fileRange",
                            "rowCount",
                            "recordCount",
                            "missingTrackingCount",
                            "printCsvRecordCount",
                            "notPrintedRowCount",
                            "uiPrintCaptureCount",
                            "uiPrintMatchedRows",
                            "uiPrintAmbiguousRows",
                            "uiPrintedMissingTimeCount",
                            "printedMissingTrackingCount",
                            "carrierCheckCount",
                            "carrierAcceptedCount",
                            "carrierNotAcceptedCount",
                            "carrierManualCount",
                            "carrierErrorCount",
                        )
                    }
                    summary["fileBase64"] = base64.b64encode(workbook).decode("ascii")
                    send({"type": "complete", "report": summary})
                except (BrokenPipeError, ConnectionResetError, TimeoutError):
                    pass
                except Exception as error:
                    try:
                        send(
                            {
                                "type": "error",
                                "message": (
                                    str(error)
                                    if isinstance(error, ReportError)
                                    else "The report could not be completed. No partial Excel file was created."
                                ),
                            }
                        )
                    except OSError:
                        pass
            finally:
                payload.clear()
                export_lock.release()
                self.close_connection = True

    class LocalServer(ThreadingHTTPServer):
        daemon_threads = True

        def handle_error(self, request, client_address):
            pass

    return LocalServer(("127.0.0.1", port), BrowserRequestHandler)

"""Optional public-web carrier tracking for UPS, FedEx and USPS only.

This module does not use carrier API credentials. When enabled, it opens an
installed Microsoft Edge or Google Chrome browser through Playwright, visits the
public tracking page for each unique tracking number, and reads the rendered status.
If a carrier blocks automation or asks for a CAPTCHA, the report keeps a direct
tracking link and marks the row for manual review instead of attempting to bypass it.
"""

from __future__ import annotations

import os
import re
import shutil
import time
from datetime import datetime
from pathlib import Path
from urllib.parse import quote

from shipstation import ReportError

SUPPORTED = ("UPS", "FedEx", "USPS")


def clean(value):
    return "" if value is None else str(value).strip()


def split_tracking(value):
    return [p.strip() for p in re.split(r"[;,\n\r]+", clean(value)) if p.strip()]


def valid_tracking_identifier(value):
    value = clean(value).replace(" ", "")
    if not value:
        return False
    # A value such as 9.40015020621792E+021 may already have lost digits in Excel.
    if re.fullmatch(r"[+-]?\d+(?:\.\d+)?[Ee][+-]?\d+", value):
        return False
    return bool(re.fullmatch(r"[A-Za-z0-9]{7,40}", value))


def normalize_carrier(carrier="", service="", provider="", tracking=""):
    text = " ".join([clean(carrier), clean(service), clean(provider)]).lower()
    t = clean(tracking).replace(" ", "").upper()

    if "fedex" in text or "fdxe" in text or "fdxg" in text:
        return "FedEx"
    if "usps" in text or "stamps" in text or "endicia" in text or "postal" in text:
        return "USPS"
    if re.search(r"\bups\b", text) or "ups_" in text or "ups wallet" in text:
        return "UPS"

    # Fallback only when ShipStation carrier text is unavailable/non-descriptive.
    if t.startswith("1Z") and len(t) >= 18:
        return "UPS"
    if t.isdigit() and len(t) in (20, 21, 22, 26, 34) and t.startswith(("9", "4")):
        return "USPS"
    if t.isdigit() and len(t) in (12, 15):
        return "FedEx"
    return "Unsupported"


def build_tracking_url(carrier, tracking):
    tracking = clean(tracking).replace(" ", "")
    encoded = quote(tracking, safe="")
    if carrier == "UPS":
        return f"https://www.ups.com/track?loc=en_US&tracknum={encoded}"
    if carrier == "FedEx":
        return f"https://www.fedex.com/fedextrack/?trknbr={encoded}"
    if carrier == "USPS":
        return f"https://tools.usps.com/go/TrackConfirmAction?tLabels={encoded}"
    return ""


def _base_result(tracking, carrier):
    return {
        "tracking": clean(tracking),
        "carrier": carrier,
        "trackingUrl": build_tracking_url(carrier, tracking),
        "status": "UNKNOWN",
        "statusDescription": "",
        "carrierAccepted": "Unknown",
        "firstCarrierScan": "",
        "latestScan": "",
        "latestLocation": "",
        "estimatedDelivery": "",
        "actualDelivery": "",
        "checkedAt": datetime.now().astimezone().isoformat(timespec="seconds"),
        "error": "",
    }


def _finish(result, physical_seen=False):
    status = result["status"]
    if status in ("LABEL CREATED", "CANCELLED"):
        result["carrierAccepted"] = "No"
    elif status in ("CARRIER ACCEPTED", "IN TRANSIT", "OUT FOR DELIVERY", "DELIVERED"):
        result["carrierAccepted"] = "Yes"
    elif physical_seen:
        result["carrierAccepted"] = "Yes"
    else:
        result["carrierAccepted"] = "Unknown"
    return result


def _normalized_identifier(value):
    return re.sub(r"[^A-Z0-9]", "", clean(value).upper())


def _relevant_lines(text, tracking):
    lines = [re.sub(r"\s+", " ", line).strip() for line in clean(text).splitlines()]
    lines = [line for line in lines if line]
    if not lines:
        return [], False

    target = _normalized_identifier(tracking)
    found_index = None
    if target:
        for index, line in enumerate(lines):
            if target in _normalized_identifier(line):
                found_index = index
                break

    if found_index is None:
        # Do not classify help/footer text when the requested tracking identifier is
        # not visible on the rendered result page.
        return lines[:140], False

    start = max(0, found_index - 30)
    end = min(len(lines), found_index + 90)
    return lines[start:end], True


def _status_patterns(carrier):
    # Patterns are intentionally specific. The first matching line in the shipment
    # area wins so a historical "Label Created" lower on a delivered shipment does
    # not override the current Delivered status near the top.
    common = [
        ("DELIVERED", ("delivered",)),
        ("OUT FOR DELIVERY", ("out for delivery",)),
    ]
    if carrier == "UPS":
        return common + [
            ("CARRIER ACCEPTED", ("we have your package", "picked up", "origin scan")),
            ("IN TRANSIT", ("on the way", "in transit", "departed from facility", "arrived at facility")),
            ("LABEL CREATED", ("label created", "shipment ready for ups", "billing information received")),
            ("EXCEPTION", ("exception", "delay", "delivery attempted", "returning to sender")),
        ]
    if carrier == "FedEx":
        return common + [
            ("CARRIER ACCEPTED", ("we have your package", "at drop off point", "picked up")),
            ("IN TRANSIT", ("on the way", "in transit", "at fedex location", "departed fedex location")),
            ("LABEL CREATED", ("label created", "shipment information sent to fedex")),
            ("CANCELLED", ("shipment cancelled",)),
            ("EXCEPTION", ("delay", "exception", "we tried to deliver", "returning to shipper")),
        ]
    if carrier == "USPS":
        return common + [
            (
                "LABEL CREATED",
                (
                    "shipping label created, usps awaiting item",
                    "usps awaiting item",
                    "pre-shipment",
                    "pre shipment",
                    "picked up by shipping partner, usps awaiting item",
                ),
            ),
            (
                "CARRIER ACCEPTED",
                (
                    "usps in possession of item",
                    "accepted at usps",
                    "shipment received, package acceptance pending",
                ),
            ),
            (
                "IN TRANSIT",
                (
                    "moving through network",
                    "in transit to next facility",
                    "arrived at usps",
                    "departed usps",
                    "processed through usps",
                    "processing at usps",
                ),
            ),
            ("EXCEPTION", ("alert", "delivery attempted", "return to sender", "insufficient address")),
        ]
    return []


def extract_browser_status(carrier, tracking, body_text):
    """Classify the rendered public tracking page without relying on fragile CSS."""
    result = _base_result(tracking, carrier)
    lines, tracking_visible = _relevant_lines(body_text, tracking)
    if not lines:
        result.update(status="MANUAL CHECK REQUIRED", error="Carrier page returned no readable text.")
        return _finish(result)
    if not tracking_visible:
        result.update(
            status="MANUAL CHECK REQUIRED",
            error="The requested tracking number was not visible on the rendered carrier result page.",
        )
        return _finish(result)

    blocked_phrases = (
        "verify you are human",
        "captcha",
        "access denied",
        "temporarily blocked",
        "unusual traffic",
        "security check",
        "robot or a human",
    )
    joined = "\n".join(lines).lower()
    if any(phrase in joined for phrase in blocked_phrases):
        result.update(
            status="MANUAL CHECK REQUIRED",
            error="Carrier website requested human verification or blocked automated reading.",
        )
        return _finish(result)

    # Build exact match candidates with their line index. Earliest visible shipment
    # status wins; this avoids footer/help text overriding the actual status.
    candidates = []
    for status, phrases in _status_patterns(carrier):
        for line_index, line in enumerate(lines):
            lower = line.lower()
            for phrase in phrases:
                if phrase in lower:
                    candidates.append((line_index, status, line, phrase))
                    break

    if not candidates:
        # Some USPS pages use the short status "Accepted" on its own.
        if carrier == "USPS":
            for line_index, line in enumerate(lines):
                if line.strip().lower() == "accepted":
                    candidates.append((line_index, "CARRIER ACCEPTED", line, "accepted"))
                    break

    if not candidates:
        result.update(
            status="MANUAL CHECK REQUIRED",
            error="The public tracking page opened, but the program could not identify the current status.",
        )
        return _finish(result)

    candidates.sort(key=lambda item: item[0])
    _, status, line, _ = candidates[0]
    result["status"] = status
    result["statusDescription"] = line[:500]

    physical_seen = status in ("CARRIER ACCEPTED", "IN TRANSIT", "OUT FOR DELIVERY", "DELIVERED")
    return _finish(result, physical_seen=physical_seen)


def _installed_browser_paths():
    candidates = []
    env = os.environ
    roots = [env.get("PROGRAMFILES(X86)"), env.get("PROGRAMFILES"), env.get("LOCALAPPDATA")]
    for root in [p for p in roots if p]:
        candidates.extend(
            [
                Path(root) / "Microsoft" / "Edge" / "Application" / "msedge.exe",
                Path(root) / "Google" / "Chrome" / "Application" / "chrome.exe",
            ]
        )
    for command in ("msedge", "microsoft-edge", "chrome", "google-chrome", "chromium", "chromium-browser"):
        found = shutil.which(command)
        if found:
            candidates.append(Path(found))
    unique = []
    seen = set()
    for path in candidates:
        key = str(path).lower()
        if path.is_file() and key not in seen:
            seen.add(key)
            unique.append(path)
    return unique


class PublicTrackingBrowser:
    def __init__(self, progress=lambda message: None, visible=True):
        self.progress = progress
        self.visible = bool(visible)
        self._playwright = None
        self._browser = None
        self._context = None
        self._page = None

    def start(self):
        try:
            from playwright.sync_api import sync_playwright
        except ImportError:
            raise ReportError(
                "Browser tracking support is not installed. Close the program and run START.cmd again while connected to the internet."
            ) from None

        self._playwright = sync_playwright().start()
        launch_errors = []

        for channel in ("msedge", "chrome"):
            try:
                self._browser = self._playwright.chromium.launch(
                    channel=channel,
                    headless=not self.visible,
                )
                break
            except Exception as error:
                launch_errors.append(f"{channel}: {error.__class__.__name__}")

        if self._browser is None:
            for executable in _installed_browser_paths():
                try:
                    self._browser = self._playwright.chromium.launch(
                        executable_path=str(executable),
                        headless=not self.visible,
                    )
                    break
                except Exception as error:
                    launch_errors.append(f"{executable.name}: {error.__class__.__name__}")

        if self._browser is None:
            self.close()
            raise ReportError(
                "Could not start Microsoft Edge or Google Chrome for carrier tracking. "
                "Install/update Edge or Chrome, then try again."
            )

        self._context = self._browser.new_context(locale="en-US", viewport={"width": 1280, "height": 900})
        self._page = self._context.new_page()
        self._page.set_default_timeout(7000)
        self._page.set_default_navigation_timeout(30000)
        return self

    def close(self):
        for obj in (self._context, self._browser):
            try:
                if obj:
                    obj.close()
            except Exception:
                pass
        self._context = None
        self._browser = None
        self._page = None
        if self._playwright:
            try:
                self._playwright.stop()
            except Exception:
                pass
        self._playwright = None

    def _body_text(self):
        try:
            return self._page.locator("body").inner_text(timeout=5000)
        except Exception:
            return ""

    def _wait_for_status(self, carrier, tracking, seconds=7.5):
        deadline = time.monotonic() + seconds
        latest = ""
        while time.monotonic() < deadline:
            latest = self._body_text()
            result = extract_browser_status(carrier, tracking, latest)
            if result["status"] != "MANUAL CHECK REQUIRED":
                return result
            # When the window is visible, give the user a short chance to complete a
            # carrier-provided human-verification step. Hidden mode returns immediately.
            if "human verification" in result.get("error", "").lower() and not self.visible:
                return result
            time.sleep(0.6)
        return extract_browser_status(carrier, tracking, latest)

    def _fill_tracking_input(self, tracking):
        # Generic fallback used when a carrier changes its direct tracking URL.
        inputs = self._page.locator("input")
        try:
            count = min(inputs.count(), 40)
        except Exception:
            count = 0

        best = None
        best_score = -1
        for index in range(count):
            item = inputs.nth(index)
            try:
                if not item.is_visible():
                    continue
                attrs = " ".join(
                    clean(item.get_attribute(name))
                    for name in ("placeholder", "aria-label", "name", "id", "title")
                ).lower()
            except Exception:
                continue
            score = 0
            if "tracking" in attrs:
                score += 6
            if "track" in attrs:
                score += 4
            if "search" in attrs:
                score += 2
            if score > best_score:
                best, best_score = item, score

        if best is None or best_score <= 0:
            return False
        try:
            best.fill(tracking)
            best.press("Enter")
            return True
        except Exception:
            return False

    def check_one(self, tracking, carrier):
        result = _base_result(tracking, carrier)
        if not valid_tracking_identifier(tracking):
            result.update(
                status="INVALID TRACKING",
                error="Tracking number is blank, malformed, or scientific notation.",
            )
            return _finish(result)
        if carrier not in SUPPORTED:
            result.update(status="UNSUPPORTED", error="Only UPS, FedEx and USPS are supported.")
            return _finish(result)

        url = build_tracking_url(carrier, tracking)
        try:
            self._page.goto(url, wait_until="domcontentloaded")
            result = self._wait_for_status(carrier, tracking)
            result["trackingUrl"] = url
            if result["status"] != "MANUAL CHECK REQUIRED":
                return result

            # One fallback: open the carrier's public tracking page and type the number.
            base_urls = {
                "UPS": "https://www.ups.com/track?loc=en_US",
                "FedEx": "https://www.fedex.com/en-us/tracking.html",
                "USPS": "https://tools.usps.com/go/TrackConfirmAction_input.action",
            }
            self._page.goto(base_urls[carrier], wait_until="domcontentloaded")
            if self._fill_tracking_input(tracking):
                result = self._wait_for_status(carrier, tracking, seconds=8.5)
                result["trackingUrl"] = url
                return result

            result["trackingUrl"] = url
            return result
        except Exception as error:
            detail = clean(str(error)).splitlines()[0][:240]
            result.update(
                status="MANUAL CHECK REQUIRED",
                error=(
                    f"Carrier page could not be read automatically ({error.__class__.__name__})"
                    + (f": {detail}" if detail else ".")
                ),
            )
            return _finish(result)

    def check_all(self, requests_to_check):
        results = {}
        if not requests_to_check:
            return results

        self.start()
        try:
            total = len(requests_to_check)
            for index, item in enumerate(requests_to_check, 1):
                tracking = item["tracking"]
                carrier = item["carrier"]
                self.progress(
                    {
                        "message": f"Carrier website {index} of {total}: {carrier} {tracking}",
                        "section": "Carrier websites",
                        "currentPage": index,
                        "totalPages": total,
                    }
                )
                results[tracking] = self.check_one(tracking, carrier)
                # Be polite to public tracking sites and reduce accidental rate limiting.
                if index < total:
                    time.sleep(0.8)
        finally:
            self.close()
        return results


def _shipping_warning(row):
    print_check = clean(row.get("printCheck"))
    carrier_status = clean(row.get("carrierStatus"))
    notified = clean(row.get("marketplaceNotified")).lower() == "notified"

    if carrier_status == "LABEL CREATED" and print_check == "NOT PRINTED":
        return "CRITICAL - NOT PRINTED AND NO CARRIER ACCEPTANCE"
    if carrier_status == "LABEL CREATED" and notified:
        return "MARKETPLACE NOTIFIED BUT NO CARRIER ACCEPTANCE"
    if carrier_status == "LABEL CREATED" and print_check == "PRINTED":
        return "PRINTED BUT NO CARRIER ACCEPTANCE"
    if print_check == "NOT PRINTED" and row.get("carrierAccepted") == "Yes":
        return "PRINT STATUS DISCREPANCY - CARRIER HAS PACKAGE"
    if carrier_status == "EXCEPTION":return "CARRIER EXCEPTION - REVIEW"
    if carrier_status == "CANCELLED":
        return "SHIPMENT CANCELLED - REVIEW"
    if carrier_status == "MANUAL CHECK REQUIRED":
        return "MANUAL CARRIER CHECK REQUIRED"
    if carrier_status == "INVALID TRACKING":
        return "INVALID TRACKING - REVIEW"
    if carrier_status == "UNSUPPORTED":
        return "UNSUPPORTED CARRIER"
    if carrier_status in ("CARRIER ACCEPTED", "IN TRANSIT", "OUT FOR DELIVERY", "DELIVERED"):
        return "OK - CARRIER ACCEPTED"
    if carrier_status == "UNKNOWN":
        return "UNKNOWN CARRIER STATUS - REVIEW"
    return ""

"""Load user-owned API files from one explicit location; persist only that location."""

from __future__ import annotations

import json
import os
from pathlib import Path
import stat
import tempfile
import threading

from shipstation import ReportError, parse_credentials

MAX_KEY_BYTES = 16 * 1024
KEY_NAMES = {"api key", "api key.txt"}


def default_settings_path():
    local = os.environ.get("LOCALAPPDATA")
    parent = Path(local) / "SSC" if local else Path.home() / ".shipstation-daily-shipment-check"
    return parent / "api_key_location.json"


class CredentialSource:
    def __init__(self, app_folder, settings_path=None):
        self.app_folder = Path(app_folder).resolve()
        self.settings_path = Path(settings_path) if settings_path is not None else default_settings_path()
        self._lock = threading.RLock()
        self._location = ""
        self._settings_error = ""
        try:
            with self.settings_path.open("r", encoding="utf-8") as handle:
                raw = handle.read(65537)
            if len(raw) > 65536:
                raise ValueError("Settings too large")
            data = json.loads(raw)
            self._location = self._clean_location(data["location"])
        except FileNotFoundError:
            pass
        except (OSError, ValueError, TypeError, KeyError, ReportError):
            self._settings_error = "The saved API location could not be read. Choose a location again or click Use program folder."

    @staticmethod
    def _clean_location(value):
        if not isinstance(value, str) or len(value) > 32768 or any(c in value for c in "\x00\r\n"):
            raise ReportError("Enter a file or folder path, not the API key itself.")
        value = value.strip()
        if len(value) >= 2 and value[0] == value[-1] and value[0] in "\"'":
            value = value[1:-1].strip()
        return value

    def _resolve(self, location):
        try:
            path = Path(os.path.expandvars(location)).expanduser() if location else self.app_folder
            if not path.is_absolute():
                path = self.app_folder / path
            if path.is_dir():
                # Deliberately shallow: no drive search or recursive folder scan.
                matches = [p for p in path.iterdir() if p.name.casefold() in KEY_NAMES and p.is_file()]
                if not matches:
                    raise ReportError("No API key file found. Put API key.txt beside START.cmd, enter its folder or full file path, or choose a file below.")
                if len(matches) != 1:
                    raise ReportError("More than one API key file was found in that folder. Enter the full path to the one you want.")
                path = matches[0]
            elif not path.exists():
                raise ReportError("The API key location was not found. Check the path or choose the file again.")
            if not stat.S_ISREG(path.stat().st_mode):
                raise ReportError("Choose a regular API text file or the folder that contains API key.txt.")
            return path.resolve()
        except (OSError, ValueError, RuntimeError):
            raise ReportError("The API key location could not be opened. Check the path and Windows permissions.") from None

    def _load(self, location):
        path = self._resolve(location)
        try:
            with path.open("rb") as handle:
                raw = handle.read(MAX_KEY_BYTES + 1)
            if len(raw) > MAX_KEY_BYTES:
                raise ReportError("Choose an API text file smaller than 16 KB.")
            encoding = "utf-16" if raw.startswith((b"\xff\xfe", b"\xfe\xff")) else "utf-8-sig"
            text = raw.decode(encoding)
        except UnicodeError:
            raise ReportError("Save the API file as UTF-8 text in Notepad, then try again.") from None
        except OSError:
            raise ReportError("The API key file could not be read. Check Windows file permissions.") from None
        credentials = parse_credentials(text)
        version = credentials["version"].upper()
        credentials.clear()
        return text, {"ready": True, "location": location, "path": str(path), "apiVersion": version,
                      "source": "saved location" if location else "program folder"}

    def load(self):
        with self._lock:
            if self._settings_error:
                raise ReportError(self._settings_error)
            return self._load(self._location)

    def status(self):
        with self._lock:
            try:
                _, metadata = self.load()
                return metadata
            except ReportError as error:
                return {"ready": False, "location": self._location, "error": str(error)}

    def use_location(self, value):
        location = self._clean_location(value)
        with self._lock:
            # A bad custom selection must not silently switch credentials or overwrite
            # the previously selected location. Resetting to the program folder is
            # allowed even if its API file has not been placed there yet.
            if location:
                _, metadata = self._load(location)
                location = metadata["path"]  # Keep the chosen absolute file path.
            temporary = None
            try:
                self.settings_path.parent.mkdir(parents=True, exist_ok=True)
                with tempfile.NamedTemporaryFile(mode="w", encoding="utf-8", dir=self.settings_path.parent,
                                                 prefix=".api-location-", suffix=".tmp", delete=False) as handle:
                    temporary = Path(handle.name)
                    json.dump({"location": location}, handle)
                    handle.write("\n")
                os.replace(temporary, self.settings_path)
            except OSError:
                raise ReportError("The API location could not be saved. Check Windows permissions, or choose the file for this report.") from None
            finally:
                if temporary is not None:
                    try:
                        temporary.unlink(missing_ok=True)
                    except OSError:
                        pass
            self._location = location
            self._settings_error = ""
            return self.status()

def _excel_date(value):
    if not value:
        return None
    if isinstance(value, (date, datetime)):
        return value
    text = str(value).strip()
    try:
        if len(text) >= 10 and text[4] == "-":
            return datetime.fromisoformat(text.replace("Z", "+00:00")).replace(tzinfo=None)
        if len(text) == 10 and text[2] == "/":
            return datetime.strptime(text, "%m/%d/%Y")
    except ValueError:
        return value
    return value


def _cell_fill(key, value):
    text = str(value or "").upper()
    if key in ("shippingWarning", "carrierCheckError") and value:
        if "CRITICAL" in text or "ERROR" in text or "NO CARRIER ACCEPTANCE" in text:
            return PatternFill("solid", fgColor="F4CCCC")
        if "REVIEW" in text or "NOT CONFIGURED" in text or "UNSUPPORTED" in text:

def table(sheet, columns, records):
    if len(records) > 1048575:
        raise ReportError("This report exceeds Excel's row limit.")
    sheet.append([header for header, _, _ in columns])
    for index, (_, _, width) in enumerate(columns, 1):
        sheet.column_dimensions[get_column_letter(index)].width = width

    date_like_keys = {
        "orderDate",
        "shipDate",
        "firstCarrierScan",
        "latestCarrierScan",
        "estimatedDelivery",
        "actualDelivery",
        "checkedAt",
        "latestScan",
        "shipstationUiCapturedAt",
    }

    for row_index, record in enumerate(records, 2):
        for column_index, (_, key, _) in enumerate(columns, 1):
            value = record.get(key)
            converted = _excel_date(value) if key in date_like_keys else value
            if isinstance(converted, str) and len(converted) > 32767:
                converted = converted[:32764] + "..."
            cell = sheet.cell(row_index, column_index, converted)
            if isinstance(converted, str):
                cell.data_type = "s"
                cell.number_format = "@"
                if key == "trackingUrl" and converted.startswith("https://") and ";" not in converted:
                    cell.hyperlink = converted

                if key in ("orderDate", "shipDate"):
                    cell.number_format = "mm/dd/yyyy"
                else:
                    cell.number_format = "mm/dd/yyyy h:mm AM/PM"
            elif key in ("unitPrice", "lineTotal") and converted is not None:
                cell.number_format = "#,##0.00"
            cell.alignment = Alignment(vertical="top", wrap_text=True)
            fill = _cell_fill(key, value)
            if fill:
                cell.fill = fill
        sheet.row_dimensions[row_index].height = 38

    sheet.freeze_panes = "A2"
    sheet.auto_filter.ref = sheet.dimensions
    sheet.row_dimensions[1].height = 34

"""Merge ShipStation Shipments-grid Label Printed data captured by the browser extension.

This module never guesses a ShipStation print time from label creation, Ship Date,
or the Windows print spooler. The displayed text from Shipments -> Label Printed is
preserved exactly and parsed only when the status/time is actually present.
"""

from __future__ import annotations

import re
from datetime import datetime, timezone
from typing import Any

PRINTED_RE = re.compile(r"\bprinted(?=\s|\d|[|·•:]|$)", re.I)
NOT_PRINTED_RE = re.compile(r"\b(?:not\s+printed|unprinted)\b", re.I)
CREATED_RE = re.compile(r"\bcreated\b", re.I)

DATE_TIME_PATTERNS = [
    re.compile(
        r"(?<!\d)\d{1,2}/\d{1,2}/\d{2,4}(?:,)?(?:(?:\s+at)?\s+|:|•|·)\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
    re.compile(
        r"\b(?:Jan(?:uary)?|Feb(?:ruary)?|Mar(?:ch)?|Apr(?:il)?|May|Jun(?:e)?|Jul(?:y)?|Aug(?:ust)?|Sep(?:t(?:ember)?)?|Oct(?:ober)?|Nov(?:ember)?|Dec(?:ember)?)\s+\d{1,2},?\s+\d{4}(?:,)?(?:\s+at)?\s+\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
    re.compile(
        r"\b\d{1,2}\s+(?:Jan(?:uary)?|Feb(?:ruary)?|Mar(?:ch)?|Apr(?:il)?|May|Jun(?:e)?|Jul(?:y)?|Aug(?:ust)?|Sep(?:t(?:ember)?)?|Oct(?:ober)?|Nov(?:ember)?|Dec(?:ember)?)\s+\d{4}(?:,)?(?:\s+at)?\s+\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
]


def clean_text(value: Any) -> str:
    return re.sub(r"\s+", " ", str(value or "")).strip()


def normalize_identifier(value: Any) -> str:
    return re.sub(r"\s+", "", clean_text(value).upper())


def split_values(value: Any) -> list[str]:
    text = clean_text(value)
    if not text:
        return []
    return [part.strip() for part in re.split(r"\s*;\s*|\s*,\s*|[\r\n]+", text) if part.strip()]


def parse_label_print_cell(raw_text: Any) -> dict[str, str]:
    """Interpret only the text/attributes ShipStation exposed in Label Printed."""
    raw = clean_text(raw_text)
    lower = raw.lower()
    if not raw:
        status = "Could not read"
    elif NOT_PRINTED_RE.search(raw):
        status = "Not Printed"
    elif PRINTED_RE.search(raw):
        status = "Printed"
    elif CREATED_RE.search(raw):
        status = "Created - not printed"
    elif lower in {"yes", "true"}:
        status = "Printed"
    elif lower in {"no", "false"}:
        status = "Not Printed"
    else:
        status = "Could not read"

    displayed_time = ""
    for pattern in DATE_TIME_PATTERNS:
        match = pattern.search(raw)
        if match:
            displayed_time = clean_text(match.group(0)).replace(" at ", " ").replace("•", " ").replace("·", " ")
            break

    return {
        "printStatus": status,
        "displayedPrintTime": displayed_time,
        "rawLabelPrinted": raw,
    }


def normalize_capture_rows(rows: Any, captured_at: str | None = None) -> list[dict[str, str]]:
    if not isinstance(rows, list):
        return []
    captured_at = clean_text(captured_at) or datetime.now(timezone.utc).isoformat()
    result = []
    seen = set()
    for raw in rows:
        if not isinstance(raw, dict):
            continue
        shipment = clean_text(raw.get("shipmentNumber"))
        tracking = clean_text(raw.get("tracking"))
        order = clean_text(raw.get("orderNumber"))
        raw_print = clean_text(raw.get("labelPrintedRaw") or raw.get("rawLabelPrinted"))
        if not any((shipment, tracking, order, raw_print)):
            continue
        parsed = parse_label_print_cell(raw_print)
        row = {
            "shipmentNumber": shipment,
            "tracking": tracking,
            "orderNumber": order,
            **parsed,
            "capturedAt": clean_text(raw.get("capturedAt")) or captured_at,
        }
        key = (
            normalize_identifier(shipment),
            normalize_identifier(tracking),
            normalize_identifier(order),
            row["rawLabelPrinted"],
        )
        if key not in seen:
            seen.add(key)
            result.append(row)
    return result


def capture_key(row: dict) -> tuple[str, str, str, str]:
    return (
        normalize_identifier(row.get("shipmentNumber")),
        normalize_identifier(row.get("tracking")),
        normalize_identifier(row.get("orderNumber")),
        clean_text(row.get("rawLabelPrinted")),
    )


def _stable_capture_identity(row: dict) -> tuple[str, str, str]:
    """Package identity that does not change when a later capture reads more cell text."""
    return (
        normalize_identifier(row.get("shipmentNumber")),
        normalize_identifier(row.get("tracking")),
        normalize_identifier(row.get("orderNumber")),
    )


def _capture_quality(row: dict) -> tuple[int, int]:
    raw = clean_text(row.get("rawLabelPrinted"))
    status = clean_text(row.get("printStatus"))
    useful = int(bool(raw)) * 2 + int(status not in {"", "Could not read"}) * 3
    return useful, len(raw)


def merge_capture_store(existing: list[dict], incoming: list[dict]) -> list[dict]:
    """Accumulate pages, replacing an older unreadable capture with a better later read."""
    combined: dict[tuple[str, str, str], dict] = {}
    for row in [*existing, *incoming]:
        if not isinstance(row, dict):
            continue
        identity = _stable_capture_identity(row)
        old = combined.get(identity)
        if old is None or _capture_quality(row) >= _capture_quality(old):
            combined[identity] = dict(row)
    return list(combined.values())


def _unique_candidates(candidates: list[dict]) -> list[dict]:
    seen = set()
    result = []
    for item in candidates:
        key = capture_key(item)
        if key not in seen:
            seen.add(key)
            result.append(item)
    return result


def _package_identity(row: dict) -> tuple[str, str]:
    return (normalize_identifier(row.get("shipmentIds")), normalize_identifier(row.get("tracking")))


def _choose_match(report_row: dict, capture_rows: list[dict], report_rows: list[dict]):
    by_tracking: dict[str, list[dict]] = {}
    by_shipment: dict[str, list[dict]] = {}
    by_order: dict[str, list[dict]] = {}
    for item in capture_rows:
        tracking = normalize_identifier(item.get("tracking"))
        shipment = normalize_identifier(item.get("shipmentNumber"))
        order = normalize_identifier(item.get("orderNumber"))
        if tracking:
            by_tracking.setdefault(tracking, []).append(item)
        if shipment:
            by_shipment.setdefault(shipment, []).append(item)
        if order:
            by_order.setdefault(order, []).append(item)

    # Only one package can inherit one captured print observation.
    report_tracking = {normalize_identifier(v) for v in split_values(report_row.get("tracking"))}
    report_tracking.discard("")
    if len(report_tracking) > 1:
        return None, "Ambiguous tracking match: multiple packages; see Tracking Records"
    if report_tracking:
        unique = _unique_candidates(by_tracking.get(next(iter(report_tracking)), []))
        if len(unique) > 1:
            return None, "Ambiguous tracking match"
        if len(unique) == 1:
            match = unique[0]
            order = normalize_identifier(report_row.get("orderNumber"))
            captured_order = normalize_identifier(match.get("orderNumber"))
            if order and captured_order and order != captured_order:
                return None, "Ambiguous tracking match: order numbers conflict"
            return match, "Tracking #"
        # Never transfer another package's print status based only on the same order.
        return None, "No exact tracking match"

    report_ids = {normalize_identifier(v) for v in split_values(
        report_row.get("shipmentIds") or report_row.get("shipmentId"))}
    report_ids.discard("")
    if len(report_ids) > 1:
        return None, "Ambiguous shipment match"
    candidates = [item for value in report_ids for item in by_shipment.get(value, [])]
    unique = _unique_candidates(candidates)
    if len(unique) == 1:
        match = unique[0]
        order = normalize_identifier(report_row.get("orderNumber"))
        other = normalize_identifier(match.get("orderNumber"))
        if order and other and order != other:
            return None, "Ambiguous shipment match: order numbers conflict"
        return match, "Shipment # (exact)"
    if len(unique) > 1:
        return None, "Ambiguous shipment match"
    order = normalize_identifier(report_row.get("orderNumber"))
    if order and len(_unique_candidates(by_order.get(order, []))) > 1:
        return None, "Ambiguous order match"
    return None, "No exact package match"


def _append_warning(row: dict, message: str) -> None:
    current = [x.strip() for x in str(row.get("warnings") or "").split(";") if x.strip()]
    if message and message not in current:
        current.append(message)
    row["warnings"] = "; ".join(current)


def merge_shipstation_print_capture(report: dict, capture_rows: list[dict]) -> dict:
    """Add ShipStation UI Label Printed state/time without disturbing the old workflow."""
    rows = report.get("rows", [])
    matched = ambiguous = missing = printed_missing_time = printed_missing_tracking = 0
    ui_not_printed = 0

    for row in rows:
        row.update(
            shipstationUiPrintStatus="",
            shipstationDisplayedPrintTime="",
            shipstationLabelPrintedRaw="",
            shipstationUiPrintMatch="",
            shipstationUiCapturedAt="",
        )

        if "shipstation label" not in clean_text(row.get("source")).lower():
            continue

        match, match_type = _choose_match(row, capture_rows, rows)
        row["shipstationUiPrintMatch"] = match_type
        if match is None:
            if "Ambiguous" in match_type:
                ambiguous += 1
                _append_warning(row, "Multiple ShipStation UI rows matched this shipment; print status was not guessed")
            else:
                missing += 1
            continue

        matched += 1
        status = clean_text(match.get("printStatus")) or "Could not read"
        displayed = clean_text(match.get("displayedPrintTime"))
        raw = clean_text(match.get("rawLabelPrinted"))
        row["shipstationUiPrintStatus"] = status
        row["shipstationDisplayedPrintTime"] = displayed
        row["shipstationLabelPrintedRaw"] = raw
        row["shipstationUiCapturedAt"] = clean_text(match.get("capturedAt"))

        # UI capture is the main print check when it is readable. The old CSV remains in the workbook.
        if status == "Printed":
            row["printCheck"] = "PRINTED"
            if not clean_text(row.get("tracking")):
                printed_missing_tracking += 1
                _append_warning(row, "CRITICAL: ShipStation says Printed but tracking number is missing")
            if not displayed:
                printed_missing_time += 1
                _append_warning(row, "ShipStation says Printed but displayed print date/time could not be read")
        elif status in {"Not Printed", "Created - not printed"}:
            row["printCheck"] = "NOT PRINTED"
            ui_not_printed += 1
        else:
            row["printCheck"] = "REVIEW - UI print status unreadable"
            _append_warning(row, "ShipStation Label Printed cell was captured but could not be interpreted")

        csv_status = clean_text(row.get("labelPrinted")).lower()
        if csv_status:
            csv_printed = csv_status == "printed"
            ui_printed = status == "Printed"
            if status != "Could not read" and csv_printed != ui_printed:
                _append_warning(row, "ShipStation CSV and Shipments-grid Label Printed status disagree")

    # Raw shipment/event sheet gets the same package-level capture when possible.
    for event in report.get("events", []):
        event.update(
            shipstationUiPrintStatus="",
            shipstationDisplayedPrintTime="",
            shipstationLabelPrintedRaw="",
            shipstationUiPrintMatch="",
            shipstationUiCapturedAt="",
        )
        match, match_type = _choose_match(event, capture_rows, report.get("events", []))
        event["shipstationUiPrintMatch"] = match_type
        if match:
            event["shipstationUiPrintStatus"] = clean_text(match.get("printStatus")) or "Could not read"
            event["shipstationDisplayedPrintTime"] = clean_text(match.get("displayedPrintTime"))
            event["shipstationLabelPrintedRaw"] = clean_text(match.get("rawLabelPrinted"))
            event["shipstationUiCapturedAt"] = clean_text(match.get("capturedAt"))

    report.update(
        shipstationPrintCapture=list(capture_rows),
        uiPrintCaptureProvided=bool(capture_rows),
        uiPrintCaptureCount=len(capture_rows),
        uiPrintMatchedRows=matched,
        uiPrintAmbiguousRows=ambiguous,
        uiPrintMissingRows=missing,
        uiPrintedMissingTimeCount=printed_missing_time,
        printedMissingTrackingCount=printed_missing_tracking,
        uiNotPrintedRowCount=ui_not_printed,
    )
    return report

"""Parse a user-exported ShipStation shipment-status CSV and merge it into API rows."""

from __future__ import annotations

import csv
import io
import re
from collections import defaultdict

from shipstation import ReportError

EXPECTED_HEADERS = {
    "Shipment #",
    "Order #",
    "Tracking #",
    "Service",
    "Recipient",
    "Ship Date",
    "Packing Slip Printed",
    "Label Created",
    "Label Printed",
    "Marketplace Notified",
    "Shipment Notification",
    "Delivery Notification",
}


def clean(value):
    return "" if value is None else str(value).strip()


def normalize_tracking(value):
    """Return a safe exact identifier or blank when Excel-style scientific notation destroyed it."""
    value = clean(value).replace(" ", "")
    if re.fullmatch(r"[+-]?\d+(?:\.\d+)?[Ee][+-]?\d+", value):
        return ""
    return value.upper()


def split_tracking(value):
    parts = re.split(r"[;,\n\r]+", clean(value))
    return [p.strip().upper() for p in parts if p.strip()]


def parse_print_status_csv(csv_text):
    if not csv_text or not str(csv_text).strip():
        return []
    if len(csv_text.encode("utf-8", errors="ignore")) > 25 * 1024 * 1024:
        raise ReportError("The ShipStation CSV is larger than 25 MB.")

    stream = io.StringIO(csv_text.lstrip("\ufeff"), newline="")
    reader = csv.DictReader(stream)
    if not reader.fieldnames:
        raise ReportError("The ShipStation CSV has no header row.")
    fieldnames = [clean(name).lstrip("\ufeff") for name in reader.fieldnames]
    reader.fieldnames = fieldnames

    minimum = {"Order #", "Tracking #", "Label Created", "Label Printed"}
    missing = sorted(minimum - set(fieldnames))
    if missing:
        raise ReportError(
            "This does not look like the ShipStation Print Status export. Missing column(s): "
            + ", ".join(missing)
        )

    records = []
    for raw in reader:
        if not raw or not any(clean(value) for value in raw.values()):
            continue
        row = {clean(key): clean(value) for key, value in raw.items() if key is not None}
        records.append(
            {
                "shipmentNumber": row.get("Shipment #", ""),
                "orderNumber": row.get("Order #", ""),
                "trackingRaw": row.get("Tracking #", ""),
                "tracking": normalize_tracking(row.get("Tracking #", "")),
                "service": row.get("Service", ""),
                "recipient": row.get("Recipient", ""),
                "shipDate": row.get("Ship Date", ""),
                "packingSlipPrinted": row.get("Packing Slip Printed", ""),
                "labelCreated": row.get("Label Created", ""),
                "labelPrinted": row.get("Label Printed", ""),
                "marketplaceNotified": row.get("Marketplace Notified", ""),
                "shipmentNotification": row.get("Shipment Notification", ""),
                "deliveryNotification": row.get("Delivery Notification", ""),
            }
        )
    return records


def _is_shipstation_label(row):
    return "shipstation label" in clean(row.get("source")).lower()


def _pick_candidate(api_row, by_tracking, by_order, by_order_id):
    # A wider date range can contain several packages for one order.
    tracking_numbers = {normalize_tracking(t) for t in split_tracking(api_row.get("tracking"))}
    tracking_numbers.discard("")
    if len(tracking_numbers) > 1:
        return None, "Ambiguous tracking: multiple packages; see Tracking Records"
    if not tracking_numbers:
        return None, "No exact tracking number"
    candidates = by_tracking.get(next(iter(tracking_numbers)), [])
    unique = {id(item): item for item in candidates}
    if len(unique) > 1:
        return None, "Ambiguous tracking match"
    if len(unique) == 1:
        item = next(iter(unique.values()))
        order = clean(api_row.get("orderNumber"))
        if order and item["orderNumber"] and order != item["orderNumber"]:
            return None, "Ambiguous tracking: order numbers conflict"
        return item, "Tracking #"
    return None, "No exact tracking match"


def merge_print_status(report, records):
    """Attach ShipStation Smart Document Tracking/export fields to report rows/events."""
    by_tracking = defaultdict(list)
    by_order = defaultdict(list)
    by_order_id = defaultdict(list)
    for item in records:
        if item["tracking"]:
            by_tracking[item["tracking"]].append(item)
        if item["orderNumber"]:
            by_order[item["orderNumber"]].append(item)
        if item["shipmentNumber"]:
            by_order_id[item["shipmentNumber"]].append(item)

    matched_record_ids = set()
    matched_rows = 0
    not_printed_rows = 0

    for row in report.get("rows", []):
        row.update(
            labelCreated="",
            labelPrinted="",
            packingSlipPrinted="",
            marketplaceNotified="",
            shipmentNotification="",
            deliveryNotification="",
            printMatch="",
            printCheck="",
            printCsvTracking="",
        )

        if not _is_shipstation_label(row):
            row["printCheck"] = "N/A - Fulfillment / marked shipped"
            continue

        match, match_type = _pick_candidate(row, by_tracking, by_order, by_order_id)
        row["printMatch"] = match_type
        if not match:
            row["printCheck"] = (
                "REVIEW - ambiguous CSV match"
                if "Ambiguous" in match_type
                else "NOT IN SELECTED PRINT STATUS CSV"
            )
            continue

        matched_rows += 1
        matched_record_ids.add(id(match))
        row["labelCreated"] = match["labelCreated"]
        row["labelPrinted"] = match["labelPrinted"]
        row["packingSlipPrinted"] = match["packingSlipPrinted"]
        row["marketplaceNotified"] = match["marketplaceNotified"]
        row["shipmentNotification"] = match["shipmentNotification"]
        row["deliveryNotification"] = match["deliveryNotification"]
        row["printCsvTracking"] = match["trackingRaw"]

        if match["labelPrinted"].strip().lower() == "printed":
            row["printCheck"] = "PRINTED"
        else:
            row["printCheck"] = "NOT PRINTED"
            not_printed_rows += 1

    # Attach print status to raw tracking records too, so the workbook can be audited at shipment level.
    for event in report.get("events", []):
        temp = {
            "tracking": event.get("tracking", ""),
            "orderNumber": event.get("orderNumber", ""),
            "orderId": event.get("orderId", ""),
        }
        match, match_type = _pick_candidate(temp, by_tracking, by_order, by_order_id)
        event["labelCreated"] = match["labelCreated"] if match else ""
        event["labelPrinted"] = match["labelPrinted"] if match else ""
        event["marketplaceNotified"] = match["marketplaceNotified"] if match else ""
        event["printMatch"] = match_type

    report["printStatusRecords"] = records
    report["printCsvProvided"] = True
    report["printCsvRecordCount"] = len(records)
    report["printCsvMatchedRows"] = matched_rows
    report["notPrintedRowCount"] = not_printed_rows
    report["unmatchedPrintCsvCount"] = len(records) - len(matched_record_ids)
    return report


def mark_no_print_csv(report):
    for row in report.get("rows", []):
        row.update(
            labelCreated="",
            labelPrinted="",
            packingSlipPrinted="",
            marketplaceNotified="",
            shipmentNotification="",

            printCheck=(
                "NOT CHECKED - no ShipStation CSV selected"

                else "N/A - Fulfillment / marked shipped"
            ),
        )
    for event in report.get("events", []):

    report.update(

        printCsvRecordCount=0,

function formatTime(seconds) {
  if (seconds === undefined || seconds === null || Number.isNaN(Number(seconds))) return "Calculating";
  seconds = Math.max(0, Math.round(Number(seconds)));
  if (seconds < 60) return `${seconds} sec`;
  return `${Math.floor(seconds / 60)} min ${seconds % 60} sec`;
}

function downloadExcel(base64File, reportDate) {
  const binaryText = window.atob(base64File);
  const fileBytes = new Uint8Array(binaryText.length);
  for (let i = 0; i < binaryText.length; i += 1) fileBytes[i] = binaryText.charCodeAt(i);
  const excelFile = new Blob([fileBytes], {type: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"});
  const link = document.createElement("a");
  link.href = URL.createObjectURL(excelFile);
  link.download = `Shipped_${reportDate}_Checked.xlsx`;
  link.click();
  setTimeout(() => URL.revokeObjectURL(link.href), 1000);
}

async function readReportMessages(response) {
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let unfinished = "";
  let completed = false;
  while (true) {
    const result = await reader.read();
    unfinished += decoder.decode(result.value || new Uint8Array(), {stream: !result.done});
    const lines = unfinished.split("\n");
    unfinished = lines.pop();
    for (const line of lines) {
      if (!line.trim()) continue;
      const message = JSON.parse(line);
      if (message.type === "progress") showProgress(message);
      if (message.type === "error") throw new Error(message.message);
      if (message.type === "complete") {
        completed = true;
        downloadExcel(message.report.fileBase64, message.report.fileRange || message.report.shipDate);
        statusMessage.textContent = "Complete. The combined Excel report has been downloaded.";
        statusMessage.className = "success-message";
        progressBar.style.width = "100%";
        sectionValue.textContent = "Complete";
        pageValue.textContent = "Done";
        timeValue.textContent = "0 sec";
        showSummary(message.report);
      }
    }
    if (result.done) break;
  }
  if (!completed) throw new Error("The connection ended before the report finished. Please run the report again.");
}

"""Read-only ShipStation extraction. Credentials and records are not persisted."""

from __future__ import annotations

import base64
import hashlib
import json
import math
import re
import time
from datetime import date, datetime, timedelta, timezone
from email.utils import parsedate_to_datetime
from urllib.parse import quote

import requests



class ReportError(Exception):
    def __init__(self, message, code="REPORT_ERROR"):
        super().__init__(message)
        self.code = code


""" ----------- 1 - CHECK USER INPUT ----------- """


def parse_credentials(text):
    if not isinstance(text, str) or len(text.encode("utf-8")) > 16384:
        raise ReportError("Choose a TXT file smaller than 16 KB.")
    lines = [
        s.strip()
        for s in text.lstrip("\ufeff").splitlines()
        if s.strip() and not s.strip().startswith("#")
    ]
    aliases = {
        "key": ("API_KEY", "V1_API_KEY", "SHIPSTATION_API_KEY"),
        "secret": ("API_SECRET", "V1_API_SECRET", "SHIPSTATION_API_SECRET"),
        "v2": ("V2_API_KEY", "SHIPSTATION_V2_API_KEY"),
    }
    allowed = {name for names in aliases.values() for name in names}
    fields = {}
    for line in lines:
        match = re.fullmatch(r"([a-zA-Z][a-zA-Z0-9_ -]*)\s*[:=]\s*(.+)", line)
        if not match:
            continue
        name = re.sub(r"[ -]", "_", match[1].strip().upper())
        if name not in allowed:
            continue
        if name in fields:
            raise ReportError("The TXT file repeats a credential field.")
        fields[name] = match[2].strip().strip("\"'")
    values = {}
    for group, names in aliases.items():
        found = [fields[name] for name in names if name in fields]
        if len(found) > 1:
            raise ReportError("Keep only one key and its matching secret in the file.")
        values[group] = found[0] if found else ""
    key, secret, v2 = (values[k] for k in ("key", "secret", "v2"))
    if v2 and (key or secret):
        raise ReportError("Use V1 key + secret OR one V2 key, not both.")
    if secret and not key or "V1_API_KEY" in fields and not secret:
        raise ReportError("V1 requires both API_KEY and API_SECRET.")
    value = v2 or key or (lines[0] if len(lines) == 1 and not fields else "")
    if not value:
        raise ReportError(
            "No API key found. Use one V2 key, or API_KEY and API_SECRET on separate lines."
        )
    for part in (value, secret):
        if part and (
            not re.fullmatch(r"[\x21-\x7e]{8,512}", part)
            or re.search(r"YOUR_|PASTE_|REPLACE_|HERE", part, re.I)
        ):
            raise ReportError(
                "Replace the example text with real credentials. Keys cannot contain spaces."
            )
    return {"version": "v1" if secret else "v2", "key": value, "secret": secret}


def parse_ship_date(value):
    value = str(value).strip()
    if re.fullmatch(r"\d{4}-\d{2}-\d{2}", value):
        try:
            value = date.fromisoformat(value).strftime("%m/%d/%Y")
        except ValueError:
            raise ReportError("Enter a real calendar date between 2000 and 2099.") from None
    if not re.fullmatch(r"\d{2}/\d{2}/\d{4}", value):
        raise ReportError("Enter Ship Date as MM/DD/YYYY, for example 08/27/2026.")
    try:
        result = datetime.strptime(value, "%m/%d/%Y").date()
        if not 2000 <= result.year <= 2099:
            raise ValueError()
    except ValueError:
        raise ReportError("Enter a real calendar date between 2000 and 2099.") from None
    return {
        "display": value,
        "iso": result.isoformat(),
        "next": (result + timedelta(days=1)).isoformat(),
    }


def parse_ship_date_range(start_value, end_value=None):
    """Inclusive calendar dates. The query's upper bound is the next midnight."""
    start = parse_ship_date(start_value)
    end = parse_ship_date(end_value if end_value not in (None, "") else start_value)
    if end["iso"] < start["iso"]:
        raise ReportError("Through date must be the same as or later than From date.")
    days = (date.fromisoformat(end["iso"]) - date.fromisoformat(start["iso"])).days + 1
    single = start["iso"] == end["iso"]
    return {
        "iso": start["iso"], "end": end["iso"], "next": end["next"],
        "startDisplay": start["display"], "endDisplay": end["display"], "days": days,
        "display": start["display"] if single else start["display"] + " through " + end["display"],
        "fileRange": start["iso"] if single else start["iso"] + "_to_" + end["iso"],
    }


def ship_date_in_range(value, selected):
    calendar = calendar_date(value)
    return bool(calendar and selected["iso"] <= calendar <= selected.get("end", selected["iso"]))


def calendar_date(value):
    if isinstance(value, str) and re.match(r"^\d{4}-\d{2}-\d{2}", value):
        try:
            return date.fromisoformat(value[:10]).isoformat()
        except ValueError:
            pass
    return ""


def as_id(value):
    return "" if value is None else str(value)


def number_or_none(value):
    if value is None or value == "" or isinstance(value, bool):
        return None
    try:
        number = float(value)
        return number if math.isfinite(number) else None
    except (ValueError, TypeError):
        return None


def joined(values):
    return "; ".join(dict.fromkeys(str(v) for v in values if v is not None and v != ""))


""" ----------- 2 - CONNECT TO SHIPSTATION ----------- """


class ShipStationAPI:
    def __init__(
        self,
        credentials,
        progress=lambda message: None,
        session=None,
        interval=None,
        sleep=time.sleep,
    ):
        self.version = credentials["version"]
        self.base = (
            "https://ssapi.shipstation.com"
            if self.version == "v1"
            else "https://api.shipstation.com/v2"
        )
        self.headers = {"Accept": "application/json"}
        if self.version == "v1":
            pair = (credentials["key"] + ":" + credentials["secret"]).encode("ascii")
            self.headers["Authorization"] = "Basic " + base64.b64encode(pair).decode("ascii")
        else:
            self.headers["api-key"] = credentials["key"]
        self.session = session if session is not None else requests.Session()
        self.interval = (
            interval if interval is not None else (1.6 if self.version == "v1" else 0.35)
        )
        self.progress, self.sleep, self.next_allowed = progress, sleep, 0

    def get(self, path, **params):
        if not re.fullmatch(r"/(orders|shipments|fulfillments|labels|stores)(/[^/?#]+)?", path):
            raise ReportError("Unsupported API resource.")
        for attempt in range(4):
            if self.next_allowed > time.monotonic():
                self.sleep(self.next_allowed - time.monotonic())
            try:
                # Explicit auth prevents an unrelated .netrc login overriding the uploaded key.
                response = self.session.get(
                    self.base + path,
                    params=params,
                    headers=self.headers,
                    timeout=(10, 45),
                    allow_redirects=False,
                    auth=lambda request: request,
                )
            except requests.RequestException:
                if attempt == 3:
                    raise ReportError(
                        "Cannot reach ShipStation. Check your internet connection and try again.",
                        "NETWORK",
                    ) from None
                self.sleep(2**attempt)
                continue
            finally:
                self.next_allowed = time.monotonic() + self.interval
            status = response.status_code
            if status == 401:
                raise ReportError(
                    "ShipStation rejected the credentials. Check API version, key and V1 secret.",
                    "AUTH",
                )
            if status in (402, 403):
                raise ReportError(
                    "Your ShipStation account or key cannot access this API. Check plan and permissions.",
                    "ACCESS",
                )
            if status == 429 or status >= 500:
                if attempt == 3:
                    raise ReportError(
                        "ShipStation is busy or rate-limiting requests. Retry later; no partial file was created.",
                        "RETRY_LIMIT",
                    )
                retry = response.headers.get("Retry-After") or response.headers.get(
                    "X-Rate-Limit-Reset"
                )
                try:
                    seconds = float(retry) if retry is not None else 2**attempt
                except ValueError:
                    try:
                        seconds = max(0, parsedate_to_datetime(retry).timestamp() - time.time())
                    except (ValueError, TypeError, OverflowError):
                        seconds = 2**attempt
                if not math.isfinite(seconds):
                    seconds = 2**attempt
                if seconds > 300:
                    raise ReportError(
                        "ShipStation requested a long pause. Please retry in a few minutes.",
                        "RATE_LIMIT",
                    )
                self.progress("ShipStation requested a pause; retrying safely...")
                self.sleep(max(1, seconds + 0.2))
                continue
            if not 200 <= status < 300:
                raise ReportError(
                    f"ShipStation returned HTTP {status} for {path.split('/')[1]}. No partial file was created.",
                    f"HTTP_{status}",
                )
            try:
                data = response.json()
            except ValueError:
                raise ReportError(
                    "ShipStation returned an unexpected response instead of JSON.", "BAD_RESPONSE"
                ) from None
            if response.headers.get("X-Rate-Limit-Remaining") == "0":
                reset = number_or_none(response.headers.get("X-Rate-Limit-Reset")) or 60
                if reset > 300:
                    raise ReportError(
                        "ShipStation requested a long pause. Please retry later.", "RATE_LIMIT"
                    )
                self.next_allowed = time.monotonic() + max(0, reset)
            return data
        raise ReportError("ShipStation requests could not be completed.")

    def get_pages(self, path, key, **params):
        size = 500 if self.version == "v1" else 100
        size_key = "pageSize" if self.version == "v1" else "page_size"
        seen, received = set(), 0
        section_started = time.monotonic()
        for page in range(1, 1001):
            self.progress(f"Reading {key}: page {page}...")
            result = self.get(path, **params, page=page, **{size_key: size})
            rows = result.get(key) if isinstance(result, dict) else None
            if not isinstance(rows, list) or any(not isinstance(row, dict) for row in rows):
                raise ReportError(
                    f"ShipStation did not return the expected {key} list.", "BAD_RESPONSE"
                )
            pages, total = number_or_none(result.get("pages")), number_or_none(result.get("total"))
            if not rows:
                if total is not None and total > received or pages is not None and pages > page:
                    raise ReportError(
                        "An API page is missing. Please rerun; no partial file was created.",
                        "PAGINATION",
                    )
                return
            total_pages = (
                int(pages)
                if pages is not None and pages > 0
                else (max(1, math.ceil(total / size)) if total is not None and total > 0 else None)
            )
            if total_pages:
                average = max(self.interval + 0.25, (time.monotonic() - section_started) / page)
                self.progress(
                    {
                        "message": f"Reading {key}: page {page} of {total_pages}...",
                        "section": key.replace("_", " ").title(),
                        "currentPage": page,
                        "totalPages": total_pages,
                        "estimatedSeconds": math.ceil(max(0, total_pages - page) * average),
                    }
                )
            signature = hashlib.sha256(json.dumps(rows, sort_keys=True).encode()).digest()
            if signature in seen:
                raise ReportError(
                    "ShipStation repeated a page. Stopping to avoid incomplete or duplicate data.",
                    "PAGINATION",
                )
            seen.add(signature)
            received += len(rows)
            yield rows
            if pages is not None and pages > 0:
                if page >= pages:
                    return
            elif total is not None:
                if received >= total:
                    return
            elif len(rows) < size:
                return
        raise ReportError(
            "The 1,000-page safety limit was reached. No partial file was created.", "PAGINATION"
        )


""" ----------- 3 - CREATE THE EXCEL ROWS ----------- """


def make_tracking_record(record, source, version):
    v1 = version == "v1"
    return {
        "recordId": as_id(
            record.get("fulfillmentId", record.get("shipmentId"))
            if v1
            else record.get("fulfillment_id", record.get("label_id"))
        ),
        "shipmentId": as_id(record.get("shipmentId") if v1 else record.get("shipment_id")),
        "orderId": as_id(record.get("orderId") if v1 else record.get("external_order_id")),
        "orderNumber": as_id(
            record.get("orderNumber")
            if v1
            else record.get("shipment_number") or record.get("external_order_id")
        ),
        "shipDate": calendar_date(record.get("shipDate") if v1 else record.get("ship_date")),
        "tracking": joined(
            [record.get("trackingNumber") if v1 else record.get("tracking_number")]
            + [
                p.get("tracking_number") or p.get("trackingNumber")
                for p in record.get("packages") or []
            ]
        ),
        "carrier": (
            record.get("carrierCode")
            if v1
            else record.get("fulfillment_carrier_friendly_name")
            or record.get("carrier_code")
            or record.get("carrier_id")
        )
        or "",
        "service": (
            record.get("serviceCode") or record.get("fulfillmentServiceCode")
            if v1
            else record.get("fulfillment_service_code") or record.get("service_code")
        )
        or "",
        "provider": (
            record.get("sellerFillProviderName") or record.get("fulfillmentProviderCode")
            if v1
            else record.get("fulfillment_provider_friendly_name")
            or record.get("fulfillment_provider_code")
        )
        or "",
        "recipient": (record.get("shipTo" if v1 else "ship_to") or {}).get("name", ""),
        "source": source,
    }


def make_item_row(
    order_number, order_id, order_date, item, store, recipient, events, quantity_basis, warnings=()
):
    item = item or {}
    quantity, price = number_or_none(item.get("quantity")), number_or_none(
        item.get("unitPrice", item.get("unit_price"))
    )
    row = {
        "orderNumber": as_id(order_number),
        "orderId": as_id(order_id),
        "orderDate": order_date,
        "itemId": as_id(
            item.get(
                "orderItemId", item.get("sales_order_item_id", item.get("external_order_item_id"))
            )
        ),
        "itemName": item.get("name") or "",
        "sku": item.get("sku") or "",
        "quantity": quantity,
        "unitPrice": price,
        "lineTotal": quantity * price if quantity is not None and price is not None else None,
        "quantityBasis": quantity_basis,
        "store": store or "",
        "recipient": recipient or "",
        "shipDate": joined(sorted({e.get("shipDate", "") for e in events if e.get("shipDate")})),
    }
    for field, event_field in {
        "tracking": "tracking",
        "carrier": "carrier",
        "service": "service",
        "fulfillmentProvider": "provider",
        "shipmentIds": "shipmentId",
        "recordIds": "recordId",
        "source": "source",
    }.items():
        row[field] = joined(e.get(event_field) for e in events)
    notes = list(warnings)
    for key, label in (
        ("tracking", "Tracking"),
        ("sku", "SKU"),
        ("itemName", "Item name"),
        ("orderDate", "Order date"),
    ):
        if not row[key]:
            notes.append(label + " unavailable")
    if quantity is None:
        notes.append("Quantity unavailable")
    row["warnings"] = joined(notes)
    return row


""" ----------- 4 - GET A VERSION 1 REPORT ----------- """


def get_v1_report(shipstation_api, day):
    events, rows, issues, by_order, seen = [], [], [], {}, set()
    params = {"shipDateStart": day["iso"] + " 00:00:00", "shipDateEnd": day["next"] + " 00:00:00"}
    for key, source in (
        ("fulfillments", "Fulfillment / marked shipped"),
        ("shipments", "ShipStation label"),
    ):
        extra = {"includeShipmentItems": "true"} if key == "shipments" else {}
        for page in shipstation_api.get_pages("/" + key, key, **params, **extra):
            for record in page:
                if (
                    record.get("voided")
                    or record.get("voidDate")
                    or record.get("isReturnLabel")
                    or not ship_date_in_range(record.get("shipDate"), day)
                ):
                    continue
                event = make_tracking_record(record, source, "v1")
                identity = source, event["recordId"]
                if event["recordId"] and identity in seen:
                    continue
                seen.add(identity)
                events.append(event)
                if event["orderId"]:
                    by_order.setdefault(event["orderId"], []).append(event)
    stores = {}
    try:
        result = shipstation_api.get("/stores")
        if isinstance(result, list):
            stores = {as_id(s.get("storeId")): s.get("storeName") for s in result}
    except ReportError as error:
        if error.code in ("AUTH", "ACCESS"):
            raise
        issues.append("Store names unavailable; Store ID is preserved instead.")
    found = set()

    def add_order(order, matched, notes=()):
        identity = as_id(order.get("orderId"))
        if identity and identity in found:
            return
        if identity:
            found.add(identity)
        notes = list(notes)
        if not matched:
            notes.append("No matching shipment/fulfillment record in the selected range")
        if not identity:
            notes.append("Order ID unavailable; tracking cannot be matched safely")
        if len(matched) > 1:
            notes.append(
                "Multiple shipment records: tracking is order-level, not item-to-package allocation"
            )
        selected = matched or [{"shipDate": calendar_date(order.get("shipDate")), "source": "Shipped order only"}]
        items = [i for i in order.get("items") or [] if not i.get("adjustment")]
        store_id = as_id((order.get("advancedOptions") or {}).get("storeId"))
        for item in items or [None]:
            rows.append(
                make_item_row(
                    order.get("orderNumber"),
                    identity,
                    calendar_date(order.get("orderDate")),
                    item,
                    stores.get(store_id) or store_id,
                    (order.get("shipTo") or {}).get("name"),
                    selected,
                    "Order item quantity",
                    notes,
                )
            )

    is_today = day["iso"] == day.get("end", day["iso"]) == date.today().isoformat()
    if is_today:
        order_ids = sorted(by_order)
        shipstation_api.progress(
            f"Today's date selected: reading only {len(order_ids)} linked order(s)..."
        )
        details_started = time.monotonic()
        for index, identity in enumerate(order_ids, 1):
            matched = by_order[identity]
            try:
                order = shipstation_api.get("/orders/" + quote(identity, safe=""))
                if not isinstance(order, dict):
                    raise ReportError("Unexpected order detail response.", "BAD_RESPONSE")
                status = order.get("orderStatus")
                notes = (
                    []
                    if status == "shipped"
                    else [
                        f"Current order status is {status or 'unavailable'}; daily shipment retained"
                    ]
                )
                add_order(order, matched, notes)
            except ReportError as error:
                if error.code != "HTTP_404":
                    raise
                found.add(identity)
                first = matched[0]
                rows.append(
                    make_item_row(
                        first["orderNumber"],
                        identity,
                        "",
                        None,
                        "",
                        first["recipient"],
                        matched,
                        "Order item quantity",
                        ["Order detail not found; tracking record retained"],
                    )
                )
            average = max(
                shipstation_api.interval + 0.25, (time.monotonic() - details_started) / index
            )
            shipstation_api.progress(
                {
                    "message": f"Reading today's order details: order {index} of {len(order_ids)}...",
                    "section": "Today's order details",
                    "currentPage": index,
                    "totalPages": len(order_ids),
                    "estimatedSeconds": math.ceil(max(0, len(order_ids) - index) * average),
                }
            )
    else:
        shipstation_api.progress(
            "Checking Shipped order history once for the selected Ship Date range..."
        )
        for page in shipstation_api.get_pages("/orders", "orders", orderStatus="shipped"):
            for order in page:
                identity = as_id(order.get("orderId"))
                if identity in found or order.get("orderStatus") != "shipped":
                    continue
                matched = by_order.get(identity, []) if identity else []
                if not matched and not ship_date_in_range(order.get("shipDate"), day):
                    continue
                add_order(order, matched)
    for event in events:
        if event["orderId"] not in found:
            issues.append(
                f"Shipment record {event['recordId'] or '(no ID)'} is not linked to a currently Shipped order. Retained on Tracking Records."
            )
    strategy = (
        "Today's linked orders + Shipments + Fulfillments"
        if is_today
        else "Full Shipped Orders history + Shipments + Fulfillments"
    )
    return {
        "rows": rows,
        "events": events,
        "issues": issues,
        "coverage": strategy,
        "quantityNote": "Quantity is ORDER LINE quantity, not proof all units shipped in this range. Each order is listed once across the range. Split orders may span dates. Tracking is linked at order level; package allocation is not inferred.",
    }


""" ----------- 5 - GET A VERSION 2 REPORT ----------- """


def get_v2_report(shipstation_api, day):
    events, rows = [], []
    for page in shipstation_api.get_pages(
        "/fulfillments",
        "fulfillments",
        ship_date_start=day["iso"] + "T00:00:00Z",
        ship_date_end=day["next"] + "T00:00:00Z",
    ):
        for record in page:
            if (
                not record.get("voided")
                and not record.get("voided_at")
                and ship_date_in_range(record.get("ship_date"), day)
            ):
                events.append(make_tracking_record(record, "Fulfillment / marked shipped", "v2"))
    # V2 labels do not have a ship-date filter. Do not restrict label creation date.
    shipstation_api.progress("Checking completed labels by Ship Date, not label creation date...")
    for page in shipstation_api.get_pages("/labels", "labels", label_status="completed"):
        for record in page:
            if (
                not record.get("voided")
                and not record.get("voided_at")
                and not record.get("is_return_label")
                and record.get("status", "completed") == "completed"
                and ship_date_in_range(record.get("ship_date"), day)
            ):
                events.append(make_tracking_record(record, "ShipStation label", "v2"))
    events = list({(e["source"], e["recordId"] or i): e for i, e in enumerate(events)}.values())
    groups = {}
    for i, event in enumerate(events):
        groups.setdefault(event["shipmentId"] or f"unmatched:{i}", []).append(event)
    details_started = time.monotonic()
    for index, (identity, group) in enumerate(groups.items(), 1):
        shipstation_api.progress(f"Reading item details: shipment {index} of {len(groups)}...")
        shipment, notes = {}, []
        if identity.startswith("unmatched:"):
            notes.append("Shipment ID unavailable; record preserved")
        else:
            try:
                shipment = shipstation_api.get("/shipments/" + quote(identity, safe=""))
                if not isinstance(shipment, dict):
                    raise ReportError("Unexpected shipment detail response.", "BAD_RESPONSE")
            except ReportError as error:
                if error.code != "HTTP_404":
                    raise
                notes.append("Shipment detail not found; record preserved")
        average = max(shipstation_api.interval + 0.25, (time.monotonic() - details_started) / index)
        shipstation_api.progress(
            {
                "message": f"Reading item details: shipment {index} of {len(groups)}...",
                "section": "Shipment details",
                "currentPage": index,
                "totalPages": len(groups),
                "estimatedSeconds": math.ceil(max(0, len(groups) - index) * average),
            }
        )
        if len(group) > 1:
            notes.append("Multiple tracking records; item-to-package allocation is not inferred")
        for item in shipment.get("items") or [{}]:
            rows.append(
                make_item_row(
                    item.get("external_order_id")
                    or shipment.get("shipment_number")
                    or group[0]["orderNumber"],
                    item.get("sales_order_id")
                    or shipment.get("external_order_id")
                    or group[0]["orderId"],
                    "",
                    item,
                    shipment.get("order_source_code"),
                    (shipment.get("ship_to") or {}).get("name") or group[0]["recipient"],
                    group,
                    "Shipment item quantity",
                    notes,
                )
            )
    return {
        "rows": rows,
        "events": events,
        "issues": [
            "V2 does not provide the original Order Date here or exact Shipped-status order reconciliation. Use a V1 key + secret for the fuller order-based report."
        ],
        "coverage": "V2 Fulfillments + completed Labels + Shipment items (limited order metadata)",
        "quantityNote": "Quantity is SHIPMENT ITEM quantity. Labels for the same shipment are grouped so items are not multiplied by package count. Order Date is blank; shipment creation date is not substituted.",
    }


""" ----------- 6 - RUN THE COMPLETE REPORT ----------- """


def extract_report(
    credentials_text,
    ship_date,
    progress=lambda message: None,
    ship_date_end=None,
    **client_options,
):
    """Build the read-only ShipStation shipment report.

    Print-status CSV matching and carrier checks are added later by their own modules so
    the API extraction stays independent and easy to test.
    """
    credentials, day = parse_credentials(credentials_text), parse_ship_date_range(ship_date, ship_date_end)
    shipstation_api = ShipStationAPI(credentials, progress, **client_options)
    try:
        progress(
            "Credentials recognized as "
            + credentials["version"].upper()
            + ". Extracting Ship Dates " + day["display"] + " (inclusive)..."
        )
        if credentials["version"] == "v1":
            report = get_v1_report(shipstation_api, day)
        else:
            report = get_v2_report(shipstation_api, day)
    finally:
        shipstation_api.session.close()
        shipstation_api.headers.clear()
        credentials.clear()

    version = shipstation_api.version
    report["rows"].sort(key=lambda r: (r["orderNumber"], r["sku"]))

    def group_key(row):
        return (
            row["orderId"]
            if version == "v1" and row["orderId"]
            else row["shipmentIds"] or row["recordIds"] or row["orderNumber"]
        )

    report.update(
        version=version,
        shipDate=day["iso"],
        shipDateStart=day["iso"],
        shipDateEnd=day["end"],
        rangeDays=day["days"],
        fileRange=day["fileRange"],
        displayDate=day["display"],
        generatedAt=datetime.now(timezone.utc).isoformat(),
        rowCount=len(report["rows"]),
        recordCount=len({group_key(row) for row in report["rows"]}),
        missingTrackingCount=len({group_key(row) for row in report["rows"] if not row["tracking"]}),
    )
    return report

KEY_B = "API_KEY=synthetic-key-2222\nAPI_SECRET=synthetic-secret-2222"


class CredentialFileTests(unittest.TestCase):
    def setUp(self):
        self.temp = tempfile.TemporaryDirectory()
        self.addCleanup(self.temp.cleanup)
        self.root = Path(self.temp.name)
        self.app = self.root / "Extracted Program"
        self.app.mkdir()
        self.settings = self.root / "settings" / "api_key_location.json"
        self.source = CredentialSource(self.app, self.settings)

    def key(self, name="API key.txt", text=KEY_A, parent=None, encoding="utf-8"):
        path = (parent or self.app) / name
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding=encoding)
        return path

    def test_automatic_folder_is_program_folder_not_working_directory(self):
        expected = self.key()
        other = self.root / "Other Folder"
        self.key(text=KEY_B, parent=other)
        before = Path.cwd()
        try:
            os.chdir(other)
            text, metadata = self.source.load()
        finally:
            os.chdir(before)
        self.assertEqual(text, KEY_A)
        self.assertEqual(metadata["path"], str(expected))
        self.assertFalse(self.settings.exists())

    def test_printed_missing_displayed_time_is_flagged(self):
        report = self._base_report()
        capture = normalize_capture_rows([{
            "shipmentNumber": "7001",
            "orderNumber": "ORDER-1",
            "tracking": "1Z1234567890123456",
            "labelPrintedRaw": "Printed",
        }])
        merge_shipstation_print_capture(report, capture)

        self.assertIn("displayed print date/time could not be read", report["rows"][0]["warnings"])

    def test_multi_package_order_does_not_use_order_number(self):
        report = {
            "rows": [
                {"orderNumber": "ORDER-X", "orderId": "1", "tracking": "", "shipmentIds": "A", "source": "ShipStation label", "warnings": "", "printCheck": "", "labelPrinted": ""},
                {"orderNumber": "ORDER-X", "orderId": "1", "tracking": "", "shipmentIds": "B", "source": "ShipStation label", "warnings": "", "printCheck": "", "labelPrinted": ""},
            ],
            "events": [],
        }
        capture = normalize_capture_rows([
            {"shipmentNumber": "UI-A", "orderNumber": "ORDER-X", "tracking": "", "labelPrintedRaw": "Printed | 09/29/2026 9:00 AM"},
            {"shipmentNumber": "UI-B", "orderNumber": "ORDER-X", "tracking": "", "labelPrintedRaw": "Printed | 09/29/2026 9:05 AM"},
        ])
        merge_shipstation_print_capture(report, capture)
        self.assertTrue(all(row["shipstationUiPrintStatus"] == "" for row in report["rows"]))
        self.assertEqual(report["uiPrintAmbiguousRows"], 2)

    def test_capture_store_accumulates_unique_pages(self):
        first = normalize_capture_rows([{"orderNumber": "A", "tracking": "T1", "labelPrintedRaw": "Printed"}])
        second = normalize_capture_rows([
            {"orderNumber": "A", "tracking": "T1", "labelPrintedRaw": "Printed"},
            {"orderNumber": "B", "tracking": "T2", "labelPrintedRaw": "Created"},
        ])
        merged = merge_capture_store(first, second)
        self.assertEqual(len(merged), 2)

    def test_later_readable_capture_replaces_old_unreadable_capture(self):
        first = normalize_capture_rows([{
            "shipmentNumber": "7001",
            "orderNumber": "ORDER-1",
            "tracking": "1Z1234567890123456",
            "labelPrintedRaw": "",
        }])
        second = normalize_capture_rows([{
            "shipmentNumber": "7001",
            "orderNumber": "ORDER-1",
            "tracking": "1Z1234567890123456",
            "labelPrintedRaw": "Printed 09/17/2026:11:36",
        }])
        merged = merge_capture_store(first, second)
        self.assertEqual(len(merged), 1)
        self.assertEqual(merged[0]["printStatus"], "Printed")
        self.assertEqual(merged[0]["displayedPrintTime"], "09/17/2026:11:36")
