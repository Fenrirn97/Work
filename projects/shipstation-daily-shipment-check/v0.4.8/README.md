# ShipStation Daily Shipment Check v0.4.8 — Auto API Key

[Download the Windows ZIP](https://raw.githubusercontent.com/Fenrirn97/Work/main/projects/shipstation-daily-shipment-check/v0.4.8/ShipStation_Daily_Shipment_Check_v0.4.8_Auto_API_Key_Windows.zip)

Put your existing API text file beside `START.cmd` and name it `API key.txt` (or `API key` without an extension). The program loads it automatically. Alternatively, enter its file or folder path under **Use a different location or choose a file**. The selected location is remembered on this PC; only the path is saved.

This release retains inclusive From / Through Ship Date ranges and the normal-browser v0.4.9 print-time capture extension. Windows 10/11 and Python 3.11 or newer are required.
