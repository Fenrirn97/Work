SHIPSTATION DAILY SHIPMENT CHECK — WINDOWS — VERSION 0.5.1

PURPOSE

The main purpose of this version is to capture the exact status shown by ShipStation
under Shipments -> Label Printed, including the displayed print date/time when
ShipStation exposes it in the grid or its tooltip.

The program does NOT substitute:
- label creation time,
- Ship Date,
- carrier pickup time, or
- Windows spooler time
for ShipStation's own Label Printed field.

WHAT VERSION 0.5.1 ADDS

- Fixes the dedicated Edge window opening at about:blank by explicitly navigating to the current ShipStation login page and verifying navigation succeeded.
- Enables the Chromium sandbox so Edge no longer launches with Playwright's --no-sandbox warning on supported Windows systems.

1. Opens ShipStation in a dedicated Microsoft Edge profile controlled by Playwright.
2. Keeps that dedicated ShipStation login session between runs.
3. Reads the current filtered Shipments grid.
4. Looks for the Shipment #, Tracking #, Order #, and Label Printed columns.
5. Preserves the original Label Printed cell text.
6. Separates:
   - ShipStation Label Printed status
   - ShipStation Displayed Print Date / Time
   - capture time (when this program read the page)
7. Attempts to read a visible tooltip when the cell says Printed but the date/time is
   not already in the cell text.
8. Scrolls virtualized grids and follows a visible Next Page control when available.
9. Treats an unreadable cell as "Could not read". It never converts missing data into
   "Not Printed".
10. Flags:
   - Printed but tracking number missing
   - Printed but displayed print date/time missing/unreadable
   - ambiguous package matches
11. Matches the ShipStation UI row to the API report by:
   a. Shipment # when the identifiers agree,
   b. Tracking #,
   c. Order # only when both sides prove there is exactly one shipment/package.
12. Keeps the existing Windows PrintService Event 307 check as SECONDARY evidence.

IMPORTANT SHIPSTATION BEHAVIOR

ShipStation Smart Document Tracking marks a label Printed when the label is downloaded
or printed through ShipStation Connect. ShipStation documentation says browser printing
does not update Smart Document Tracking.

Because the live account still needs to validate reprint behavior, this program calls
the value "ShipStation Displayed Print Time". It does not assume the time is the first
print, last print, or physical-printer completion time.

START ON WINDOWS

1. Extract the ZIP to a normal folder. A short folder such as C:\ShipStationCheck is
   recommended, but this version no longer places the Python virtual environment inside
   the extracted folder.
2. Double-click START.cmd.
3. The first run installs the Python packages if needed. Internet is required for that
   first setup.
4. The program uses Microsoft Edge already installed on Windows. It does NOT download a
   separate Playwright browser.
5. Your normal browser opens the local control page at http://127.0.0.1:8787.

WHY THE PLAYWRIGHT PATH IS DIFFERENT

Earlier Playwright installation failed with Windows WinError 206 because the project was
inside a deeply nested folder and the .venv was created inside that folder.

This version creates the virtual environment at:

%LOCALAPPDATA%\ShipStationDailyCheck\venv

and the dedicated Edge profile at:

%LOCALAPPDATA%\ShipStationDailyCheck\EdgeProfile

This keeps Playwright's files in a short path.

HOW TO READ LABEL PRINTED STATUS

1. In the local program click "Open ShipStation".
2. A dedicated Edge window opens.
3. Sign in to ShipStation if required.
4. In ShipStation go to Shipments -> Shipments.
5. Apply the exact date/filter you want the program to read.
6. Use ShipStation's Columns control and make sure these are visible:
   - Shipment #
   - Tracking #
   - Label Printed
   Order # is strongly recommended as an additional identity field.
7. Return to the local program.
8. Click "Read Shipments Grid".
9. Review the counts for:
   - Rows read
   - Printed
   - Printed / time missing
   - Printed / tracking missing
   - Unreadable cells
   - Pages read
10. Click "Download Print Status Excel" if you want the browser-capture-only workbook.

SAFETY / COMPLETENESS RULES

- The ShipStation UI reader is read-only. It does not click Print, create labels, void
  labels, change shipment data, or change filters.
- It only clicks a recognized Next Page pagination control while reading.
- It does not rely on Order # alone for split/multi-package orders.
- If the page structure cannot be recognized, the run stops and tells you which columns
  need to be visible. It does not create a false "Not Printed" result.
- The exact ShipStation page structure can change. The first live run against your
  account is required validation for this version.

FIRST LIVE VALIDATION

Use a small known set first, for example 5-10 shipments where you already know:
- which ones are Printed,
- the date/time ShipStation displays,
- the tracking number,
- at least one unprinted/created label if possible.

Compare the downloaded ShipStation Print Status workbook against the Shipments screen.
Do not rely on this version for the whole operation until those rows match correctly.

REPRINT VALIDATION

We still need to establish what ShipStation does to the displayed timestamp when a label
is reprinted. Test one known shipment by recording the displayed value, reprinting it in
the normal ShipStation workflow, then reading the grid again. Until that is confirmed,
the program deliberately preserves the displayed value without calling it first-print or
last-print time.

"""Local Python web app. Run with START.cmd or python app.py."""

from __future__ import annotations

import argparse
import atexit
import base64
import json
import mimetypes
import os
from pathlib import Path
import threading
import webbrowser
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import unquote, urlsplit

from excel_export import build_excel, build_print_capture_excel
from shipstation import ReportError, extract_report, parse_credentials, parse_ship_date
from shipstation_ui import ShipStationBrowserManager, merge_shipstation_capture

ROOT = Path(__file__).resolve().parent
BROWSER_SECURITY_HEADERS = {
    "Cache-Control": "no-store",
    "X-Content-Type-Options": "nosniff",
    "Referrer-Policy": "no-referrer",
    "X-Frame-Options": "DENY",
    "Content-Security-Policy": "default-src 'self'; connect-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'",
}


""" ----------- 1 - START THE LOCAL WEBSITE ----------- """


def make_server(port=8787, root=None, extractor=extract_report):
    public_folder = Path(root or ROOT / "public").resolve()
    export_lock = threading.Lock()
    shipstation_browser = ShipStationBrowserManager()
    latest_capture = {"data": None}
    atexit.register(shipstation_browser.close)

    class BrowserRequestHandler(BaseHTTPRequestHandler):
        # Silence default URL logging and keep credentials/customer data out of logs.
        def log_message(self, format, *args):
            pass

        @property
        def origin(self):
            return f"http://127.0.0.1:{self.server.server_port}"

        def headers_ok(self):
            return self.headers.get("Host") == urlsplit(self.origin).netloc

        def reply(self, status, content, content_type="application/json"):
            if isinstance(content, dict):
                content = json.dumps(content).encode()
            self.send_response(status)
            for key, value in BROWSER_SECURITY_HEADERS.items():
                self.send_header(key, value)
            self.send_header("Content-Type", content_type)
            self.send_header("Content-Length", str(len(content)))
            self.end_headers()
            if self.command != "HEAD":
                self.wfile.write(content)

        def do_GET(self):
            if not self.headers_ok():
                self.reply(403, {"error": "Open the displayed 127.0.0.1 address."})
                return
            path = unquote(urlsplit(self.path).path)
            requested_file = (
                public_folder / ("local/index.html" if path == "/" else path.lstrip("/"))
            ).resolve()
            if not requested_file.is_relative_to(public_folder) or not requested_file.is_file():
                self.reply(404, {"error": "Not found."})
                return
            content_type = {
                ".js": "text/javascript",
                ".css": "text/css",
                ".html": "text/html; charset=utf-8",
            }.get(requested_file.suffix)
            self.reply(
                200,
                requested_file.read_bytes(),
                content_type
                or mimetypes.guess_type(requested_file.name)[0]
                or "application/octet-stream",
            )

        do_HEAD = do_GET

        def do_POST(self):
            if (
                not self.headers_ok()
                or self.headers.get("Origin", self.origin) != self.origin
                or self.headers.get("Sec-Fetch-Site", "same-origin") not in ("same-origin", "none")
            ):
                self.reply(403, {"error": "Open this app directly to continue."})
                return
            request_path = urlsplit(self.path).path

            if request_path == "/api/exit":
                try:
                    shipstation_browser.close()
                except Exception:
                    pass
                self.reply(200, {"stopping": True})
                threading.Thread(target=self.server.shutdown, daemon=True).start()
                return

            if request_path == "/api/shipstation/open":
                try:
                    result = shipstation_browser.call("open")
                    self.reply(200, result)
                except Exception as error:
                    self.reply(500, {"error": str(error)})
                return

            if request_path == "/api/shipstation/read":
                if not export_lock.acquire(blocking=False):
                    self.reply(409, {"error": "Another read/export is already running."})
                    return
                try:
                    result = shipstation_browser.call("read", max_pages=100)
                    latest_capture["data"] = result
                    self.reply(
                        200,
                        {
                            "rowCount": result["rowCount"],
                            "printedCount": result["printedCount"],
                            "printedMissingTimeCount": result["printedMissingTimeCount"],
                            "unreadableCount": result["unreadableCount"],
                            "printedMissingTrackingCount": result["printedMissingTrackingCount"],
                            "capturedAt": result["capturedAt"],
                            "pagesRead": len(result.get("pages") or []),
                            "url": result.get("url", ""),
                        },
                    )
                except Exception as error:
                    self.reply(500, {"error": str(error)})
                finally:
                    export_lock.release()
                return

            if request_path == "/api/shipstation/capture-excel":
                capture = latest_capture.get("data")
                if not capture:
                    self.reply(400, {"error": "Read the ShipStation Shipments grid first."})
                    return
                try:
                    workbook = build_print_capture_excel(capture)
                    self.reply(
                        200,
                        {
                            "fileBase64": base64.b64encode(workbook).decode("ascii"),
                            "rowCount": capture["rowCount"],
                        },
                    )
                except Exception as error:
                    self.reply(500, {"error": str(error)})
                return

            if request_path != "/api/report":
                self.reply(404, {"error": "Not found."})
                return
            if not self.headers.get("Content-Type", "").startswith("application/json"):
                self.reply(415, {"error": "Expected a JSON request."})
                return
            payload = {}
            try:
                length = int(self.headers.get("Content-Length", "0"))
                if not 1 <= length <= 24000 or self.headers.get("Transfer-Encoding"):
                    raise ReportError("Choose a TXT key file smaller than 16 KB.")
                self.connection.settimeout(30)
                payload = json.loads(self.rfile.read(length))
                if not isinstance(payload, dict):
                    raise ValueError()
                parse_credentials(payload.get("credentialsText"))
                parse_ship_date(payload.get("shipDate"))
            except (ValueError, TypeError, ReportError, OSError) as error:
                self.reply(
                    400,
                    {
                        "error": (
                            str(error)
                            if isinstance(error, ReportError)
                            else "Choose a valid TXT key file and Ship Date (MM/DD/YYYY)."
                        )
                    },
                )
                return
            if not export_lock.acquire(blocking=False):
                self.reply(409, {"error": "An export is already running. Wait for it to finish."})
                return
            try:
                self.send_response(200)
                for key, value in BROWSER_SECURITY_HEADERS.items():
                    self.send_header(key, value)
                self.send_header("Content-Type", "application/x-ndjson; charset=utf-8")
                self.send_header("Connection", "close")
                self.end_headers()

                def send(event):
                    self.wfile.write(
                        (json.dumps(event, ensure_ascii=True, allow_nan=False) + "\n").encode()
                    )
                    self.wfile.flush()

                def progress(update):
                    if isinstance(update, dict):
                        send({"type": "progress", **update})
                    else:
                        send({"type": "progress", "message": str(update)})

                try:
                    report = extractor(
                        payload["credentialsText"], payload["shipDate"], progress=progress
                    )
                    payload["credentialsText"] = ""
                    capture = latest_capture.get("data")
                    if capture:
                        progress("Matching ShipStation Label Printed status to shipment/tracking records...")
                        match_summary = merge_shipstation_capture(report["rows"], capture["rows"])
                        report["shipstationPrintCapture"] = capture
                        report["shipstationPrintMatchSummary"] = match_summary
                    else:
                        report["shipstationPrintCapture"] = None
                        report["shipstationPrintMatchSummary"] = {
                            "matched": 0,
                            "ambiguous": 0,
                            "missing": len(report["rows"]),
                        }
                        for row in report["rows"]:
                            row.update(
                                shipstationPrintStatus="Could not read",
                                shipstationDisplayedPrintTime="",
                                shipstationLabelPrintedRaw="",
                                shipstationPrintMatch="No UI capture",
                                shipstationPrintCapturedAt="",
                            )
                    send({"type": "progress", "message": "Creating Excel with Python..."})
                    workbook = build_excel(report)
                    summary = {
                        key: report[key]
                        for key in (
                            "version",
                            "shipDate",
                            "rowCount",
                            "missingTrackingCount",
                            "printJobCount",
                            "printHistoryAvailable",
                        )
                    }
                    summary["shipstationPrintMatched"] = report["shipstationPrintMatchSummary"]["matched"]
                    summary["shipstationPrintCaptured"] = bool(capture)
                    summary["fileBase64"] = base64.b64encode(workbook).decode("ascii")
                    send({"type": "complete", "report": summary})
                except (BrokenPipeError, ConnectionResetError, TimeoutError):
                    pass
                except Exception as error:
                    try:
                        send(
                            {
                                "type": "error",
                                "message": (
                                    str(error)
                                    if isinstance(error, ReportError)
                                    else "The export could not be completed. No partial file was created."
                                ),
                            }
                        )
                    except OSError:
                        pass
            finally:
                payload.clear()
                export_lock.release()
                self.close_connection = True

    class LocalServer(ThreadingHTTPServer):
        daemon_threads = True

        def handle_error(self, request, client_address):
            # Never dump an exception containing a request or customer record.
            pass

    return LocalServer(("127.0.0.1", port), BrowserRequestHandler)

class ReportError(Exception):
    def __init__(self, message, code="REPORT_ERROR"):
        super().__init__(message)
        self.code = code


""" ----------- 1 - CHECK USER INPUT ----------- """


def parse_credentials(text):
    if not isinstance(text, str) or len(text.encode("utf-8")) > 16384:
        raise ReportError("Choose a TXT file smaller than 16 KB.")
    lines = [
        s.strip()
        for s in text.lstrip("\ufeff").splitlines()
        if s.strip() and not s.strip().startswith("#")
    ]
    aliases = {
        "key": ("API_KEY", "V1_API_KEY", "SHIPSTATION_API_KEY"),
        "secret": ("API_SECRET", "V1_API_SECRET", "SHIPSTATION_API_SECRET"),
        "v2": ("V2_API_KEY", "SHIPSTATION_V2_API_KEY"),
    }
    allowed = {name for names in aliases.values() for name in names}
    fields = {}
    for line in lines:
        match = re.fullmatch(r"([a-zA-Z][a-zA-Z0-9_ -]*)\s*[:=]\s*(.+)", line)
        if not match:
            continue
        name = re.sub(r"[ -]", "_", match[1].strip().upper())
        if name not in allowed:
            continue
        if name in fields:
            raise ReportError("The TXT file repeats a credential field.")
        fields[name] = match[2].strip().strip("\"'")
    values = {}
    for group, names in aliases.items():
        found = [fields[name] for name in names if name in fields]
        if len(found) > 1:
            raise ReportError("Keep only one key and its matching secret in the file.")
        values[group] = found[0] if found else ""
    key, secret, v2 = (values[k] for k in ("key", "secret", "v2"))
    if v2 and (key or secret):
        raise ReportError("Use V1 key + secret OR one V2 key, not both.")
    if secret and not key or "V1_API_KEY" in fields and not secret:
        raise ReportError("V1 requires both API_KEY and API_SECRET.")
    value = v2 or key or (lines[0] if len(lines) == 1 and not fields else "")
    if not value:
        raise ReportError(
            "No API key found. Use one V2 key, or API_KEY and API_SECRET on separate lines."
        )
    for part in (value, secret):
        if part and (
            not re.fullmatch(r"[\x21-\x7e]{8,512}", part)
            or re.search(r"YOUR_|PASTE_|REPLACE_|HERE", part, re.I)
        ):
            raise ReportError(
                "Replace the example text with real credentials. Keys cannot contain spaces."
            )
    return {"version": "v1" if secret else "v2", "key": value, "secret": secret}


def parse_ship_date(value):
    value = str(value).strip()
    if not re.fullmatch(r"\d{2}/\d{2}/\d{4}", value):
        raise ReportError("Enter Ship Date as MM/DD/YYYY, for example 08/27/2026.")
    try:
        result = datetime.strptime(value, "%m/%d/%Y").date()
        if not 2000 <= result.year <= 2099:
            raise ValueError()
    except ValueError:
        raise ReportError("Enter a real calendar date between 2000 and 2099.") from None
    return {
        "display": value,
        "iso": result.isoformat(),
        "next": (result + timedelta(days=1)).isoformat(),
    }


def calendar_date(value):
    if isinstance(value, str) and re.match(r"^\d{4}-\d{2}-\d{2}", value):
        try:
            return date.fromisoformat(value[:10]).isoformat()
        except ValueError:
            pass
    return ""


def as_id(value):
    return "" if value is None else str(value)


def number_or_none(value):
    if value is None or value == "" or isinstance(value, bool):
        return None
    try:
        number = float(value)
        return number if math.isfinite(number) else None
    except (ValueError, TypeError):
        return None


def joined(values):
    return "; ".join(dict.fromkeys(str(v) for v in values if v is not None and v != ""))


""" ----------- 2 - CONNECT TO SHIPSTATION ----------- """


class ShipStationAPI:
    def __init__(
        self,
        credentials,
        progress=lambda message: None,
        session=None,
        interval=None,
        sleep=time.sleep,
    ):
        self.version = credentials["version"]
        self.base = (
            "https://ssapi.shipstation.com"
            if self.version == "v1"
            else "https://api.shipstation.com/v2"
        )
        self.headers = {"Accept": "application/json"}
        if self.version == "v1":
            pair = (credentials["key"] + ":" + credentials["secret"]).encode("ascii")
            self.headers["Authorization"] = "Basic " + base64.b64encode(pair).decode("ascii")
        else:
            self.headers["api-key"] = credentials["key"]
        self.session = session if session is not None else requests.Session()
        self.interval = (
            interval if interval is not None else (1.6 if self.version == "v1" else 0.35)
        )
        self.progress, self.sleep, self.next_allowed = progress, sleep, 0

    def get(self, path, **params):
        if not re.fullmatch(r"/(orders|shipments|fulfillments|labels|stores)(/[^/?#]+)?", path):
            raise ReportError("Unsupported API resource.")
        for attempt in range(4):
            if self.next_allowed > time.monotonic():
                self.sleep(self.next_allowed - time.monotonic())
            try:
                # Explicit auth prevents an unrelated .netrc login overriding the uploaded key.
                response = self.session.get(
                    self.base + path,
                    params=params,
                    headers=self.headers,
                    timeout=(10, 45),
                    allow_redirects=False,
                    auth=lambda request: request,
                )
            except requests.RequestException:
                if attempt == 3:
                    raise ReportError(
                        "Cannot reach ShipStation. Check your internet connection and try again.",
                        "NETWORK",
                    ) from None
                self.sleep(2**attempt)
                continue
            finally:
                self.next_allowed = time.monotonic() + self.interval
            status = response.status_code
            if status == 401:
                raise ReportError(
                    "ShipStation rejected the credentials. Check API version, key and V1 secret.",
                    "AUTH",
                )
            if status in (402, 403):
                raise ReportError(
                    "Your ShipStation account or key cannot access this API. Check plan and permissions.",
                    "ACCESS",
                )
            if status == 429 or status >= 500:
                if attempt == 3:
                    raise ReportError(
                        "ShipStation is busy or rate-limiting requests. Retry later; no partial file was created.",
                        "RETRY_LIMIT",
                    )
                retry = response.headers.get("Retry-After") or response.headers.get(
                    "X-Rate-Limit-Reset"
                )
                try:
                    seconds = float(retry) if retry is not None else 2**attempt
                except ValueError:
                    try:
                        seconds = max(0, parsedate_to_datetime(retry).timestamp() - time.time())
                    except (ValueError, TypeError, OverflowError):
                        seconds = 2**attempt
                if not math.isfinite(seconds):
                    seconds = 2**attempt
                if seconds > 300:
                    raise ReportError(
                        "ShipStation requested a long pause. Please retry in a few minutes.",
                        "RATE_LIMIT",
                    )
                self.progress("ShipStation requested a pause; retrying safely...")
                self.sleep(max(1, seconds + 0.2))
                continue
            if not 200 <= status < 300:
                raise ReportError(
                    f"ShipStation returned HTTP {status} for {path.split('/')[1]}. No partial file was created.",
                    f"HTTP_{status}",
                )
            try:
                data = response.json()
            except ValueError:
                raise ReportError(
                    "ShipStation returned an unexpected response instead of JSON.", "BAD_RESPONSE"
                ) from None
            if response.headers.get("X-Rate-Limit-Remaining") == "0":
                reset = number_or_none(response.headers.get("X-Rate-Limit-Reset")) or 60
                if reset > 300:
                    raise ReportError(
                        "ShipStation requested a long pause. Please retry later.", "RATE_LIMIT"
                    )
                self.next_allowed = time.monotonic() + max(0, reset)
            return data
        raise ReportError("ShipStation requests could not be completed.")

    def get_pages(self, path, key, **params):
        size = 500 if self.version == "v1" else 100
        size_key = "pageSize" if self.version == "v1" else "page_size"
        seen, received = set(), 0
        section_started = time.monotonic()
        for page in range(1, 1001):
            self.progress(f"Reading {key}: page {page}...")
            result = self.get(path, **params, page=page, **{size_key: size})
            rows = result.get(key) if isinstance(result, dict) else None
            if not isinstance(rows, list) or any(not isinstance(row, dict) for row in rows):
                raise ReportError(
                    f"ShipStation did not return the expected {key} list.", "BAD_RESPONSE"
                )
            pages, total = number_or_none(result.get("pages")), number_or_none(result.get("total"))
            if not rows:
                if total is not None and total > received or pages is not None and pages > page:
                    raise ReportError(
                        "An API page is missing. Please rerun; no partial file was created.",
                        "PAGINATION",
                    )
                return
            total_pages = (
                int(pages)
                if pages is not None and pages > 0
                else (max(1, math.ceil(total / size)) if total is not None and total > 0 else None)
            )
            if total_pages:
                average = max(self.interval + 0.25, (time.monotonic() - section_started) / page)
                self.progress(
                    {
                        "message": f"Reading {key}: page {page} of {total_pages}...",
                        "section": key.replace("_", " ").title(),
                        "currentPage": page,
                        "totalPages": total_pages,
                        "estimatedSeconds": math.ceil(max(0, total_pages - page) * average),
                    }
                )
            signature = hashlib.sha256(json.dumps(rows, sort_keys=True).encode()).digest()
            if signature in seen:
                raise ReportError(
                    "ShipStation repeated a page. Stopping to avoid incomplete or duplicate data.",
                    "PAGINATION",
                )
            seen.add(signature)
            received += len(rows)
            yield rows
            if pages is not None and pages > 0:
                if page >= pages:
                    return
            elif total is not None:
                if received >= total:
                    return
            elif len(rows) < size:
                return
        raise ReportError(
            "The 1,000-page safety limit was reached. No partial file was created.", "PAGINATION"
        )


""" ----------- 3 - CREATE THE EXCEL ROWS ----------- """


def make_tracking_record(record, source, version):
    v1 = version == "v1"
    return {
        "recordId": as_id(
            record.get("fulfillmentId", record.get("shipmentId"))
            if v1
            else record.get("fulfillment_id", record.get("label_id"))
        ),
        "shipmentId": as_id(record.get("shipmentId") if v1 else record.get("shipment_id")),
        "orderId": as_id(record.get("orderId") if v1 else record.get("external_order_id")),
        "orderNumber": as_id(
            record.get("orderNumber")
            if v1
            else record.get("shipment_number") or record.get("external_order_id")
        ),
        "shipDate": calendar_date(record.get("shipDate") if v1 else record.get("ship_date")),
        "tracking": joined(
            [record.get("trackingNumber") if v1 else record.get("tracking_number")]
            + [
                p.get("tracking_number") or p.get("trackingNumber")
                for p in record.get("packages") or []
            ]
        ),
        "carrier": (
            record.get("carrierCode")
            if v1
            else record.get("fulfillment_carrier_friendly_name")
            or record.get("carrier_code")
            or record.get("carrier_id")
        )
        or "",
        "service": (
            record.get("serviceCode") or record.get("fulfillmentServiceCode")
            if v1
            else record.get("fulfillment_service_code") or record.get("service_code")
        )
        or "",
        "provider": (
            record.get("sellerFillProviderName") or record.get("fulfillmentProviderCode")
            if v1
            else record.get("fulfillment_provider_friendly_name")
            or record.get("fulfillment_provider_code")
        )
        or "",
        "recipient": (record.get("shipTo" if v1 else "ship_to") or {}).get("name", ""),
        "source": source,
    }


def make_item_row(
    order_number, order_id, order_date, item, store, recipient, events, quantity_basis, warnings=()
):
    item = item or {}
    quantity, price = number_or_none(item.get("quantity")), number_or_none(
        item.get("unitPrice", item.get("unit_price"))
    )
    row = {
        "orderNumber": as_id(order_number),
        "orderId": as_id(order_id),
        "orderDate": order_date,
        "itemId": as_id(
            item.get(
                "orderItemId", item.get("sales_order_item_id", item.get("external_order_item_id"))
            )
        ),
        "itemName": item.get("name") or "",
        "sku": item.get("sku") or "",
        "quantity": quantity,
        "unitPrice": price,
        "lineTotal": quantity * price if quantity is not None and price is not None else None,
        "quantityBasis": quantity_basis,
        "store": store or "",
        "recipient": recipient or "",
        "shipDate": events[0].get("shipDate", ""),
    }    for field, event_field in {
        "tracking": "tracking",
        "carrier": "carrier",
        "service": "service",
        "fulfillmentProvider": "provider",
        "shipmentIds": "shipmentId",
        "recordIds": "recordId",
        "source": "source",
    }.items():
        row[field] = joined(e.get(event_field) for e in events)
    notes = list(warnings)
    for key, label in (
        ("tracking", "Tracking"),
        ("sku", "SKU"),
        ("itemName", "Item name"),
        ("orderDate", "Order date"),
    ):
        if not row[key]:
            notes.append(label + " unavailable")
    if quantity is None:
        notes.append("Quantity unavailable")
    row["warnings"] = joined(notes)
    return row

def get_v1_report(shipstation_api, day):
    events, rows, issues, by_order, seen = [], [], [], {}, set()
    params = {"shipDateStart": day["iso"] + " 00:00:00", "shipDateEnd": day["next"] + " 00:00:00"}
    for key, source in (
        ("fulfillments", "Fulfillment / marked shipped"),
        ("shipments", "ShipStation label"),
    ):
        extra = {"includeShipmentItems": "true"} if key == "shipments" else {}
        for page in shipstation_api.get_pages("/" + key, key, **params, **extra):
            for record in page:
                if (
                    record.get("voided")
                    or record.get("voidDate")
                    or record.get("isReturnLabel")
                    or calendar_date(record.get("shipDate")) != day["iso"]
                ):
                    continue
                event = make_tracking_record(record, source, "v1")
                identity = source, event["recordId"]
                if event["recordId"] and identity in seen:
                    continue
                seen.add(identity)
                events.append(event)
                if event["orderId"]:
                    by_order.setdefault(event["orderId"], []).append(event)
    stores = {}
    try:
        result = shipstation_api.get("/stores")
        if isinstance(result, list):
            stores = {as_id(s.get("storeId")): s.get("storeName") for s in result}
    except ReportError as error:
        if error.code in ("AUTH", "ACCESS"):
            raise
        issues.append("Store names unavailable; Store ID is preserved instead.")
    found = set()

    def add_order(order, matched, notes=()):
        identity = as_id(order.get("orderId"))
        if identity and identity in found:
            return
        if identity:
            found.add(identity)
        notes = list(notes)
        if not matched:
            notes.append("No matching daily shipment/fulfillment record")
        if not identity:
            notes.append("Order ID unavailable; tracking cannot be matched safely")
        if len(matched) > 1:
            notes.append(
                "Multiple shipment records: tracking is order-level, not item-to-package allocation"
            )
        selected = matched or [{"shipDate": day["iso"], "source": "Shipped order only"}]
        items = [i for i in order.get("items") or [] if not i.get("adjustment")]
        store_id = as_id((order.get("advancedOptions") or {}).get("storeId"))
        for item in items or [None]:
            rows.append(
                make_item_row(
                    order.get("orderNumber"),
                    identity,
                    calendar_date(order.get("orderDate")),
                    item,
                    stores.get(store_id) or store_id,
                    (order.get("shipTo") or {}).get("name"),
                    selected,
                    "Order item quantity",
                    notes,
                )
            )

    is_today = day["iso"] == date.today().isoformat()
    if is_today:
        order_ids = sorted(by_order)
        shipstation_api.progress(
            f"Today's date selected: reading only {len(order_ids)} linked order(s)..."
        )
        details_started = time.monotonic()
        for index, identity in enumerate(order_ids, 1):
            matched = by_order[identity]
            try:
                order = shipstation_api.get("/orders/" + quote(identity, safe=""))
                if not isinstance(order, dict):
                    raise ReportError("Unexpected order detail response.", "BAD_RESPONSE")
                status = order.get("orderStatus")
                notes = (
                    []
                    if status == "shipped"
                    else [
                        f"Current order status is {status or 'unavailable'}; daily shipment retained"
                    ]
                )
                add_order(order, matched, notes)
            except ReportError as error:
                if error.code != "HTTP_404":
                    raise
                found.add(identity)
                first = matched[0]
                rows.append(
                    make_item_row(
                        first["orderNumber"],
                        identity,
                        "",
                        None,
                        "",
                        first["recipient"],
                        matched,
                        "Order item quantity",
                        ["Order detail not found; tracking record retained"],
                    )
                )
            average = max(
                shipstation_api.interval + 0.25, (time.monotonic() - details_started) / index
            )
            shipstation_api.progress(
                {
                    "message": f"Reading today's order details: order {index} of {len(order_ids)}...",
                    "section": "Today's order details",
                    "currentPage": index,
                    "totalPages": len(order_ids),
                    "estimatedSeconds": math.ceil(max(0, len(order_ids) - index) * average),
                }
            )
    else:
        shipstation_api.progress(
            "Earlier date selected: checking all Shipped orders, including orders placed on earlier dates..."
        )
        for page in shipstation_api.get_pages("/orders", "orders", orderStatus="shipped"):
            for order in page:
                identity = as_id(order.get("orderId"))
                if identity in found or order.get("orderStatus") != "shipped":
                    continue
                matched = by_order.get(identity, []) if identity else []
                if not matched and calendar_date(order.get("shipDate")) != day["iso"]:
                    continue
                add_order(order, matched)
    for event in events:
        if event["orderId"] not in found:
            issues.append(
                f"Daily record {event['recordId'] or '(no ID)'} is not linked to a currently Shipped order. Retained on Tracking Records."
            )
    strategy = (
        "Today's linked orders + Shipments + Fulfillments"
        if is_today
        else "Full Shipped Orders history + Shipments + Fulfillments"
    )
    return {
        "rows": rows,
        "events": events,
        "issues": issues,
        "coverage": strategy,
        "quantityNote": "Quantity is ORDER LINE quantity, not proof all units shipped that day. Split orders may span dates. Tracking is linked at order level; package allocation is not inferred.",
    }

def get_v2_report(shipstation_api, day):
    events, rows = [], []
    for page in shipstation_api.get_pages(
        "/fulfillments",
        "fulfillments",
        ship_date_start=day["iso"] + "T00:00:00Z",
        ship_date_end=day["next"] + "T00:00:00Z",
    ):
        for record in page:
            if (
                not record.get("voided")
                and not record.get("voided_at")
                and calendar_date(record.get("ship_date")) == day["iso"]
            ):
                events.append(make_tracking_record(record, "Fulfillment / marked shipped", "v2"))
    # V2 labels do not have a ship-date filter. Do not restrict label creation date.
    shipstation_api.progress("Checking completed labels by Ship Date, not label creation date...")
    for page in shipstation_api.get_pages("/labels", "labels", label_status="completed"):
        for record in page:
            if (
                not record.get("voided")
                and not record.get("voided_at")
                and not record.get("is_return_label")
                and record.get("status", "completed") == "completed"
                and calendar_date(record.get("ship_date")) == day["iso"]
            ):
                events.append(make_tracking_record(record, "ShipStation label", "v2"))
    events = list({(e["source"], e["recordId"] or i): e for i, e in enumerate(events)}.values())
    groups = {}
    for i, event in enumerate(events):
        groups.setdefault(event["shipmentId"] or f"unmatched:{i}", []).append(event)
    details_started = time.monotonic()
    for index, (identity, group) in enumerate(groups.items(), 1):
        shipstation_api.progress(f"Reading item details: shipment {index} of {len(groups)}...")
        shipment, notes = {}, []
        if identity.startswith("unmatched:"):
            notes.append("Shipment ID unavailable; record preserved")
        else:
            try:
                shipment = shipstation_api.get("/shipments/" + quote(identity, safe=""))
                if not isinstance(shipment, dict):
                    raise ReportError("Unexpected shipment detail response.", "BAD_RESPONSE")
            except ReportError as error:
                if error.code != "HTTP_404":
                    raise
                notes.append("Shipment detail not found; record preserved")
        average = max(shipstation_api.interval + 0.25, (time.monotonic() - details_started) / index)
        shipstation_api.progress(
            {
                "message": f"Reading item details: shipment {index} of {len(groups)}...",
                "section": "Shipment details",
                "currentPage": index,
                "totalPages": len(groups),
                "estimatedSeconds": math.ceil(max(0, len(groups) - index) * average),
            }
        )
        if len(group) > 1:
            notes.append("Multiple tracking records; item-to-package allocation is not inferred")
        for item in shipment.get("items") or [{}]:
            rows.append(
                make_item_row(
                    item.get("external_order_id")
                    or shipment.get("shipment_number")
                    or group[0]["orderNumber"],
                    item.get("sales_order_id")
                    or shipment.get("external_order_id")
                    or group[0]["orderId"],
                    "",
                    item,
                    shipment.get("order_source_code"),
                    (shipment.get("ship_to") or {}).get("name") or group[0]["recipient"],
                    group,
                    "Shipment item quantity",
                    notes,
                )
            )
    return {
        "rows": rows,
        "events": events,
        "issues": [
            "V2 does not provide the original Order Date here or exact Shipped-status order reconciliation. Use a V1 key + secret for the fuller order-based report."
        ],
        "coverage": "V2 Fulfillments + completed Labels + Shipment items (limited order metadata)",
        "quantityNote": "Quantity is SHIPMENT ITEM quantity. Labels for the same shipment are grouped so items are not multiplied by package count. Order Date is blank; shipment creation date is not substituted.",
    }


""" ----------- 6 - RUN THE COMPLETE REPORT ----------- """


def extract_report(
    credentials_text,
    ship_date,
    progress=lambda message: None,
    print_history_reader=read_windows_print_history,
    **client_options,
):
    credentials, day = parse_credentials(credentials_text), parse_ship_date(ship_date)
    shipstation_api = ShipStationAPI(credentials, progress, **client_options)
    try:
        progress(
            "Credentials recognized as "
            + credentials["version"].upper()
            + ". Starting read-only export..."
        )
        if credentials["version"] == "v1":
            report = get_v1_report(shipstation_api, day)
        else:
            report = get_v2_report(shipstation_api, day)
    finally:
        shipstation_api.session.close()
        shipstation_api.headers.clear()
        credentials.clear()
    version = shipstation_api.version
    report["rows"].sort(key=lambda r: (r["orderNumber"], r["sku"]))

    def group_key(row):
        return (
            row["orderId"]
            if version == "v1" and row["orderId"]
            else row["shipmentIds"] or row["recordIds"] or row["orderNumber"]
        )

    progress("Checking Windows print history on this computer...")
    print_history = print_history_reader(day["iso"])
    matched_print_jobs = add_print_history(report["rows"], print_history)

    report.update(
        version=version,
        shipDate=day["iso"],
        displayDate=day["display"],
        generatedAt=datetime.now(timezone.utc).isoformat(),
        rowCount=len(report["rows"]),
        recordCount=len({group_key(row) for row in report["rows"]}),
        missingTrackingCount=len({group_key(row) for row in report["rows"] if not row["tracking"]}),
        printJobs=matched_print_jobs,
        printJobCount=len(matched_print_jobs),
        printHistoryAvailable=bool(print_history.get("available")),
        printHistoryNote=print_history.get("note") or "Print history was not checked.",
    )
    return report

"""Read Windows print records. This module never sends anything to a printer."""

import json
import os
import re
import subprocess
from datetime import date

""" ----------- 1 - READ WINDOWS PRINT HISTORY ----------- """


def read_windows_print_history(ship_date):
    """Return completed print jobs from the computer running this program."""

    if os.name != "nt":
        return {
            "available": False,
            "jobs": [],
            "note": "Windows print history is only available when the program runs on Windows.",
        }

    selected_date = date.fromisoformat(ship_date)

    # Event 307 means that the Windows print spooler completed a print job.
    powershell_code = f"""
$ErrorActionPreference = 'Stop'
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
$logName = 'Microsoft-Windows-PrintService/Operational'
$logInformation = Get-WinEvent -ListLog $logName

if (-not $logInformation.IsEnabled) {{
    @{{
        available = $false
        note = 'Windows PrintService Operational logging is disabled.'
        jobs = @()
    }} | ConvertTo-Json -Compress -Depth 4
    exit
}}

$startDate = [datetime]::new({selected_date.year}, {selected_date.month}, {selected_date.day}, 0, 0, 0)
$endDate = $startDate.AddDays(1)

$events = @(Get-WinEvent -FilterHashtable @{{
    LogName = $logName
    Id = 307
    StartTime = $startDate
    EndTime = $endDate
}} -ErrorAction SilentlyContinue)

$printJobs = @($events | ForEach-Object {{
    $details = $_.Properties

    [PSCustomObject]@{{
        recordId = $_.RecordId
        printedAt = $_.TimeCreated.ToString('o')
        documentName = if ($details.Count -gt 1) {{ [string]$details[1].Value }} else {{ '' }}
        userName = if ($details.Count -gt 2) {{ [string]$details[2].Value }} else {{ '' }}
        computerName = if ($details.Count -gt 3) {{ [string]$details[3].Value }} else {{ $_.MachineName }}
        printerName = if ($details.Count -gt 4) {{ [string]$details[4].Value }} else {{ '' }}
        pages = if ($details.Count -gt 7) {{ $details[7].Value }} else {{ $null }}
    }}
}})

@{{
    available = $true
    note = 'Windows PrintService Event 307 records were checked on this computer.'
    jobs = $printJobs
}} | ConvertTo-Json -Compress -Depth 4
"""

    try:
        completed_process = subprocess.run(
            ["powershell.exe", "-NoProfile", "-NonInteractive", "-Command", powershell_code],
            capture_output=True,
            text=True,
            encoding="utf-8",
            errors="replace",
            timeout=60,
            creationflags=getattr(subprocess, "CREATE_NO_WINDOW", 0),
        )
    except (OSError, subprocess.SubprocessError):
        return {
            "available": False,
            "jobs": [],
            "note": "The program could not read Windows print history.",
        }

    if completed_process.returncode != 0 or not completed_process.stdout.strip():
        return {
            "available": False,
            "jobs": [],
            "note": "Windows did not return its print history.",
        }

    try:
        print_history = json.loads(completed_process.stdout.lstrip("\ufeff").strip())
    except json.JSONDecodeError:
        return {
            "available": False,
            "jobs": [],
            "note": "Windows returned print history in an unexpected format.",
        }

    if not isinstance(print_history, dict):
        return {
            "available": False,
            "jobs": [],
            "note": "Windows returned print history in an unexpected format.",
        }

    print_history["jobs"] = print_history.get("jobs") or []
    return print_history


""" ----------- 2 - MATCH PRINT JOBS TO SHIPSTATION ----------- """


def clean_text(value):
    """Remove spaces and punctuation so tracking numbers are easier to compare."""

    return re.sub(r"[^a-zA-Z0-9]", "", str(value or "")).lower()


def get_row_identifiers(order_row):
    """Return the useful numbers that may appear in a print-job name."""

    identifiers = []

    fields = [
        ("Tracking number", order_row.get("tracking")),
        ("Order number", order_row.get("orderNumber")),
        ("Shipment ID", order_row.get("shipmentIds")),
        ("Record ID", order_row.get("recordIds")),
    ]

    for identifier_type, field_value in fields:
        for value in str(field_value or "").split(";"):
            cleaned_value = clean_text(value)

            # Short values create too many accidental matches.
            if len(cleaned_value) >= 6:
                identifiers.append((identifier_type, cleaned_value))

    return identifiers


def add_print_history(order_rows, print_history):
    """Add print information to each row and return only matched print jobs."""

    print_log_available = bool(print_history.get("available"))
    print_jobs = print_history.get("jobs") or []
    matched_print_jobs = {}

    for order_row in order_rows:
        order_row["printStatus"] = "Unknown - print log unavailable"
        order_row["printedAt"] = ""
        order_row["printerName"] = ""
        order_row["printComputer"] = ""
        order_row["printDocument"] = ""
        order_row["printMatch"] = ""
        order_row["printCount"] = 0

        if not print_log_available:
            continue

        matching_jobs = []
        match_type = ""

        for identifier_type, identifier in get_row_identifiers(order_row):
            for print_job in print_jobs:
                document_name = clean_text(print_job.get("documentName"))

                if identifier in document_name:
                    matching_jobs.append(print_job)
                    match_type = identifier_type

            if matching_jobs:
                break

        if not matching_jobs:
            order_row["printStatus"] = "No matching print record"
            continue

        matching_jobs.sort(key=lambda job: job.get("printedAt") or "")
        first_print_job = matching_jobs[0]

        order_row["printStatus"] = "Printed - Windows record found"
        order_row["printedAt"] = first_print_job.get("printedAt") or ""
        order_row["printerName"] = first_print_job.get("printerName") or ""
        order_row["printComputer"] = first_print_job.get("computerName") or ""
        order_row["printDocument"] = first_print_job.get("documentName") or ""
        order_row["printMatch"] = match_type

                str(print_job.get("printedAt") or ""),
                str(print_job.get("documentName") or ""),
            )

            if job_key not in matched_print_jobs:
                matched_print_jobs[job_key] = {
                    **print_job,
                    "matchedOrderNumbers": [],
                    "matchTypes": [],
                }

            saved_job = matched_print_jobs[job_key]
            order_number = order_row.get("orderNumber") or ""

            if order_number and order_number not in saved_job["matchedOrderNumbers"]:

            if match_type and match_type not in saved_job["matchTypes"]:
                saved_job["matchTypes"].append(match_type)

    final_jobs = []

    for print_job in matched_print_jobs.values():
        print_job["matchedOrderNumbers"] = "; ".join(print_job["matchedOrderNumbers"])
        print_job["matchTypes"] = "; ".join(print_job["matchTypes"])
        final_jobs.append(print_job)

    final_jobs.sort(key=lambda job: job.get("printedAt") or "")
    return final_jobs

"""Read ShipStation's Shipments grid with a dedicated persistent Edge profile.

The Shipments -> Label Printed cell is treated as the authoritative ShipStation UI
source. The module never guesses a print time from label creation, Ship Date, or the

PRINTED_RE = re.compile(r"\bprinted\b", re.I)
NOT_PRINTED_RE = re.compile(r"\b(?:not\s+printed|unprinted)\b", re.I)
CREATED_RE = re.compile(r"\bcreated\b", re.I)
SHIPSTATION_LOGIN_URL = "https://ss6.shipstation.com/login"
SHIPSTATION_HOME_URL = "https://ss6.shipstation.com/"

DATE_TIME_PATTERNS = [
    re.compile(
        r"\b\d{1,2}/\d{1,2}/\d{2,4}(?:,)?(?:\s+at)?\s+\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
    re.compile(
        r"\b(?:Jan(?:uary)?|Feb(?:ruary)?|Mar(?:ch)?|Apr(?:il)?|May|Jun(?:e)?|Jul(?:y)?|Aug(?:ust)?|Sep(?:t(?:ember)?)?|Oct(?:ober)?|Nov(?:ember)?|Dec(?:ember)?)\s+\d{1,2},?\s+\d{4}(?:,)?(?:\s+at)?\s+\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
    re.compile(
        r"\b\d{1,2}\s+(?:Jan(?:uary)?|Feb(?:ruary)?|Mar(?:ch)?|Apr(?:il)?|May|Jun(?:e)?|Jul(?:y)?|Aug(?:ust)?|Sep(?:t(?:ember)?)?|Oct(?:ober)?|Nov(?:ember)?|Dec(?:ember)?)\s+\d{4}(?:,)?(?:\s+at)?\s+\d{1,2}:\d{2}(?::\d{2})?\s*(?:AM|PM)?\b",
        re.I,
    ),
]


def clean_text(value: Any) -> str:
    return re.sub(r"\s+", " ", str(value or "")).strip()


def parse_label_print_cell(raw_text: str) -> dict[str, str]:
    """Interpret only what the ShipStation cell actually exposes."""
    raw = clean_text(raw_text)
    lower = raw.lower()
    if not raw:
        status = "Could not read"
    elif NOT_PRINTED_RE.search(raw):
        status = "Not Printed"
    elif PRINTED_RE.search(raw):
        status = "Printed"
    elif CREATED_RE.search(raw):
        status = "Created - not printed"
    elif lower in {"yes", "true"}:
        status = "Printed"
    elif lower in {"no", "false"}:
        status = "Not Printed"
    else:
        status = "Could not read"

    displayed_time = ""
    for pattern in DATE_TIME_PATTERNS:
        match = pattern.search(raw)
        if match:
            displayed_time = clean_text(match.group(0)).replace(" at ", " ")
            break

    return {
        "printStatus": status,
        "displayedPrintTime": displayed_time,
        "rawLabelPrinted": raw,
    }


def split_values(value: Any) -> list[str]:
    text = clean_text(value)
    if not text:
        return []
    return [part.strip() for part in re.split(r"\s*;\s*|\s*,\s*", text) if part.strip()]


def _norm_identifier(value: Any) -> str:
    return re.sub(r"[^A-Z0-9]", "", clean_text(value).upper())


def merge_shipstation_capture(report_rows: list[dict], capture_rows: list[dict]) -> dict[str, int]:
    """Attach ShipStation UI print status by shipment number first, then tracking.

    An order number alone is intentionally not used as an automatic match because one
    order can have multiple shipments/packages.
    """
    by_shipment: dict[str, list[dict]] = {}
    by_tracking: dict[str, list[dict]] = {}
    by_order: dict[str, list[dict]] = {}
    for captured in capture_rows:
        shipment = _norm_identifier(captured.get("shipmentNumber"))
        tracking = _norm_identifier(captured.get("tracking"))
        if shipment:
            by_shipment.setdefault(shipment, []).append(captured)
        if tracking:
            by_tracking.setdefault(tracking, []).append(captured)
        order = _norm_identifier(captured.get("orderNumber"))
        if order:
            by_order.setdefault(order, []).append(captured)

    # Order-number fallback is allowed only when both sides prove that the order has
    # exactly one shipment/package. This avoids linking the wrong package on split orders.
    report_order_packages: dict[str, set[tuple[str, str]]] = {}
    for report_row in report_rows:
        order = _norm_identifier(report_row.get("orderNumber"))
        if not order:
            continue
        report_order_packages.setdefault(order, set()).add(
            (
                _norm_identifier(report_row.get("shipmentIds")),
                _norm_identifier(report_row.get("tracking")),
            )
        )

    matched = ambiguous = missing = 0
    for row in report_rows:
        candidates: list[dict] = []
        match_type = ""
        for shipment in split_values(row.get("shipmentIds")):
            found = by_shipment.get(_norm_identifier(shipment), [])
            if found:
                candidates.extend(found)
                match_type = "Shipment #"
        if not candidates:
            for tracking in split_values(row.get("tracking")):
                found = by_tracking.get(_norm_identifier(tracking), [])
                if found:
                    candidates.extend(found)
                    match_type = "Tracking #"
        if not candidates:
            order_key = _norm_identifier(row.get("orderNumber"))
            captured_for_order = by_order.get(order_key, []) if order_key else []
            unique_capture_shipments = {
                (
                    _norm_identifier(item.get("shipmentNumber")),
                    _norm_identifier(item.get("tracking")),
                )
                for item in captured_for_order
            }
            if (
                order_key
                and len(report_order_packages.get(order_key, set())) == 1
                and len(unique_capture_shipments) == 1
                and captured_for_order
            ):
                candidates.extend(captured_for_order)
                match_type = "Order # (unique shipment only)"

        unique: list[dict] = []
        seen = set()
        for item in candidates:
            key = (
                _norm_identifier(item.get("shipmentNumber")),
                _norm_identifier(item.get("tracking")),
                clean_text(item.get("rawLabelPrinted")),
            )
            if key not in seen:
                seen.add(key)
                unique.append(item)

        row.update(
            shipstationPrintStatus="Could not read",
            shipstationDisplayedPrintTime="",
            shipstationLabelPrintedRaw="",
            shipstationPrintMatch="No UI match",
            shipstationPrintCapturedAt="",
        )
        notes = [n.strip() for n in str(row.get("warnings") or "").split(";") if n.strip()]

        if len(unique) == 1:
            item = unique[0]
            row["shipstationPrintStatus"] = item.get("printStatus") or "Could not read"
            row["shipstationDisplayedPrintTime"] = item.get("displayedPrintTime") or ""
            row["shipstationLabelPrintedRaw"] = item.get("rawLabelPrinted") or ""
            row["shipstationPrintMatch"] = match_type
            row["shipstationPrintCapturedAt"] = item.get("capturedAt") or ""
            matched += 1
            if row["shipstationPrintStatus"] == "Printed" and not clean_text(row.get("tracking")):
                notes.append("CRITICAL: ShipStation says Printed but tracking number is missing")
            if row["shipstationPrintStatus"] == "Printed" and not row["shipstationDisplayedPrintTime"]:
                notes.append("ShipStation says Printed but displayed print date/time could not be read")
        elif len(unique) > 1:
            ambiguous += 1
            row["shipstationPrintMatch"] = "Ambiguous"
            notes.append("Multiple ShipStation UI rows matched this shipment; print status not guessed")
        else:
            missing += 1
            notes.append("ShipStation Label Printed cell was not matched from the Shipments grid")

        row["warnings"] = "; ".join(dict.fromkeys(notes))

    return {"matched": matched, "ambiguous": ambiguous, "missing": missing}

@dataclass
class _Command:
    action: str
    payload: dict
    reply: queue.Queue


class ShipStationBrowserManager:
    """Own Playwright on one background thread so the browser can stay open."""

    def __init__(self):
        self.commands: queue.Queue[_Command] = queue.Queue()
        self.thread: threading.Thread | None = None
        self.started = threading.Event()
        self.start_error = ""

    def _ensure_thread(self):
        if self.thread and self.thread.is_alive():
            return
        self.thread = threading.Thread(target=self._worker, name="ShipStationBrowser", daemon=True)
        self.thread.start()
        self.started.wait(timeout=15)
        if self.start_error:
            raise RuntimeError(self.start_error)

    def call(self, action: str, **payload):
        self._ensure_thread()
        reply: queue.Queue = queue.Queue(maxsize=1)
        self.commands.put(_Command(action, payload, reply))
        result = reply.get(timeout=180)
        if isinstance(result, Exception):
            raise result
        return result

    def close(self):
        if not (self.thread and self.thread.is_alive()):
            return
        try:
            self.call("close")
        except Exception:
            pass

    def _worker(self):
        try:
            from playwright.sync_api import sync_playwright
        except Exception as exc:
            self.start_error = (
                "Browser support is not installed. Close the program and run START.cmd while connected to the internet. "
                f"({exc})"
            )
            self.started.set()
            return

        playwright = context = None
        try:
            playwright = sync_playwright().start()
            self.started.set()
            while True:
                cmd = self.commands.get()
                try:
                    if cmd.action == "close":
                        if context:
                            context.close()
                            context = None                        cmd.reply.put({"closed": True})
                        break
                    if context is None:
                        context = self._launch_context(playwright)
                    page = self._get_page(context)
                    if cmd.action == "open":
                        self._navigate_to_shipstation(page)
                        page.bring_to_front()
                        cmd.reply.put({"opened": True, "url": page.url})
                    elif cmd.action == "read":
                        cmd.reply.put(self._read_all_pages(page, cmd.payload.get("max_pages", 100)))
                    else:
                        raise RuntimeError("Unknown browser command.")
                except Exception as exc:
                    cmd.reply.put(exc)
        except Exception as exc:
            if not self.started.is_set():
                self.start_error = str(exc)
                self.started.set()
        finally:
            try:
                if context:
                    context.close()
            except Exception:
                pass
            try:
                if playwright:
                    playwright.stop()
            except Exception:
                pass

    def _profile_dir(self) -> Path:
        base = Path(os.environ.get("LOCALAPPDATA") or Path.home()) / "ShipStationDailyCheck"
        path = base / "EdgeProfile"
        path.mkdir(parents=True, exist_ok=True)
        return path

    def _launch_context(self, playwright):
        profile = self._profile_dir()
        try:
            return playwright.chromium.launch_persistent_context(
                user_data_dir=str(profile),
                channel="msedge",
                headless=False,
                viewport=None,
                chromium_sandbox=True,
                args=["--start-maximized"],
            )
        except Exception as edge_error:
            raise RuntimeError(
                "Could not open the dedicated ShipStation Edge window. Make sure Microsoft Edge is installed. "
                f"Details: {edge_error}"
            ) from edge_error


    @staticmethod
    def _navigate_to_shipstation(page):
        """Open the real ShipStation sign-in/app page from an about:blank tab.

        Use a documented/current ShipStation login host and verify that navigation
        actually left about:blank.  A failed navigation is surfaced to the local app
        instead of silently leaving the employee staring at a blank automation window.
        """
        current = clean_text(getattr(page, "url", ""))
        if "shipstation" in current.lower() and current.lower() not in {"about:blank", "about:blank/"}:
            return

        errors = []
        for target in (SHIPSTATION_LOGIN_URL, SHIPSTATION_HOME_URL):
            try:
                page.goto(target, wait_until="commit", timeout=60000)
                page.wait_for_timeout(1000)
                current = clean_text(getattr(page, "url", ""))
                if current and not current.lower().startswith("about:blank"):
                    return
                errors.append(f"{target} stayed on {current or 'blank page'}")
            except Exception as exc:
                errors.append(f"{target}: {exc}")

        raise RuntimeError(
            "The dedicated Edge window opened, but ShipStation did not load. "
            "Check that this computer can open ShipStation normally in Edge, then try again. "
            "Navigation details: " + " | ".join(errors)
        )

    @staticmethod
    def _get_page(context):
        pages = [p for p in context.pages if not p.is_closed()]
        if pages:
            # Prefer the most recently opened ShipStation page.
            for page in reversed(pages):
                if "shipstation" in page.url.lower():
                    return page
            return pages[-1]
        return context.new_page()

    def _read_page(self, page):
        result = page.evaluate(GRID_EXTRACTOR_JS)
        if not isinstance(result, dict) or not result.get("ok"):
            headers = ", ".join((result or {}).get("headers") or [])
            reason = (result or {}).get("reason") or "Shipments grid could not be read"
            if headers:
                reason += f". Visible headers: {headers[:1000]}"
            raise RuntimeError(
                reason
                + ". In ShipStation, open Shipments > Shipments and enable the Label Printed, Shipment #, and Tracking # columns, then try again."
            )
        captured_at = datetime.now().astimezone().isoformat(timespec="seconds")
        rows = []
        for raw in result.get("rows") or []:
            parsed = parse_label_print_cell(raw.get("labelPrintedRaw", ""))
            rows.append(
                {
                    "shipmentNumber": clean_text(raw.get("shipmentNumber")),
                    "tracking": clean_text(raw.get("tracking")),
                    "orderNumber": clean_text(raw.get("orderNumber")),
                    **parsed,
                    "capturedAt": captured_at,
                }
            )
        return {
            "rows": rows,
            "headers": result.get("headers") or [],
            "ariaRowCount": result.get("ariaRowCount"),
            "capturedAt": captured_at,
        }

    @staticmethod
    def _find_next_button(page):
        selectors = [
            'button[aria-label="Next page" i]',
            'button[aria-label*="next page" i]',
            'button[title="Next page" i]',
            'button[title*="next page" i]',
            '[role="button"][aria-label*="next page" i]',
        ]
        for selector in selectors:
            loc = page.locator(selector)
            for i in range(min(loc.count(), 10)):
                candidate = loc.nth(i)
                try:
                    if candidate.is_visible():
                        return candidate
                except Exception:
                    continue
        return None

    def _read_all_pages(self, page, max_pages: int):
        if "shipstation" not in page.url.lower():
            raise RuntimeError("The dedicated browser is not on ShipStation. Open ShipStation first.")
        all_rows: dict[tuple, dict] = {}

                    _norm_identifier(row.get("shipmentNumber")),

                )
                all_rows[key] = row
            page_summaries.append({"page": page_number, "rows": len(data["rows"])})

            next_button = self._find_next_button(page)
            if next_button is None:
                break
            try:
                disabled = next_button.is_disabled() or next_button.get_attribute("aria-disabled") == "true"
            except Exception:
                disabled = False
            if disabled:
                break

            before = "|".join(
                f"{r.get('shipmentNumber','')}:{r.get('tracking','')}" for r in data["rows"][:5]
            )
            next_button.click(timeout=10000)
            changed = False
            for _ in range(40):
                time.sleep(0.15)
                try:
                    probe = self._read_page(page)
                except Exception:
                    continue
                after = "|".join(
                    f"{r.get('shipmentNumber','')}:{r.get('tracking','')}" for r in probe["rows"][:5]
                )
                if after != before:
                    changed = True
                    break
            if not changed:
                # Avoid clicking indefinitely if ShipStation's pagination control changed behavior.
                break

        rows = list(all_rows.values())
        printed = sum(r.get("printStatus") == "Printed" for r in rows)
        incomplete = sum(
            r.get("printStatus") == "Printed" and not r.get("displayedPrintTime") for r in rows
        )
        unreadable = sum(r.get("printStatus") == "Could not read" for r in rows)
        missing_tracking_printed = sum(
            r.get("printStatus") == "Printed" and not clean_text(r.get("tracking")) for r in rows
        )
        return {
            "url": page.url,
            "headers": first_headers,
            "rows": rows,
            "rowCount": len(rows),
            "printedCount": printed,
            "printedMissingTimeCount": incomplete,
            "unreadableCount": unreadable,
            "printedMissingTrackingCount": missing_tracking_printed,
            "pages": page_summaries,
            "capturedAt": datetime.now().astimezone().isoformat(timespec="seconds"),
            "note": "Print time is preserved exactly as displayed by ShipStation. It is not assumed to be first-print time.",
        }

""" ----------- 1 - CREATE A FORMATTED EXCEL TABLE ----------- """


def table(sheet, columns, records):
    if len(records) > 1048575:
        raise ReportError("This report exceeds Excel's row limit. No partial workbook was created.")
    sheet.append([header for header, _, _ in columns])
    for index, (_, _, width) in enumerate(columns, 1):
        sheet.column_dimensions[get_column_letter(index)].width = width
    for row_index, record in enumerate(records, 2):
        for column_index, (_, key, _) in enumerate(columns, 1):
            value = record.get(key)
            if key in ("orderDate", "shipDate"):
                value = date.fromisoformat(value) if value else None
            elif key == "printedAt" and value:
                value = datetime.fromisoformat(value).replace(tzinfo=None)
            if isinstance(value, str) and len(value) > 32767:
                raise ReportError(
                    "A field exceeds Excel's text limit. No truncated workbook was created."
                )
            cell = sheet.cell(row_index, column_index, value)
            if isinstance(value, str):
                # API text stays text, even when it starts with =, +, -, @ or #.
                cell.data_type = "s"
                cell.number_format = "@"
            elif key in ("orderDate", "shipDate"):
                cell.number_format = "mm/dd/yyyy"
            elif key == "printedAt":
                cell.number_format = "mm/dd/yyyy h:mm AM/PM"
            elif key in ("unitPrice", "lineTotal"):
                cell.number_format = "#,##0.00"
            cell.alignment = Alignment(vertical="top", wrap_text=True)
            if key == "warnings" and value:
                cell.fill = PatternFill("solid", fgColor="FFF1CE")
        sheet.row_dimensions[row_index].height = 40
    sheet.freeze_panes = "A2"
    sheet.auto_filter.ref = sheet.dimensions
    sheet.row_dimensions[1].height = 34
    for cell in sheet[1]:
        cell.fill = PatternFill("solid", fgColor="285F99")
        cell.font = Font(name="Calibri", bold=True, color="FFFFFF", size=11)
        cell.alignment = Alignment(vertical="center", wrap_text=True)
    sheet.sheet_properties.pageSetUpPr.fitToPage = True
    sheet.page_setup.orientation = "landscape"
    sheet.page_setup.fitToWidth, sheet.page_setup.fitToHeight = 1, 0

function formatTime(seconds) {
    if (!Number.isFinite(seconds)) return "—";
    if (seconds < 60) return `${Math.max(0, Math.ceil(seconds))} seconds`;
    const minutes = Math.floor(seconds / 60);
    const remainingSeconds = Math.ceil(seconds % 60);
    return `${minutes} min ${remainingSeconds} sec`;
}

function base64ToExcel(base64File, filename) {
    const binaryText = window.atob(base64File);
    const fileBytes = new Uint8Array(binaryText.length);
    for (let index = 0; index < binaryText.length; index += 1) {
        fileBytes[index] = binaryText.charCodeAt(index);
    }
    const excelFile = new Blob(
        [fileBytes],
        {type: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"}
    );
    const downloadLink = document.createElement("a");
    downloadLink.href = URL.createObjectURL(excelFile);
    downloadLink.download = filename;
    downloadLink.click();
    URL.revokeObjectURL(downloadLink.href);
}

async function readReportMessages(response) {
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let unfinishedText = "";
    while (true) {
        const result = await reader.read();
        unfinishedText += decoder.decode(result.value || new Uint8Array(), {stream: !result.done});
        const lines = unfinishedText.split("\n");
        unfinishedText = lines.pop();
        for (const line of lines) {
            if (!line.trim()) continue;
            const message = JSON.parse(line);
            if (message.type === "progress") showProgress(message);
            if (message.type === "error") throw new Error(message.message);
            if (message.type === "complete") {
                base64ToExcel(message.report.fileBase64, `ShipStation_${message.report.shipDate}_Report.xlsx`);
                const printPart = message.report.shipstationPrintCaptured
                    ? ` ${message.report.shipstationPrintMatched} row(s) matched to the ShipStation Label Printed capture.`
                    : " No ShipStation Label Printed capture was loaded.";
                statusMessage.textContent = `Complete. ${message.report.rowCount} Excel row(s) created.${printPart}`;
                statusMessage.className = "success-message";
                progressBar.style.width = "100%";
                sectionValue.textContent = "Complete";
                pageValue.textContent = "Done";
                timeValue.textContent = "0 seconds";
            }
        }
        if (result.done) break;
    }
}

class Response:
    def __init__(self, data, status=200, headers=None):
        self.data, self.status_code = data, status
        self.headers = CaseInsensitiveDict(headers or {})

    def json(self):
        if isinstance(self.data, Exception):
            raise self.data
        return copy.deepcopy(self.data)


def envelope(key, rows, page=1, pages=1, total=None):
    return {key: rows, "page": page, "pages": pages, "total": len(rows) if total is None else total}


class Session:
    def __init__(self, responder):
        self.responder, self.calls, self.closed = responder, [], False

    def get(self, url, **kwargs):
        self.calls.append((url, copy.deepcopy({k: v for k, v in kwargs.items() if k != "auth"})))
        return self.responder(url, kwargs)

    def close(self):
        self.closed = True


def v1_session(missing=False, multiple=False, extra=False, ship_day="2026-08-27"):
    orders = [
        {
            "orderId": i + 1,
            "orderNumber": "00000000000000000" + str(i + 1),
            "orderStatus": "shipped",
            "orderDate": "2026-08-18T11:00:00" if i == 6 else "2026-08-26T11:00:00",
            "shipDate": ship_day + "T00:00:00",
            "shipTo": {"name": "Test Recipient"},
            "advancedOptions": {"storeId": 42},
            "items": [
                {
                    "orderItemId": 100 + i,
                    "name": "Test item",
                    "sku": "SAME-WATCH-SKU" if i >= 3 else "SKU-" + str(i),
                    "quantity": 1,
                    "unitPrice": 12.5,
                }
            ],
        }
        for i in range(7)
    ]
    events = [
        {
            "orderId": i + 1,
            "orderNumber": order["orderNumber"],
            "shipDate": ship_day + "T00:00:00",
            "trackingNumber": "" if missing and i == 6 else "000000000000000000000" + str(i),
            "carrierCode": "ups" if i < 2 else "amazon",
            **(
                {"shipmentId": "label-" + str(i)}
                if i < 2
                else {"fulfillmentId": "external-" + str(i)}
            ),
        }
        for i, order in enumerate(orders)
    ]
    if multiple:
        events.append(
            {**events[0], "shipmentId": "extra-package", "trackingNumber": "SECOND-PACKAGE"}
        )
    if extra:
        orders.append({**orders[0], "orderId": 8, "orderNumber": "missing-event-order"})

    def respond(url, kwargs):
        path = url.removeprefix("https://ssapi.shipstation.com")
        if path.startswith("/orders/"):
            order_id = int(path.rsplit("/", 1)[-1])
            order = next((order for order in orders if order["orderId"] == order_id), None)
            return Response(order or {}, 200 if order else 404)
        key = url.rsplit("/", 1)[-1]
        if key == "fulfillments":
            return Response(envelope(key, [e for e in events if "fulfillmentId" in e]))
        if key == "shipments":
            return Response(envelope(key, [e for e in events if "shipmentId" in e]))
        if key == "stores":
            return Response([{"storeId": 42, "storeName": "Test Store"}])
        if key == "orders":
            page = kwargs["params"]["page"]
            return Response(
                envelope(key, orders[:3] if page == 1 else orders[3:], page, 2, len(orders))
            )
        raise AssertionError("Unexpected fixture path")

    return Session(respond)

    return Session(respond)

import unittest

from shipstation_ui import ShipStationBrowserManager, merge_shipstation_capture, parse_label_print_cell


class ShipStationUIParserTests(unittest.TestCase):
    def test_printed_time_is_preserved_from_cell(self):
        parsed = parse_label_print_cell("Label: Printed  09/28/2026 3:14 PM")
        self.assertEqual(parsed["printStatus"], "Printed")
        self.assertEqual(parsed["displayedPrintTime"], "09/28/2026 3:14 PM")
        self.assertIn("Printed", parsed["rawLabelPrinted"])

    def test_created_is_not_printed(self):
        parsed = parse_label_print_cell("Label: Created")
        self.assertEqual(parsed["printStatus"], "Created - not printed")
        self.assertEqual(parsed["displayedPrintTime"], "")

    def test_blank_is_unreadable_not_unprinted(self):
        parsed = parse_label_print_cell("")
        self.assertEqual(parsed["printStatus"], "Could not read")

    def test_merge_prefers_tracking(self):
        rows = [{
            "orderNumber": "1001",
            "shipmentIds": "internal-55",
            "tracking": "1Z999",
            "warnings": "",
        }]
        capture = [{
            "orderNumber": "1001",
            "shipmentNumber": "visible-88",
            "tracking": "1Z999",
            "printStatus": "Printed",
            "displayedPrintTime": "09/28/2026 4:20 PM",
            "rawLabelPrinted": "Printed 09/28/2026 4:20 PM",
            "capturedAt": "2026-09-29T10:00:00-04:00",
        }]
        summary = merge_shipstation_capture(rows, capture)
        self.assertEqual(summary["matched"], 1)
        self.assertEqual(rows[0]["shipstationPrintMatch"], "Tracking #")
        self.assertEqual(rows[0]["shipstationDisplayedPrintTime"], "09/28/2026 4:20 PM")

    def test_unique_order_fallback_can_flag_printed_missing_tracking(self):
        rows = [{
            "orderNumber": "1002",
            "shipmentIds": "shipment-a",
            "tracking": "",
            "warnings": "Tracking unavailable",
        }]
        capture = [{
            "orderNumber": "1002",
            "shipmentNumber": "shipment-visible-a",
            "tracking": "",
            "printStatus": "Printed",
            "displayedPrintTime": "09/28/2026 5:00 PM",
            "rawLabelPrinted": "Printed 09/28/2026 5:00 PM",
            "capturedAt": "2026-09-29T10:00:00-04:00",
        }]
        summary = merge_shipstation_capture(rows, capture)
        self.assertEqual(summary["matched"], 1)
        self.assertIn("unique shipment only", rows[0]["shipstationPrintMatch"])
        self.assertIn("CRITICAL", rows[0]["warnings"])

    def test_order_fallback_refuses_multiple_shipments(self):
        rows = [
            {"orderNumber": "1003", "shipmentIds": "a", "tracking": "", "warnings": ""},
            {"orderNumber": "1003", "shipmentIds": "b", "tracking": "", "warnings": ""},
        ]
        capture = [
            {"orderNumber": "1003", "shipmentNumber": "visible-a", "tracking": "", "printStatus": "Printed", "displayedPrintTime": "", "rawLabelPrinted": "Printed", "capturedAt": "x"},
            {"orderNumber": "1003", "shipmentNumber": "visible-b", "tracking": "", "printStatus": "Printed", "displayedPrintTime": "", "rawLabelPrinted": "Printed", "capturedAt": "x"},
        ]
        summary = merge_shipstation_capture(rows, capture)
        self.assertEqual(summary["matched"], 0)
        self.assertEqual(summary["missing"], 2)
