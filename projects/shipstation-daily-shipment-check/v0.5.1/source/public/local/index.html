STEP 1 · PRIMARY CHECK

Read ShipStation Label Printed

Primary source

The program reads the Shipments → Label Printed column directly. It preserves the displayed text and does not substitute label creation time or Windows print time.

  1. Click Open ShipStation. Sign in if needed.
  2. Open Shipments → Shipments, set the date/filter you want, and make sure Shipment #, Tracking #, and Label Printed columns are visible.
  3. Return here and click Read Shipments Grid. The program will read the current filtered grid and page forward when ShipStation exposes a Next Page button.

What the two print timestamps mean

ShipStation Displayed Print Time is the main field. It is copied from the Shipments → Label Printed cell and kept exactly as displayed. Until reprint behavior is validated on the live account, the program does not call it “first printed.”

Windows Printed Date / Time remains a secondary check from Windows PrintService Event 307. It is not allowed to overwrite ShipStation's status.

Printed + missing tracking and Printed + unreadable print time are both flagged for review.
