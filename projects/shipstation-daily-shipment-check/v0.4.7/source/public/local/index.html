ShipStation Daily Shipment Check

Choose a Ship Date range, compare your shipment records, and include ShipStation’s displayed printed status and time.

1

Choose the Ship Date range

Both dates are included. For one day, choose the same date twice. This range uses Ship Date, not the date the label was printed.

In ShipStation, apply the same Ship Date range to the Shipments view. Then use Export Shipments → Current View.

Uses your existing signed-in browser.

2

Capture ShipStation Label Printed date/time (recommended for exact print time)

The CSV gives us Label Printed, but not the displayed print date/time. The included v0.4.9 Edge/Chrome extension reads the Shipments → Label Printed cell from the browser session you already use. The CSV/API report also works without the print-time capture.

No ShipStation print-time rows captured yet.

Use Clear Capture before capturing a different range. Capture every page in that range; the extension reads one page at a time.

One-time setup: Edge → edge://extensions → Developer mode → Load unpacked → select the included ShipStation_Print_Time_Extension folder. Then, on ShipStation Shipments, click the extension and choose Capture this Shipments page.

3

Create the combined report

CSV results match by exact tracking number. Multiple-package item rows are marked for review; use Tracking Records for each package.

Carrier pages can request human verification. The program does not bypass it; those records are marked for manual checking.
