# Inventory Count Web App v1.6.4 — Google Sheets Memory Extraction

This version continues v1.6.3, including warehouse count sessions, expected units, autosave, import checks, and Excel exports. It expands product memory recognition for RAM **3–12 GB** and storage **32–512 GB** in Google Sheets exported as Excel (.xlsx).

Source: `source/`. The complete Windows portable package is published as a GitHub Release under tag `inventory-v1.6.4`. Extract the ZIP and run `start_app.cmd`.

The parser does not discard other capacities; the stated ranges are verified cases, not mandatory data limits.
