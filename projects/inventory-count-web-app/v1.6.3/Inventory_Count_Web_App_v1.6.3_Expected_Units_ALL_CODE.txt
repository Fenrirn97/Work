# Inventory Count Web App

A local Python web application for recording boxed and loose inventory, running controlled cycle counts, keeping count-session history in SQLite, comparing Excel workbooks, and exporting organized `.xlsx` reports.

## Run it on Windows without installing Python

1. Extract the ZIP file to a normal folder.
2. Double-click `start_app.cmd`.
3. Your default browser opens the app at `http://127.0.0.1:8765/`.
4. Keep the black server window open while using the app. Press `Ctrl+C` in that window when finished.

The portable Windows x64 package includes the official CPython 3.14.7 embedded runtime in the `runtime` folder. Python does not need to be installed on the PC. Keep the entire extracted folder together; do not run the launcher from inside the ZIP.

The launcher uses the bundled runtime first and falls back to an installed Python 3.10 or newer only when the `runtime` folder is missing. The app does not require Flask, Excel, Microsoft Office, or a separate database installation.

This portable build supports 64-bit Windows 10 and Windows 11. The bundled runtime is the official Python Software Foundation release from `https://www.python.org/downloads/release/python-3147/`; its license is included at `runtime/LICENSE.txt`.

## Inventory fields

- Model
- RAM
- Storage / Memory
- Color
- Items per Box
- Number of Boxes
- Loose Items
- Area / Location
- Broken Box

The saved amount is calculated as:

```text
(Items per Box × Number of Boxes) + Loose Items
```

Every new product row automatically records its original entry date and time. The web table and Excel export display that timestamp in the computer's local time. Editing a row does not replace its original entry timestamp.

## Cycle-count workflow

1. Create a **Planned** or **Spot** session and enter the warehouse, location, operator, and optional tolerances.
2. Open **Session History**, select the reference workbook, and choose **Freeze Reference & Download Organized Copy**.
3. The app validates the workbook before saving anything. It stores a SHA-256 fingerprint and parsed snapshot in SQLite, loads the autocomplete variants, and downloads a separate organized copy. The original workbook is never changed.
4. Enter the physical count. The **Compare & Review** screen shows the frozen reference quantity and current difference for products already counted.
5. When the count is ready for final review, choose **Submit Count for Review**. The app performs the complete comparison against the frozen snapshot, including reference items not yet counted.
6. Exact matches are accepted automatically. Differences inside a configured tolerance wait for supervisor review. Differences outside tolerance request a recount. A supervisor can approve or start a new recount and must record a name and reason.
7. After approval, finalize the session to lock it.

Recounts never delete prior captures. Each attempt keeps its count rows, submitted results, reviewer decision, name, reason, and timestamps.

## Inventory movement log

The **Movement Log** records receiving, shipments, transfers, temporary removals, returns to stock, and adjustments. Each movement keeps the product identity, quantity, locations, operator, note, and time. Movements during a count window produce review warnings; they never change physical-count quantities automatically.

## Organize an existing Excel workbook without changing it

Open the **Organize Excel** tab, select an `.xlsx` or `.xlsm` workbook, and choose **Create Organized Copy**. The uploaded workbook is read-only input: the app never edits, renames, moves, or overwrites it. The app first displays a validation preview and asks for confirmation. A separate macro-free download named `OriginalName_Organized.xlsx` is created with these columns:

- Model
- RAM
- Storage
- Color
- START
- END
- Date Counted

The organizer recognizes `Model` or `MAKE`, `Color` or `Colour`, separate or combined `START`/`END` headings, common date headings, and optional separate RAM and Storage columns. For Date Counted, it uses a labeled date column first. It can also recognize a consistently date-formatted unlabeled column and preserves partial values such as `11/13` without inventing a year. Worksheet names are never treated as product dates; when a product row has no date, Date Counted stays blank. A combined item such as `Phone X 8+256` is split into Model `Phone X`, RAM `8 GB`, and Storage `256 GB`. A `0+0` suffix is removed and leaves RAM and Storage blank for non-memory items.

### Model autocomplete

Creating the organized copy also replaces the app's local autocomplete catalog with the unique product variants extracted from that workbook. The catalog is stored in `data/inventory.db`, so it remains available after closing and reopening the app.

When a user types at least two characters in the Model field, the app searches the catalog and displays every matching variant. Each option shows Model, RAM, Storage, and Color. Selecting an option fills all four identity fields. For non-memory items, selecting the option fills RAM and Storage with `0` so the existing validation rule remains valid. Manual entry is always available when no option matches.

## Product identity rules

- Normal comparison identity: Model + RAM + Storage + Color.
- Area does not change product identity.
- Broken Box does not change product identity; its quantity is reported separately.
- When RAM and Storage are both `0`, the item is treated as a non-memory product. RAM and Storage are omitted from its displayed name and the comparison identity becomes Model + Color.
- A partial zero such as RAM `0` with Storage `256 GB` is rejected.
- Repeated rows with the same product identity are permitted after a warning and are totaled during comparison.

## Excel comparison

### Current Count vs Reference Sheet

The reference workbook must contain either a combined `MAKE` column or separate `Model`/optional `RAM`/`Storage` columns, plus `COLOR` and either `START` or `END` on the same header row. `START` is the preferred baseline; `END` is used when START is unavailable.

### Old Count vs Current Count

Use a workbook previously exported by this app or the desktop version. The importer reads the separate fields from its `Detailed Data` worksheet.

### Old Count vs Reference Sheet

Select both an older exported count workbook and the reference workbook. The app applies the same identity and totaling rules to the old count, then checks it against the reference baseline. This mode does not require entries in the active session.

## Data and backups

All sessions are stored in:

```text
data/inventory.db
```

Copy that file while the application is stopped to make a complete database backup. Excel exports provide an additional human-readable record.

Cycle-count exports can include `Inventory Count`, `Summary`, hidden `Detailed Data`, `Comparison Results`, `Issues`, hidden `Audit Log`, `Movement Log`, and `Count Attempts` worksheets. The application also writes operational messages to `data/inventory.log`.

The app binds only to `127.0.0.1`, so it is available only on the computer running it. Do not expose this development server directly to the public internet. A publicly hosted version should add user authentication, HTTPS, managed backups, and a production web server.

## Run tests

From the project folder:

```text
python -m unittest discover -s tests -v
```

"""Reference-vs-count and old-vs-new inventory comparison logic."""

from __future__ import annotations

from decimal import Decimal, InvalidOperation
from typing import Any

from .rules import group_entries, normalize_color_key, normalize_make_key


def _add_match_keys(results: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Attach the normalized identity used by movement and review workflows."""

    for result in results:
        result["match_key"] = (
            f"{normalize_make_key(result.get('item'))}|{normalize_color_key(result.get('color'))}"
        )
    return results


def _reference_amount(value: Any) -> dict[str, Any]:
    text = "" if value is None else str(value).strip()
    try:
        normalized = text.replace(",", "")
        number = Decimal(normalized)
        if not number.is_finite() or number < 0 or number != number.to_integral_value():
            raise InvalidOperation
        integer = int(number)
        return {"valid": True, "value": integer, "display": f"{integer:,}"}
    except (InvalidOperation, ValueError):
        return {"valid": False, "value": -1, "display": text or "(blank)"}


def _baseline(reference: dict[str, Any]) -> dict[str, Any]:
    start = _reference_amount(reference.get("start_text"))
    end = _reference_amount(reference.get("end_text"))
    if start["valid"]:
        used = "START (START != END)" if end["valid"] and end["value"] != start["value"] else "START"
        return {"valid": True, "value": start["value"], "start": start, "end": end, "used": used}
    if end["valid"]:
        return {
            "valid": True,
            "value": end["value"],
            "start": start,
            "end": end,
            "used": "END (START unavailable)",
        }
    return {"valid": False, "value": -1, "start": start, "end": end, "used": "NO VALID START OR END"}


def _contains_component(make_key: str, component: Any) -> bool:
    normalized = normalize_make_key(component)
    return not normalized or f" {normalized} " in f" {make_key} "


def _find_reference_match(group: dict[str, Any], references: list[dict[str, Any]]) -> dict[str, Any]:
    same_color = [row for row in references if row["color_key"] == group["color_key"]]
    if not same_color:
        return {"status": "NOT FOUND", "rows": []}
    exact = [row for row in same_color if row["make_key"] == group["make_key"]]
    if exact:
        return {"status": "EXACT", "rows": exact}
    component_matches = []
    for candidate in same_color:
        if (
            _contains_component(candidate["make_key"], group["model_key"])
            and _contains_component(candidate["make_key"], group["ram_key"])
            and _contains_component(candidate["make_key"], group["storage_key"])
        ):
            component_matches.append(candidate)
    if component_matches:
        return {"status": "ALIAS", "rows": component_matches}
    same_model = [
        row for row in same_color if _contains_component(row["make_key"], group["model_key"])
    ]
    if same_model:
        return {"status": "ATTRIBUTE CONFLICT", "rows": same_model}
    return {"status": "NOT FOUND", "rows": []}


def compare_reference(
    entries: list[dict[str, Any]],
    references: list[dict[str, Any]],
    include_missing_reference: bool = True,
) -> list[dict[str, Any]]:
    results: list[dict[str, Any]] = []
    matched_ids: set[str] = set()
    for group in group_entries(entries):
        match = _find_reference_match(group, references)
        if match["status"] == "NOT FOUND":
            results.append(
                {
                    "result": "NOT IN REFERENCE",
                    "item": group["item"],
                    "color": group["color"],
                    "counted": group["amount"],
                    "baseline": None,
                    "end_value": None,
                    "difference": None,
                    "broken_amount": group["broken_amount"],
                    "source_rows": group["source_rows"],
                    "last_updated": "",
                    "explanation": "No reference item matched Model, RAM, Storage, and Color.",
                }
            )
            continue
        if match["status"] == "ATTRIBUTE CONFLICT":
            results.append(
                {
                    "result": "ATTRIBUTE CONFLICT",
                    "item": group["item"],
                    "color": group["color"],
                    "counted": group["amount"],
                    "baseline": None,
                    "end_value": None,
                    "difference": None,
                    "broken_amount": group["broken_amount"],
                    "source_rows": group["source_rows"],
                    "last_updated": "",
                    "explanation": "The model and color are similar, but RAM or Storage does not match.",
                }
            )
            continue

        candidates = match["rows"]
        reference = max(
            candidates,
            key=lambda row: (row.get("last_updated_sort", float("-inf")), row.get("row_number", 0)),
        )
        matched_ids.update(row["reference_id"] for row in candidates)
        baseline = _baseline(reference)
        end_amount = _reference_amount(reference.get("end_text"))
        if not baseline["valid"]:
            results.append(
                {
                    "result": "INVALID REFERENCE",
                    "item": group["item"],
                    "color": group["color"],
                    "counted": group["amount"],
                    "baseline": None,
                    "end_value": None,
                    "difference": None,
                    "broken_amount": group["broken_amount"],
                    "source_rows": group["source_rows"],
                    "last_updated": reference.get("last_updated", ""),
                    "explanation": "START and END are missing or invalid.",
                }
            )
            continue
        difference = baseline["value"] - group["amount"]
        result_type = "MATCH" if difference == 0 else ("MISSING ITEMS" if difference > 0 else "EXTRA ITEMS")
        results.append(
            {
                "result": result_type,
                "item": group["item"],
                "color": group["color"],
                "counted": group["amount"],
                "baseline": baseline["value"],
                "end_value": end_amount["value"] if end_amount["valid"] else None,
                "difference": difference,
                "broken_amount": group["broken_amount"],
                "source_rows": group["source_rows"],
                "last_updated": reference.get("last_updated", ""),
                "explanation": f"{baseline['used']}; Difference = baseline minus counted.",
            }
        )

    if include_missing_reference:
        for reference in references:
            if reference["reference_id"] in matched_ids:
                continue
            baseline = _baseline(reference)
            end_amount = _reference_amount(reference.get("end_text"))
            results.append(
                {
                    "result": "MISSING FROM COUNT" if baseline["valid"] else "INVALID REFERENCE",
                    "item": reference["make"],
                    "color": reference["color"] or "(blank)",
                    "counted": 0,
                    "baseline": baseline["value"] if baseline["valid"] else None,
                    "end_value": end_amount["value"] if end_amount["valid"] else None,
                    "difference": baseline["value"] if baseline["valid"] else None,
                    "broken_amount": 0,
                    "source_rows": 0,
                    "last_updated": reference.get("last_updated", ""),
                    "explanation": (
                        "Reference item was not present in the count."
                        if baseline["valid"]
                        else "Reference item is missing a valid START and END."
                    ),
                }
            )
    return _add_match_keys(results)


def compare_old_new(
    old_entries: list[dict[str, Any]], new_entries: list[dict[str, Any]]
) -> list[dict[str, Any]]:
    results: list[dict[str, Any]] = []
    old_groups = group_entries(old_entries)
    new_groups = group_entries(new_entries)
    old_index = {group["match_key"]: group for group in old_groups}
    new_index = {group["match_key"]: group for group in new_groups}

    for old in old_groups:
        new = new_index.get(old["match_key"])
        if new:
            difference = new["amount"] - old["amount"]
            results.append(
                {
                    "result": "MATCH" if difference == 0 else "AMOUNT CHANGED",
                    "item": new["item"],
                    "color": new["color"],
                    "counted": new["amount"],
                    "baseline": old["amount"],
                    "end_value": new["amount"],
                    "difference": difference,
                    "broken_amount": new["broken_amount"],
                    "source_rows": new["source_rows"],
                    "last_updated": "",
                    "explanation": "Difference = new count minus old count.",
                }
            )
        else:
            results.append(
                {
                    "result": "MISSING IN NEW",
                    "item": old["item"],
                    "color": old["color"],
                    "counted": 0,
                    "baseline": old["amount"],
                    "end_value": 0,
                    "difference": -old["amount"],
                    "broken_amount": 0,
                    "source_rows": 0,
                    "last_updated": "",
                    "explanation": "Item existed in the old count but is absent from the new count.",
                }
            )
    for new in new_groups:
        if new["match_key"] in old_index:
            continue
        results.append(
            {
                "result": "NEW ITEM",
                "item": new["item"],
                "color": new["color"],
                "counted": new["amount"],
                "baseline": 0,
                "end_value": new["amount"],
                "difference": new["amount"],
                "broken_amount": new["broken_amount"],
                "source_rows": new["source_rows"],
                "last_updated": "",
                "explanation": "Item exists in the new count but not in the old count.",
            }
        )
    return _add_match_keys(results)

"""Cycle-count workflow, review decisions, frozen references, and movement records."""

from __future__ import annotations

import hashlib
import json
import math
import sqlite3
import uuid
from datetime import datetime
from typing import Any

from .comparison import compare_reference
from .database import add_audit, replace_comparison_results, session_entries, utc_now
from .rules import InventoryError, clean_text, comparison_key, parse_whole_number


MOVEMENT_TYPES = {
    "RECEIVE",
    "SHIPMENT",
    "TRANSFER",
    "TEMPORARY_OUT",
    "RETURN_TO_STOCK",
    "ADJUSTMENT",
}


def _safe_reference_rows(references: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return JSON-safe parsed rows while preserving every comparison field."""

    safe: list[dict[str, Any]] = []
    for reference in references:
        row = dict(reference)
        sort_value = row.get("last_updated_sort")
        if isinstance(sort_value, float) and not math.isfinite(sort_value):
            row["last_updated_sort"] = -1.0
        safe.append(row)
    return safe


def frozen_reference(connection: sqlite3.Connection, session_id: str) -> dict[str, Any] | None:
    row = connection.execute(
        "SELECT source_name, source_hash, row_count, section_count, created_at "
        "FROM cycle_references WHERE session_id = ?",
        (session_id,),
    ).fetchone()
    return dict(row) if row else None


def save_frozen_reference(
    connection: sqlite3.Connection,
    session_id: str,
    source_name: str,
    source_payload: bytes,
    references: list[dict[str, Any]],
    section_count: int,
) -> dict[str, Any]:
    session = connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone()
    if not session:
        raise KeyError("Inventory session not found.")
    if session["status"] != "DRAFT":
        raise PermissionError("This inventory session is finalized and locked.")
    if connection.execute(
        "SELECT COUNT(*) AS count FROM entries WHERE session_id = ?", (session_id,)
    ).fetchone()["count"]:
        raise InventoryError("Load the frozen reference before entering counts for this session.")

    now = utc_now()
    digest = hashlib.sha256(source_payload).hexdigest()
    safe_rows = _safe_reference_rows(references)
    connection.execute(
        """
        INSERT INTO cycle_references
        (session_id, source_name, source_hash, row_count, section_count, references_json, created_at)
        VALUES (?, ?, ?, ?, ?, ?, ?)
        ON CONFLICT(session_id) DO UPDATE SET
            source_name = excluded.source_name,
            source_hash = excluded.source_hash,
            row_count = excluded.row_count,
            section_count = excluded.section_count,
            references_json = excluded.references_json,
            created_at = excluded.created_at
        """,
        (
            session_id,
            clean_text(source_name)[:255] or "Reference.xlsx",
            digest,
            len(safe_rows),
            section_count,
            json.dumps(safe_rows, ensure_ascii=False, separators=(",", ":"), allow_nan=False),
            now,
        ),
    )
    connection.execute(
        """
        UPDATE sessions SET reference_name = ?, reference_hash = ?, reference_loaded_at = ?,
            workflow_status = 'COUNTING', submitted_at = NULL, approved_at = NULL,
            approved_by = '', review_reason = ''
        WHERE id = ?
        """,
        (clean_text(source_name)[:255] or "Reference.xlsx", digest, now, session_id),
    )
    add_audit(
        connection,
        session_id,
        "FREEZE REFERENCE",
        "",
        "",
        f"{clean_text(source_name)} | SHA256 {digest} | {len(safe_rows)} rows",
    )
    return {
        "source_name": clean_text(source_name)[:255] or "Reference.xlsx",
        "source_hash": digest,
        "row_count": len(safe_rows),
        "section_count": section_count,
        "created_at": now,
    }


def load_frozen_reference(connection: sqlite3.Connection, session_id: str) -> list[dict[str, Any]]:
    row = connection.execute(
        "SELECT references_json FROM cycle_references WHERE session_id = ?", (session_id,)
    ).fetchone()
    if not row:
        raise InventoryError("Load and freeze a reference workbook before submitting the cycle count.")
    references = json.loads(row["references_json"])
    if not isinstance(references, list) or not references:
        raise InventoryError("The saved reference snapshot is empty or invalid.")
    return references


def list_attempts(connection: sqlite3.Connection, session_id: str) -> list[dict[str, Any]]:
    rows = connection.execute(
        """
        SELECT attempt, submitted_at, status, decision, decision_by, decision_reason, decided_at
        FROM cycle_count_attempts WHERE session_id = ? ORDER BY attempt
        """,
        (session_id,),
    ).fetchall()
    return [dict(row) for row in rows]


def list_movements(connection: sqlite3.Connection, limit: int = 500) -> list[dict[str, Any]]:
    rows = connection.execute(
        "SELECT * FROM inventory_movements ORDER BY occurred_at DESC, rowid DESC LIMIT ?",
        (max(1, min(int(limit), 2000)),),
    ).fetchall()
    return [dict(row) for row in rows]


def validate_movement(payload: dict[str, Any]) -> dict[str, Any]:
    movement_type = clean_text(payload.get("movement_type")).upper().replace(" ", "_")
    if movement_type not in MOVEMENT_TYPES:
        raise InventoryError("Select a valid movement type.")
    model = clean_text(payload.get("model"))
    ram = clean_text(payload.get("ram"))
    storage = clean_text(payload.get("storage"))
    color = clean_text(payload.get("color"))
    operator_name = clean_text(payload.get("operator_name"))
    if not model or not ram or not storage or not color:
        raise InventoryError("Enter Model, RAM, Storage, and Color for the movement.")
    if not operator_name:
        raise InventoryError("Enter the operator who recorded the movement.")
    quantity = parse_whole_number(payload.get("quantity"), "Movement Quantity", allow_zero=False)
    occurred_at = clean_text(payload.get("occurred_at")) or utc_now()
    try:
        datetime.fromisoformat(occurred_at.replace("Z", "+00:00"))
    except ValueError:
        raise InventoryError("Movement Time must be a valid date and time.") from None
    return {
        "movement_type": movement_type,
        "model": model,
        "ram": ram,
        "storage": storage,
        "color": color.title(),
        "item_key": comparison_key(model, ram, storage, color),
        "quantity": quantity,
        "from_location": clean_text(payload.get("from_location")),
        "to_location": clean_text(payload.get("to_location")),
        "operator_name": operator_name,
        "note": clean_text(payload.get("note")),
        "occurred_at": occurred_at,
    }


def add_movement(connection: sqlite3.Connection, payload: dict[str, Any]) -> dict[str, Any]:
    movement = validate_movement(payload)
    movement["id"] = str(uuid.uuid4())
    connection.execute(
        """
        INSERT INTO inventory_movements
        (id, movement_type, model, ram, storage, color, item_key, quantity, from_location,
         to_location, operator_name, note, occurred_at)
        VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        """,
        tuple(movement[key] for key in (
            "id", "movement_type", "model", "ram", "storage", "color", "item_key",
            "quantity", "from_location", "to_location", "operator_name", "note", "occurred_at",
        )),
    )
    return movement


def _movement_warnings(
    connection: sqlite3.Connection,
    session: sqlite3.Row,
) -> dict[str, str]:
    location = clean_text(session["location"]).casefold()
    rows = connection.execute(
        "SELECT * FROM inventory_movements WHERE occurred_at >= ? ORDER BY occurred_at",
        (session["created_at"],),
    ).fetchall()
    warnings: dict[str, list[str]] = {}
    for row in rows:
        if location and location not in {
            clean_text(row["from_location"]).casefold(),
            clean_text(row["to_location"]).casefold(),
        }:
            continue
        route = " → ".join(part for part in (row["from_location"], row["to_location"]) if part)
        message = f"{row['movement_type'].replace('_', ' ').title()} {row['quantity']}"
        if route:
            message += f" ({route})"
        message += f" at {row['occurred_at']}"
        warnings.setdefault(row["item_key"], []).append(message)
    return {key: "; ".join(values) for key, values in warnings.items()}


def submit_cycle_count(connection: sqlite3.Connection, session_id: str) -> dict[str, Any]:
    session = connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone()
    if not session:
        raise KeyError("Inventory session not found.")
    if session["status"] != "DRAFT":
        raise PermissionError("This inventory session is finalized and locked.")
    if session["workflow_status"] != "COUNTING":
        raise InventoryError("This count is already submitted. Approve it or start a recount.")
    entries = session_entries(connection, session_id)
    if not entries:
        raise InventoryError("Add at least one inventory count before submitting.")

    references = load_frozen_reference(connection, session_id)
    results = compare_reference(entries, references)
    movement_warnings = _movement_warnings(connection, session)
    quantity_tolerance = max(0, int(session["quantity_tolerance"] or 0))
    percentage_tolerance = max(0.0, float(session["percentage_tolerance"] or 0))
    attempt = max(1, int(session["recount_attempt"] or 1))
    has_review = False
    has_recount = False

    for result in results:
        difference = result.get("difference")
        baseline = result.get("baseline")
        exact = result["result"] == "MATCH"
        percent = None
        if difference is not None and baseline not in (None, 0):
            percent = round(abs(float(difference)) / abs(float(baseline)) * 100, 2)
        quantity_ok = difference is not None and quantity_tolerance > 0 and abs(int(difference)) <= quantity_tolerance
        percentage_ok = percent is not None and percentage_tolerance > 0 and percent <= percentage_tolerance
        within = exact or quantity_ok or percentage_ok
        if exact:
            review_status = "ACCEPTED"
        elif within:
            review_status = "PENDING REVIEW"
            has_review = True
        else:
            review_status = "RECOUNT REQUIRED"
            has_recount = True
        result.update(
            {
                "difference_percent": percent,
                "within_tolerance": within,
                "review_status": review_status,
                "movement_warning": movement_warnings.get(result.get("match_key", ""), ""),
                "attempt": attempt,
            }
        )

    workflow_status = "RECOUNT_REQUIRED" if has_recount else ("PENDING_REVIEW" if has_review else "APPROVED")
    submitted_at = utc_now()
    replace_comparison_results(connection, session_id, "CYCLE_REFERENCE", results)
    connection.execute(
        """
        INSERT INTO cycle_count_attempts
        (session_id, attempt, submitted_at, status, results_json)
        VALUES (?, ?, ?, ?, ?)
        ON CONFLICT(session_id, attempt) DO UPDATE SET
            submitted_at = excluded.submitted_at,
            status = excluded.status,
            results_json = excluded.results_json
        """,
        (
            session_id,
            attempt,
            submitted_at,
            workflow_status,
            json.dumps(results, ensure_ascii=False, separators=(",", ":"), allow_nan=False),
        ),
    )
    approved_at = submitted_at if workflow_status == "APPROVED" else None
    approved_by = "Automatic exact match" if workflow_status == "APPROVED" else ""
    connection.execute(
        """
        UPDATE sessions SET workflow_status = ?, submitted_at = ?, approved_at = ?,
            approved_by = ?, review_reason = '' WHERE id = ?
        """,
        (workflow_status, submitted_at, approved_at, approved_by, session_id),
    )
    add_audit(
        connection,
        session_id,
        "SUBMIT COUNT",
        "",
        "COUNTING",
        f"{workflow_status} | attempt {attempt} | {len(results)} identities",
    )
    return {
        "workflow_status": workflow_status,
        "attempt": attempt,
        "result_count": len(results),
        "submitted_at": submitted_at,
    }


def review_cycle_count(
    connection: sqlite3.Connection,
    session_id: str,
    action: str,
    reviewer: str,
    reason: str,
) -> dict[str, Any]:
    session = connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone()
    if not session:
        raise KeyError("Inventory session not found.")
    if session["status"] != "DRAFT":
        raise PermissionError("This inventory session is finalized and locked.")
    decision = clean_text(action).upper()
    reviewer_name = clean_text(reviewer)
    reason_text = clean_text(reason)
    if decision not in {"APPROVE", "RECOUNT"}:
        raise InventoryError("Review action must be Approve or Recount.")
    if not reviewer_name:
        raise InventoryError("Enter the supervisor or reviewer name.")
    if not reason_text:
        raise InventoryError("Enter a reason for the review decision.")
    if session["workflow_status"] not in {"PENDING_REVIEW", "RECOUNT_REQUIRED"}:
        raise InventoryError("Submit the count before recording a review decision.")

    now = utc_now()
    attempt = max(1, int(session["recount_attempt"] or 1))
    if decision == "APPROVE":
        connection.execute(
            """
            UPDATE sessions SET workflow_status = 'APPROVED', approved_at = ?, approved_by = ?,
                review_reason = ? WHERE id = ?
            """,
            (now, reviewer_name, reason_text, session_id),
        )
        next_status = "APPROVED"
    else:
        connection.execute(
            """
            UPDATE sessions SET workflow_status = 'COUNTING', recount_attempt = recount_attempt + 1,
                submitted_at = NULL, approved_at = NULL, approved_by = '', review_reason = ?
            WHERE id = ?
            """,
            (reason_text, session_id),
        )
        connection.execute("DELETE FROM comparison_results WHERE session_id = ?", (session_id,))
        next_status = "COUNTING"
    connection.execute(
        """
        UPDATE cycle_count_attempts SET decision = ?, decision_by = ?, decision_reason = ?,
            decided_at = ? WHERE session_id = ? AND attempt = ?
        """,
        (decision, reviewer_name, reason_text, now, session_id, attempt),
    )
    add_audit(
        connection,
        session_id,
        f"REVIEW {decision}",
        "",
        session["workflow_status"],
        f"{next_status} | {reviewer_name} | {reason_text}",
    )
    return {"workflow_status": next_status, "attempt": attempt + (decision == "RECOUNT")}

def utc_now() -> str:
    return datetime.now(timezone.utc).replace(microsecond=0).isoformat().replace("+00:00", "Z")


def connect(path: str | Path) -> sqlite3.Connection:
    connection = sqlite3.connect(str(path), timeout=15)
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA foreign_keys = ON")
    connection.execute("PRAGMA journal_mode = WAL")
    return connection


def init_database(path: str | Path) -> None:
    database_path = Path(path)
    database_path.parent.mkdir(parents=True, exist_ok=True)
    with connect(database_path) as connection:
        connection.executescript(SCHEMA)
        _ensure_columns(connection, "sessions", SESSION_COLUMNS)
        _ensure_columns(connection, "entries", ENTRY_COLUMNS)
        _ensure_columns(connection, "comparison_results", COMPARISON_COLUMNS)
        _ensure_columns(connection, "catalog_items", CATALOG_COLUMNS)
        connection.execute(
            "UPDATE sessions SET session_number = 'CC-' || substr(replace(id, '-', ''), 1, 8) "
            "WHERE session_number = ''"
        )
        ensure_active_session(connection)


def _ensure_columns(
    connection: sqlite3.Connection,
    table: str,
    definitions: dict[str, str],
) -> None:
    """Add backwards-compatible columns without replacing the user's database."""

    existing = {row["name"] for row in connection.execute(f"PRAGMA table_info({table})")}
    for column, definition in definitions.items():
        if column not in existing:
            connection.execute(f"ALTER TABLE {table} ADD COLUMN {column} {definition}")


def create_session(
    connection: sqlite3.Connection,
    name: str | None = None,
    *,
    count_type: str = "SPOT",
    warehouse: str = "",
    location: str = "",
    operator_name: str = "",
    quantity_tolerance: int = 0,
    percentage_tolerance: float = 0,
) -> dict[str, Any]:
    session_id = str(uuid.uuid4())
    created_at = utc_now()
    session_name = (name or "").strip() or datetime.now().strftime("Inventory Count %Y-%m-%d %H:%M")
    count_kind = str(count_type or "SPOT").strip().upper()
    if count_kind not in {"PLANNED", "SPOT"}:
        raise ValueError("Count Type must be Planned or Spot.")
    session_number = f"CC-{datetime.now():%Y%m%d}-{session_id[:6].upper()}"
    connection.execute(
        """
        INSERT INTO sessions
        (id, name, status, created_at, session_number, count_type, warehouse, location,
         operator_name, quantity_tolerance, percentage_tolerance, workflow_status)
        VALUES (?, ?, 'DRAFT', ?, ?, ?, ?, ?, ?, ?, ?, 'COUNTING')
        """,
        (
            session_id, session_name, created_at, session_number, count_kind,
            str(warehouse).strip(), str(location).strip(), str(operator_name).strip(),
            max(0, int(quantity_tolerance)), max(0, float(percentage_tolerance)),
        ),
    )
    connection.execute(
        "INSERT INTO app_settings (key, value) VALUES ('active_session_id', ?) "
        "ON CONFLICT(key) DO UPDATE SET value = excluded.value",
        (session_id,),
    )
    add_audit(connection, session_id, "NEW SESSION", "", "", session_name)
    return dict(connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone())


def ensure_active_session(connection: sqlite3.Connection) -> dict[str, Any]:
    setting = connection.execute(
        "SELECT value FROM app_settings WHERE key = 'active_session_id'"
    ).fetchone()
    if setting:
        row = connection.execute("SELECT * FROM sessions WHERE id = ?", (setting["value"],)).fetchone()
        if row:
            return dict(row)
    latest = connection.execute("SELECT * FROM sessions ORDER BY created_at DESC LIMIT 1").fetchone()
    if latest:
        connection.execute(
            "INSERT INTO app_settings (key, value) VALUES ('active_session_id', ?) "
            "ON CONFLICT(key) DO UPDATE SET value = excluded.value",
            (latest["id"],),
        )
        return dict(latest)
    return create_session(connection)

    connection.execute(
        "INSERT INTO app_settings (key, value) VALUES ('active_session_id', ?) "
        "ON CONFLICT(key) DO UPDATE SET value = excluded.value",
        (session_id,),
    )
    return dict(row)


def current_session(connection: sqlite3.Connection) -> dict[str, Any]:
    return ensure_active_session(connection)


def require_draft(connection: sqlite3.Connection, session_id: str) -> None:
    row = connection.execute("SELECT status FROM sessions WHERE id = ?", (session_id,)).fetchone()
    if not row:
        raise KeyError("Inventory session not found.")
    if row["status"] != "DRAFT":
        raise PermissionError("This inventory session is finalized and locked.")


def finalize_session(connection: sqlite3.Connection, session_id: str) -> dict[str, Any]:
    require_draft(connection, session_id)
    count = connection.execute(
        """
        SELECT COUNT(*) AS count FROM entries e JOIN sessions s ON s.id = e.session_id
        WHERE e.session_id = ? AND e.attempt = s.recount_attempt
        """,
        (session_id,),
    ).fetchone()["count"]
    if count == 0:
        raise ValueError("Add at least one inventory count before finalizing.")
    session = connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone()
    if session["reference_name"] and session["workflow_status"] != "APPROVED":
        raise ValueError("Approve the submitted cycle count before finalizing it.")
    finalized_at = utc_now()
    connection.execute(
        "UPDATE sessions SET status = 'FINALIZED', workflow_status = 'FINALIZED', finalized_at = ? WHERE id = ?",
        (finalized_at, session_id),
    )
    add_audit(connection, session_id, "FINALIZE", "", "DRAFT", "FINALIZED")
    return dict(connection.execute("SELECT * FROM sessions WHERE id = ?", (session_id,)).fetchone())

    )


def rows_as_dicts(rows: list[sqlite3.Row] | tuple[sqlite3.Row, ...]) -> list[dict[str, Any]]:
    result = []
    for row in rows:
        item = dict(row)
        if "broken_box" in item:
            item["broken_box"] = bool(item["broken_box"])
        if "within_tolerance" in item and item["within_tolerance"] is not None:
            item["within_tolerance"] = bool(item["within_tolerance"])
        result.append(item)
    return result

def _catalog_reference_quantity(item: dict[str, Any]) -> int | None:
    """Return the quantity the count workflow uses as the inventory baseline.

    START is preferred to match reference comparison behavior. END is used only
    when START is unavailable. Invalid, negative, or fractional values are ignored.
    """

    for key in ("start", "end"):
        text = str(item.get(key) or "").strip().replace(",", "")
        if not text:
            continue
        try:
            number = Decimal(text)
        except InvalidOperation:
            continue
        if not number.is_finite() or number < 0 or number != number.to_integral_value():
            continue
        return int(number)
    return None


def replace_catalog_items(
    connection: sqlite3.Connection,
    items: list[dict[str, Any]],
    source_name: str,
) -> int:
    """Replace the local autocomplete catalog with unique product variants.

    Duplicate source rows are intentionally retained as metadata so the UI can
    explain when several spreadsheet rows represent the same product identity.
    """

    loaded_at = utc_now()
    unique: dict[tuple[str, str, str, str], dict[str, Any]] = {}
    for item in items:
        model = str(item.get("model") or "").strip()
        ram = str(item.get("ram") or "").strip()
        storage = str(item.get("storage") or "").strip()
        color = str(item.get("color") or "").strip()
        if not model or not color:
            continue
        key = (model.casefold(), ram.casefold(), storage.casefold(), color.casefold())
        group = unique.setdefault(
            key,
            {"values": (model, ram, storage, color), "locations": [], "reference_quantity": None},
        )
        location = ""
        if item.get("source_sheet") and item.get("source_row"):
            location = f"{item['source_sheet']}!{item['source_row']}"
        if location and location not in group["locations"]:
            group["locations"].append(location)
        quantity = _catalog_reference_quantity(item)
        if quantity is not None:
            group["reference_quantity"] = quantity

    connection.execute("DELETE FROM catalog_items")
    connection.executemany(
        "INSERT INTO catalog_items "
        "(model, ram, storage, color, source_name, loaded_at, source_rows, source_locations, reference_quantity) "
        "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)",
        [
            (
                *group["values"],
                source_name,
                loaded_at,
                max(1, len(group["locations"])),
                "; ".join(group["locations"][:20]),
                group["reference_quantity"],
            )
            for group in unique.values()
        ],
    )
    settings = {
        "catalog_source_name": source_name,
        "catalog_loaded_at": loaded_at,
        "catalog_variant_count": str(len(unique)),
    }
    connection.executemany(
        "INSERT INTO app_settings (key, value) VALUES (?, ?) "
        "ON CONFLICT(key) DO UPDATE SET value = excluded.value",
        settings.items(),
    )
    return len(unique)


def catalog_summary(connection: sqlite3.Connection) -> dict[str, Any]:
    rows = connection.execute(
        "SELECT key, value FROM app_settings WHERE key IN "
        "('catalog_source_name', 'catalog_loaded_at', 'catalog_variant_count')"
    ).fetchall()
    settings = {row["key"]: row["value"] for row in rows}
    actual_count = connection.execute("SELECT COUNT(*) AS count FROM catalog_items").fetchone()["count"]
    return {
        "variant_count": int(actual_count),
        "source_name": settings.get("catalog_source_name", ""),
        "loaded_at": settings.get("catalog_loaded_at", ""),
    }


def search_catalog_items(
    connection: sqlite3.Connection,
    query: str,
    limit: int = 30,
) -> list[dict[str, Any]]:
    text = query.strip()
    if not text:
        return []
    rows = connection.execute(
        """
        SELECT id, model, ram, storage, color, source_rows, source_locations, reference_quantity
        FROM catalog_items
        WHERE instr(lower(model || ' ' || ram || ' ' || storage || ' ' || color), lower(?)) > 0
        ORDER BY
            CASE
                WHEN lower(model) = lower(?) THEN 0
                WHEN lower(model) LIKE lower(?) || '%' THEN 1
                ELSE 2
            END,
            model COLLATE NOCASE,
            ram COLLATE NOCASE,
            storage COLLATE NOCASE,
            color COLLATE NOCASE
        LIMIT ?
        """,
        (text, text, text, max(1, min(int(limit), 100))),
    ).fetchall()
    return [dict(row) for row in rows]



def save_last_workbook(
    connection: sqlite3.Connection,
    source_name: str,
    source_payload: bytes,
    organized_payload: bytes,
    validation_json: str,
) -> dict[str, Any]:
    """Persist the last successfully validated workbook for one-click reuse."""

    import hashlib

    saved_at = utc_now()
    source_hash = hashlib.sha256(source_payload).hexdigest()
    connection.execute(
        """
        INSERT INTO saved_workbooks
        (key, source_name, source_hash, source_payload, organized_payload, validation_json, saved_at)
        VALUES ('last_reference', ?, ?, ?, ?, ?, ?)
        ON CONFLICT(key) DO UPDATE SET

               COALESCE(SUM(CASE WHEN e.broken_box = 1 THEN e.amount ELSE 0 END), 0) AS broken_amount

"""Validation and product-identity rules shared by the API and comparator."""

from __future__ import annotations

import re
from collections import OrderedDict
from decimal import Decimal, InvalidOperation
from typing import Any, Iterable


class InventoryError(ValueError):
    """A user-correctable inventory validation error."""


def clean_text(value: Any) -> str:
    if value is None:
        return ""
    return re.sub(r"\s+", " ", str(value).strip())


def normalize_match_text(value: Any) -> str:
    return clean_text(value).upper()


def normalize_header(value: Any) -> str:
    return re.sub(r"[^a-z0-9]", "", clean_text(value).lower())


def normalize_make_key(value: Any) -> str:
    text = normalize_match_text(value)
    text = re.sub(r"\b([0-9]+)\s*(GB|TB)\b", r"\1", text)
    text = re.sub(r"[^A-Z0-9]+", " ", text)
    return re.sub(r"\s+", " ", text.strip())


def normalize_color_key(value: Any) -> str:
    return normalize_match_text(value)


def is_zero_memory(value: Any) -> bool:
    text = normalize_match_text(value)
    text = re.sub(r"\s*(GB|TB)\s*$", "", text)
    if not text:
        return False
    try:
        return Decimal(text) == 0
    except InvalidOperation:
        return False


def is_non_memory_item(ram: Any, storage: Any) -> bool:
    return is_zero_memory(ram) and is_zero_memory(storage)


def has_partial_zero_memory(ram: Any, storage: Any) -> bool:
    return is_zero_memory(ram) != is_zero_memory(storage)


def remove_memory_unit(value: Any) -> str:
    return re.sub(r"(?i)\s*(GB|TB)\s*$", "", clean_text(value))


def count_make(model: Any, ram: Any, storage: Any) -> str:
    model_text = clean_text(model)
    if is_non_memory_item(ram, storage):
        return model_text
    return f"{model_text} {remove_memory_unit(ram)}+{remove_memory_unit(storage)}".strip()


def item_details(entry: dict[str, Any], include_broken_box: bool = True) -> str:
    parts = [clean_text(entry.get("model"))]
    if not is_non_memory_item(entry.get("ram"), entry.get("storage")):
        parts.extend([clean_text(entry.get("ram")), clean_text(entry.get("storage"))])
    if include_broken_box and bool(entry.get("broken_box")):
        parts.append("Broken Box")
    return " · ".join(part for part in parts if part)


def comparison_key(model: Any, ram: Any, storage: Any, color: Any) -> str:
    make = count_make(model, ram, storage)
    return f"{normalize_make_key(make)}|{normalize_color_key(color)}"


def parse_whole_number(value: Any, label: str, *, allow_zero: bool = True) -> int:
    text = clean_text(value).replace(",", "")
    try:
        number = Decimal(text)
    except (InvalidOperation, ValueError):
        raise InventoryError(f"{label} must be a whole number.") from None
    if not number.is_finite() or number != number.to_integral_value():
        raise InventoryError(f"{label} must be a whole number.")
    integer = int(number)
    if integer < 0 or (not allow_zero and integer == 0):
        qualifier = "greater than zero" if not allow_zero else "zero or greater"
        raise InventoryError(f"{label} must be {qualifier}.")
    if integer > 9_223_372_036_854_775_807:
        raise InventoryError(f"{label} is too large.")
    return integer


def validate_entry(payload: dict[str, Any]) -> dict[str, Any]:
    model = clean_text(payload.get("model"))
    ram = clean_text(payload.get("ram"))
    storage = clean_text(payload.get("storage"))
    color = clean_text(payload.get("color"))
    area = clean_text(payload.get("area"))

    if not model:
        raise InventoryError("Enter the Model.")
    if not ram:
        raise InventoryError("Enter RAM. Use 0 when the item has no RAM.")
    if not storage:
        raise InventoryError("Enter Storage. Use 0 when the item has no Storage.")
    if has_partial_zero_memory(ram, storage):
        raise InventoryError(
            "RAM and Storage must both be 0 for a non-memory item. A partial zero is not allowed."
        )
    if not color:
        raise InventoryError("Enter the Color.")
    if not area:
        raise InventoryError("Enter the Area or warehouse location.")

    items_per_box = parse_whole_number(payload.get("items_per_box", 0), "Items per Box")
    boxes = parse_whole_number(payload.get("boxes", 0), "Boxes")
    loose_items = parse_whole_number(payload.get("loose_items", 0), "Loose Items")
    amount = (items_per_box * boxes) + loose_items
    if amount <= 0:
        raise InventoryError("The calculated Amount must be greater than zero.")

    return {
        "model": model,
        "ram": ram,
        "storage": storage,
        "color": color.title(),
        "items_per_box": items_per_box,
        "boxes": boxes,
        "loose_items": loose_items,
        "amount": amount,
        "area": area,
        "broken_box": bool(payload.get("broken_box", False)),
    }


def group_entries(rows: Iterable[dict[str, Any]]) -> list[dict[str, Any]]:
    grouped: OrderedDict[str, dict[str, Any]] = OrderedDict()
    for row in rows:
        key = comparison_key(row.get("model"), row.get("ram"), row.get("storage"), row.get("color"))
        if key not in grouped:
            non_memory = is_non_memory_item(row.get("ram"), row.get("storage"))
            grouped[key] = {
                "match_key": key,
                "make_key": normalize_make_key(
                    count_make(row.get("model"), row.get("ram"), row.get("storage"))
                ),
                "model_key": normalize_make_key(row.get("model")),
                "ram_key": "" if non_memory else normalize_make_key(row.get("ram")),
                "storage_key": "" if non_memory else normalize_make_key(row.get("storage")),
                "color_key": normalize_color_key(row.get("color")),
                "model": clean_text(row.get("model")),
                "ram": clean_text(row.get("ram")),
                "storage": clean_text(row.get("storage")),
                "color": clean_text(row.get("color")),
                "make": count_make(row.get("model"), row.get("ram"), row.get("storage")),
                "item": item_details(row, include_broken_box=False),
                "amount": 0,
                "broken_amount": 0,
                "source_rows": 0,
            }
        group = grouped[key]
        amount = int(row.get("amount") or 0)
        group["amount"] += amount
        if bool(row.get("broken_box")):
            group["broken_amount"] += amount
        group["source_rows"] += 1
    return list(grouped.values())

"""Dependency-free XLSX reader and writer used by the local Python web app."""

from __future__ import annotations

MAIN_NS = "http://schemas.openxmlformats.org/spreadsheetml/2006/main"
DOC_REL_NS = "http://schemas.openxmlformats.org/officeDocument/2006/relationships"
PACKAGE_REL_NS = "http://schemas.openxmlformats.org/package/2006/relationships"


def _tag(namespace: str, name: str) -> str:
    return f"{{{namespace}}}{name}"


def _column_number(reference: str) -> int:
    letters = re.match(r"^[A-Za-z]+", reference or "")
    number = 0
    for character in (letters.group(0).upper() if letters else ""):
        number = (number * 26) + (ord(character) - ord("A") + 1)
    return number - 1


def _column_name(index: int) -> str:
    number = index + 1
    result = ""
    while number > 0:
        number, remainder = divmod(number - 1, 26)
        result = chr(ord("A") + remainder) + result
    return result


def _cell_text(cell: ET.Element, shared_strings: list[str]) -> str:
    cell_type = cell.attrib.get("t", "")
    if cell_type == "inlineStr":
        return "".join(node.text or "" for node in cell.findall(f".//{_tag(MAIN_NS, 't')}"))
    value = cell.find(_tag(MAIN_NS, "v"))
    if value is None:
        return ""
    raw = value.text or ""
    if cell_type == "s":
        try:
            index = int(raw)
            return shared_strings[index] if 0 <= index < len(shared_strings) else ""
        except (ValueError, IndexError):
            return ""
    if cell_type == "b":
        return "TRUE" if raw == "1" else "FALSE"
    return raw


def read_xlsx_sheets(payload: bytes) -> list[dict[str, Any]]:
    try:
        archive = zipfile.ZipFile(io.BytesIO(payload), "r")
    except (zipfile.BadZipFile, OSError) as exc:
        raise InventoryError("The selected file is not a valid .xlsx workbook.") from exc

    with archive:
        names = set(archive.namelist())
        shared_strings: list[str] = []
        if "xl/sharedStrings.xml" in names:
            try:
                root = ET.fromstring(archive.read("xl/sharedStrings.xml"))
                for item in root.findall(_tag(MAIN_NS, "si")):
                    shared_strings.append(
                        "".join(node.text or "" for node in item.findall(f".//{_tag(MAIN_NS, 't')}"))
                    )
            except ET.ParseError as exc:
                raise InventoryError("The workbook shared-string table is damaged.") from exc

        sheet_entries: list[tuple[str, str, bool]] = []
        if "xl/workbook.xml" in names and "xl/_rels/workbook.xml.rels" in names:
            try:
                workbook = ET.fromstring(archive.read("xl/workbook.xml"))
                relationships = ET.fromstring(archive.read("xl/_rels/workbook.xml.rels"))
                targets = {
                    rel.attrib.get("Id", ""): rel.attrib.get("Target", "")
                    for rel in relationships.findall(_tag(PACKAGE_REL_NS, "Relationship"))
                }
                for sheet in workbook.findall(f".//{_tag(MAIN_NS, 'sheet')}"):
                    rel_id = sheet.attrib.get(_tag(DOC_REL_NS, "id"), "")
                    target = targets.get(rel_id, "")
                    if not target:
                        continue
                    path = target.lstrip("/") if target.startswith("/") else posixpath.normpath(posixpath.join("xl", target))
                    if path in names:
                        sheet_entries.append(
                            (sheet.attrib.get("name", "Worksheet"), path, sheet.attrib.get("state") == "hidden")
                        )
            except ET.ParseError as exc:
                raise InventoryError("The workbook structure is damaged.") from exc

        if not sheet_entries:
            fallback = sorted(
                name for name in names if re.fullmatch(r"xl/worksheets/sheet\d+\.xml", name)
            )
            sheet_entries = [(f"Sheet {index + 1}", name, False) for index, name in enumerate(fallback)]
        if not sheet_entries:
            raise InventoryError("The workbook does not contain any readable worksheets.")

        sheets: list[dict[str, Any]] = []
        for sheet_name, path, hidden in sheet_entries:
            try:
                root = ET.fromstring(archive.read(path))
            except (KeyError, ET.ParseError) as exc:
                raise InventoryError(f"Worksheet '{sheet_name}' could not be read.") from exc
            rows = []
            for row_index, row_node in enumerate(root.findall(f".//{_tag(MAIN_NS, 'sheetData')}/{_tag(MAIN_NS, 'row')}"), 1):
                row_number = int(row_node.attrib.get("r") or row_index)
                cells: dict[int, str] = {}
                for cell in row_node.findall(_tag(MAIN_NS, "c")):
                    column = _column_number(cell.attrib.get("r", ""))
                    if column >= 0:
                        cells[column] = _cell_text(cell, shared_strings)
                rows.append({"row_number": row_number, "cells": cells})
            sheets.append({"name": sheet_name, "path": path, "hidden": hidden, "rows": rows})
        return sheets


def _reference_date(value: Any) -> dict[str, Any]:
    text = clean_text(value)
    if not text:
        return {"valid": False, "value": None, "sort": float("-inf"), "display": "(not provided)"}
    try:
        serial = float(text)
        if 30_000 <= serial <= 80_000:
            date_value = datetime(1899, 12, 30) + timedelta(seconds=round(serial * 86_400))
            return {
                "valid": True,
                "value": date_value,
                "sort": date_value.timestamp(),
                "display": date_value.strftime("%m/%d/%Y"),
            }
    except ValueError:
        pass
    candidate = text.replace("Z", "+00:00")
    try:
        date_value = datetime.fromisoformat(candidate)
        if date_value.tzinfo:
            date_value = date_value.astimezone(timezone.utc).replace(tzinfo=None)
        return {
            "valid": True,
            "value": date_value,
            "sort": date_value.timestamp(),
            "display": date_value.strftime("%m/%d/%Y"),
        }
    except ValueError:
        pass
    for pattern in ("%m/%d/%Y", "%Y-%m-%d", "%m/%d/%y", "%B %d, %Y", "%b %d, %Y"):
        try:
            date_value = datetime.strptime(text, pattern)
            return {
                "valid": True,
                "value": date_value,
                "sort": date_value.timestamp(),
                "display": date_value.strftime("%m/%d/%Y"),
            }
        except ValueError:
            continue
    return {"valid": False, "value": None, "sort": float("-inf"), "display": text}


def _date_from_row(row: dict[str, Any], date_column: int | None, excluded: set[int]) -> dict[str, Any]:
    if date_column is not None:
        return _reference_date(row["cells"].get(date_column))
    for column in sorted(row["cells"], reverse=True):
        if column in excluded:
            continue
        candidate = _reference_date(row["cells"].get(column))
        if candidate["valid"]:
            return candidate
    return _reference_date(None)


def _looks_like_partial_date(value: Any) -> bool:
    match = re.fullmatch(r"(\d{1,2})/(\d{1,2})", clean_text(value))
    if not match:
        return False
    month, day = (int(part) for part in match.groups())
    return 1 <= month <= 12 and 1 <= day <= 31


def _infer_date_column(
    rows: list[dict[str, Any]],
    first_row: int,
    last_row: int | None,
    excluded: set[int],
) -> int | None:
    """Find an unlabeled column whose populated values consistently look like dates."""

    statistics: dict[int, dict[str, int]] = {}
    for row in rows:
        row_number = int(row["row_number"])
        if row_number <= first_row or (last_row is not None and row_number >= last_row):
            continue
        for column, value in row["cells"].items():
            text = clean_text(value)
            if column in excluded or not text:
                continue
            column_stats = statistics.setdefault(column, {"populated": 0, "date_like": 0})
            column_stats["populated"] += 1
            if _reference_date(text)["valid"] or _looks_like_partial_date(text):
                column_stats["date_like"] += 1

    candidates = [
        (stats["date_like"] / stats["populated"], stats["date_like"], column)
        for column, stats in statistics.items()
        if stats["date_like"] >= 3 and stats["date_like"] / stats["populated"] >= 0.60
    ]
    return max(candidates)[2] if candidates else None


def _effective_row_date(
    row: dict[str, Any],
    date_column: int | None,
    inferred_date_column: int | None,
    excluded: set[int],
) -> dict[str, Any]:
    """Return only a date stored on this product row."""

    for column in (date_column, inferred_date_column):
        if column is None:
            continue
        raw_value = clean_text(row["cells"].get(column))
        if raw_value:
            return _reference_date(raw_value)
    return _reference_date(None)

def _display_memory(value: Any, default_unit: str = "GB") -> str:
    text = clean_text(value)
    if not text:
        return ""
    compact = re.sub(r"\s+", "", text).upper()
    if compact in {"0", "0GB", "0G", "0TB", "0T"}:
        return "0"
    match = re.fullmatch(r"(\d+(?:\.\d+)?)\s*(TB|GB|T|G)?", text, re.IGNORECASE)
    if not match:
        return text
    number, unit = match.groups()
    normalized_unit = {"T": "TB", "G": "GB"}.get((unit or default_unit).upper(), (unit or default_unit).upper())
    return f"{number} {normalized_unit}"


def split_model_memory(model_value: Any, ram_value: Any = "", storage_value: Any = "") -> tuple[str, str, str]:
    """Return separate model, RAM, and Storage values without inventing a 0+0 identity."""

    model = clean_text(model_value)    ram = _display_memory(ram_value)
    storage = _display_memory(storage_value)
    if ram or storage:
        if ram == "0" and storage == "0":
            return model, "", ""
        return model, ram, storage

    labeled = re.fullmatch(
        r"(?is)(?P<model>.+?)\s+(?:RAM\s*)?(?P<ram>\d+(?:\.\d+)?)\s*(?P<ram_unit>GB|G)?"
        r"\s*(?:\+|/|,|\s+)\s*(?:STORAGE|MEMORY|ROM)?\s*(?P<storage>\d+(?:\.\d+)?)"
        r"\s*(?P<storage_unit>TB|GB|T|G)?\s*",
        model,
    )
    compact = re.fullmatch(
        r"(?is)(?P<model>.+?)\s*(?:[-|]\s*)?\(?\s*(?P<ram>\d+(?:\.\d+)?)\s*(?P<ram_unit>GB|G)?"
        r"\s*(?:\+|/)\s*(?P<storage>\d+(?:\.\d+)?)\s*(?P<storage_unit>TB|GB|T|G)?\s*\)?\s*",
        model,
    )
    match = labeled or compact
    if not match:
        return model, "", ""

    separated_model = clean_text(match.group("model")).rstrip("-–—|,/").strip()
    ram_unit = match.group("ram_unit") or "GB"
    storage_unit = match.group("storage_unit") or "GB"
    ram = _display_memory(f"{match.group('ram')} {ram_unit}")
    storage = _display_memory(f"{match.group('storage')} {storage_unit}")
    if match.group("ram") == "0" and match.group("storage") == "0":
        return separated_model, "", ""
    return separated_model, ram, storage


def _split_start_end(value: Any) -> tuple[str, str]:
    text = clean_text(value)
    if not text:
        return "", ""
    parts = re.split(r"\s*(?:→|->|/|\||\bto\b)\s*", text, maxsplit=1, flags=re.IGNORECASE)
    if len(parts) == 2:
        return clean_text(parts[0]), clean_text(parts[1])
    return text, ""


def analyze_organized_rows(payload: bytes) -> tuple[list[dict[str, Any]], int, dict[str, Any]]:
    """Extract rows and return a transparent import-validation report.

    The report counts every nonblank candidate row inside a recognized inventory
    section. Rows that cannot be imported are listed with the worksheet, row
    number, and reason so nothing disappears silently.
    """

    result: list[dict[str, Any]] = []
    section_count = 0
    sheets = read_xlsx_sheets(payload)
    skipped: list[dict[str, Any]] = []
    candidate_rows = 0
    section_details: list[dict[str, Any]] = []

    for sheet in sheets:
        headers: list[dict[str, Any]] = []
        for row in sheet["rows"]:
            found: dict[str, int] = {}
            for column, value in row["cells"].items():
                key = ORGANIZE_HEADER_ALIASES.get(normalize_header(value))
                if key and key not in found:
                    found[key] = column
            has_counts = "start" in found or "end" in found or "start_end" in found
            if "model" in found and "color" in found and has_counts:
                header = {"row_number": row["row_number"], **found}
                headers.append(header)
                section_count += 1
                section_details.append(
                    {
                        "sheet": sheet["name"],
                        "header_row": int(row["row_number"]),
                    }
                )
        if not headers:
            continue

        for index, header in enumerate(headers):
            next_header = headers[index + 1]["row_number"] if index + 1 < len(headers) else None
            excluded = {
                column for key, column in header.items()
                if key != "row_number"
            }
            header["inferred_date"] = _infer_date_column(
                sheet["rows"], header["row_number"], next_header, excluded
            )

        current: dict[str, Any] | None = None
        header_position = 0
        header_rows = {header["row_number"] for header in headers}
        for row in sheet["rows"]:
            while header_position < len(headers) and headers[header_position]["row_number"] < row["row_number"]:
                current = headers[header_position]
                header_position += 1
            if current is None or row["row_number"] in header_rows:
                continue

            relevant_columns = {
                column for key, column in current.items()
                if key in {"model", "ram", "storage", "color", "start", "end", "start_end", "date", "inferred_date"}
                and isinstance(column, int)
            }
            if not any(clean_text(row["cells"].get(column)) for column in relevant_columns):
                continue

            candidate_rows += 1
            raw_model = clean_text(row["cells"].get(current["model"]))
            raw_color = clean_text(row["cells"].get(current["color"]))
            raw_start = clean_text(row["cells"].get(current.get("start", -1)))
            raw_end = clean_text(row["cells"].get(current.get("end", -1)))
            if "start_end" in current:
                combined_start, combined_end = _split_start_end(row["cells"].get(current["start_end"]))
                raw_start = raw_start or combined_start
                raw_end = raw_end or combined_end

            if not raw_model:
                skipped.append(
                    {
                        "sheet": sheet["name"],
                        "row": int(row["row_number"]),
                        "reason": "Missing Model / MAKE",
                    }
                )
                continue
            if not raw_color and not raw_start and not raw_end:
                skipped.append(
                    {
                        "sheet": sheet["name"],
                        "row": int(row["row_number"]),
                        "reason": "Model exists, but Color and START/END are blank",
                        "model": raw_model,
                    }
                )
                continue

            model, ram, storage = split_model_memory(
                raw_model,
                row["cells"].get(current.get("ram", -1)),
                row["cells"].get(current.get("storage", -1)),
            )
            excluded = {
                column for key, column in current.items()
                if key in {"model", "ram", "storage", "color", "start", "end", "start_end"}
                and isinstance(column, int)
            }
            counted = _effective_row_date(
                row, current.get("date"), current.get("inferred_date"), excluded
            )
            counted_value = counted["value"] if counted["valid"] else (
                "" if counted["display"] == "(not provided)" else counted["display"]
            )
            result.append(
                {
                    "model": model,
                    "ram": ram,
                    "storage": storage,
                    "color": raw_color,
                    "start": raw_start,
                    "end": raw_end,
                    "date_counted": counted_value,
                    "source_sheet": sheet["name"],
                    "source_row": int(row["row_number"]),
                }
            )

    if section_count == 0:
        raise InventoryError(
            "No worksheet contains Model or MAKE, Color, and START, END, or START/END headers on the same row."
        )
    if not result:
        raise InventoryError("Organizing headers were found, but no inventory rows could be extracted.")

    duplicate_map: dict[tuple[str, str, str, str], list[dict[str, Any]]] = {}
    for row in result:
        key = (
            str(row.get("model") or "").casefold(),
            str(row.get("ram") or "").casefold(),
            str(row.get("storage") or "").casefold(),
            str(row.get("color") or "").casefold(),
        )
        duplicate_map.setdefault(key, []).append(row)

    duplicate_groups: list[dict[str, Any]] = []
    for group in duplicate_map.values():
        if len(group) < 2:
            continue
        first = group[0]
        duplicate_groups.append(
            {
                "model": first["model"],
                "ram": first["ram"],
                "storage": first["storage"],
                "color": first["color"],
                "row_count": len(group),
                "source_rows": [f"{item['source_sheet']}!{item['source_row']}" for item in group[:20]],
            }
        )
    duplicate_groups.sort(key=lambda item: (-int(item["row_count"]), str(item["model"]).casefold()))

    date_counts: dict[str, int] = {}
    blank_date_rows = 0
    for row in result:
        value = row.get("date_counted")
        if not value:
            blank_date_rows += 1
            continue
        if hasattr(value, "strftime"):
            label = value.strftime("%m/%d/%Y")
        else:
            label = str(value)
        date_counts[label] = date_counts.get(label, 0) + 1

    report = {
        "worksheet_count": len(sheets),
        "section_count": section_count,
        "sections": section_details,
        "candidate_rows": candidate_rows,
        "extracted_rows": len(result),
        "skipped_rows": len(skipped),
        "skipped_examples": skipped[:50],
        "unique_variants": len(duplicate_map),
        "duplicate_rows": len(result) - len(duplicate_map),
        "duplicate_group_count": len(duplicate_groups),
        "duplicate_groups": duplicate_groups[:50],
        "non_memory_rows": sum(not row.get("ram") and not row.get("storage") for row in result),
        "dated_rows": len(result) - blank_date_rows,
        "blank_date_rows": blank_date_rows,
        "date_breakdown": [
            {"date": date, "rows": count}
            for date, count in sorted(date_counts.items(), key=lambda item: item[0])
        ],
    }
    return result, section_count, report


def extract_organized_rows(payload: bytes) -> tuple[list[dict[str, Any]], int]:
    """Read inventory-style sections without changing the uploaded workbook."""

    rows, section_count, _ = analyze_organized_rows(payload)
    return rows, section_count


def parse_reference_workbook(payload: bytes) -> tuple[list[dict[str, Any]], int]:
    result: list[dict[str, Any]] = []
    section_count = 0
    for sheet in read_xlsx_sheets(payload):
        headers: list[dict[str, Any]] = []
        for row in sheet["rows"]:
            found: dict[str, int] = {}
            for column, value in row["cells"].items():
                header = normalize_header(value)
                aliases = {"memory": "storage", "datecounted": "date"}
                header = aliases.get(header, header)
                if header in {"make", "model", "ram", "storage", "color", "start", "end"} and header not in found:
                    found[header] = column
                if header in {
                    "date", "lastupdated", "updated", "updateddate", "dateupdated",
                    "lastupdate", "updatedon", "lastupdateddate",
                } and "date" not in found:
                    found["date"] = column
            if ("make" in found or "model" in found) and "color" in found and ("start" in found or "end" in found):
                headers.append({"row_number": row["row_number"], **found})
                section_count += 1
        if not headers:
            continue

        for index, header in enumerate(headers):
            next_header = headers[index + 1]["row_number"] if index + 1 < len(headers) else None
            excluded = {
                column for key, column in header.items()
                if key != "row_number"
            }
            header["inferred_date"] = _infer_date_column(
                sheet["rows"], header["row_number"], next_header, excluded
            )

        current: dict[str, Any] | None = None
        header_position = 0
        header_rows = {header["row_number"] for header in headers}
        for row in sheet["rows"]:
            while header_position < len(headers) and headers[header_position]["row_number"] < row["row_number"]:
                current = headers[header_position]
                header_position += 1
            if current is None or row["row_number"] in header_rows:
                continue
            if "make" in current:
                make = clean_text(row["cells"].get(current["make"]))
            else:
                model = clean_text(row["cells"].get(current.get("model", -1)))
                ram = clean_text(row["cells"].get(current.get("ram", -1)))
                storage = clean_text(row["cells"].get(current.get("storage", -1)))
                make = count_make(model, ram, storage) if model else ""
            color = clean_text(row["cells"].get(current["color"]))
            start = clean_text(row["cells"].get(current.get("start", -1)))
            end = clean_text(row["cells"].get(current.get("end", -1)))
            if not make:
                continue
            if not color and not start and not end:
                continue
            excluded = {column for key, column in current.items() if key in {"make", "model", "ram", "storage", "color", "start", "end"}}
            updated = _effective_row_date(
                row, current.get("date"), current.get("inferred_date"), excluded
            )
            result.append(
                {
                    "reference_id": f"{sheet['name']}|{row['row_number']}",
                    "make": make,
                    "color": color,
                    "make_key": normalize_make_key(make),
                    "color_key": normalize_color_key(color),
                    "start_text": start,
                    "end_text": end,
                    "last_updated": updated["display"],
                    "last_updated_sort": updated["sort"],
                    "row_number": row["row_number"],
                }
            )
    if section_count == 0:
        raise InventoryError("No worksheet contains MAKE or Model, COLOR, and START or END headers on the same row.")
    if not result:
        raise InventoryError("Reference headers were found, but no valid item rows were found.")
    return result, section_count


def parse_count_workbook(payload: bytes) -> list[dict[str, Any]]:
    result: list[dict[str, Any]] = []
    found_header = False
    for sheet in read_xlsx_sheets(payload):
        mapping: dict[str, int] | None = None
        header_row = 0
        for row in sheet["rows"]:
            candidate: dict[str, int] = {}
            for column, value in row["cells"].items():
                header = normalize_header(value)
                aliases = {
                    "memory": "storage",
                    "quantity": "amount",
                    "qty": "amount",
                    "enteredat": "date",
                    "entrydate": "date",
                    "entrytime": "date",
                    "dateentered": "date",
                    "countedat": "date",
                }
                header = aliases.get(header, header)
                if header in {"model", "ram", "storage", "color", "amount", "area", "brokenbox", "date"}:
                    candidate[header] = column
            if {"model", "ram", "storage", "color", "amount"}.issubset(candidate):
                mapping = candidate
                header_row = row["row_number"]
                found_header = True
                break
        if mapping is None:
            continue
        for row in sheet["rows"]:
            if row["row_number"] <= header_row:
                continue
            model = clean_text(row["cells"].get(mapping["model"]))
            ram = clean_text(row["cells"].get(mapping["ram"]))
            storage = clean_text(row["cells"].get(mapping["storage"]))
            color = clean_text(row["cells"].get(mapping["color"]))
            if not model and not ram and not storage:
                continue
            context = f"{sheet['name']}, row {row['row_number']}"
            if not model:
                raise InventoryError(f"Model is required in {context}.")
            if not ram and not storage:
                ram = storage = "0"
            if not ram or not storage:
                raise InventoryError(f"RAM and Storage must both contain values in {context}.")
            if has_partial_zero_memory(ram, storage):
                raise InventoryError(f"RAM and Storage must both be zero for a non-memory item in {context}.")
            if not color:
                raise InventoryError(f"Color is required in {context}.")
            amount = parse_whole_number(row["cells"].get(mapping["amount"]), f"Amount in {context}")
            broken_text = normalize_header(row["cells"].get(mapping.get("brokenbox", -1)))
            broken = broken_text in {"true", "yes", "1", "brokenbox", "broken"}
            area = clean_text(row["cells"].get(mapping.get("area", -1))) or "Imported"
            date_data = _reference_date(row["cells"].get(mapping.get("date", -1)))
            counted_at = date_data["value"] or datetime.now()
            result.append(
                {
                    "id": "",
                    "model": model,
                    "ram": ram,
                    "storage": storage,
                    "color": color,
                    "items_per_box": 0,
                    "boxes": 0,
                    "loose_items": amount,
                    "amount": amount,
                    "area": area,
                    "broken_box": broken,
                    "counted_at": counted_at.replace(microsecond=0).isoformat(),
                }
            )
    if not found_header:
        raise InventoryError("The workbook needs Model, RAM, Storage, Color, and Amount headers.")
    if not result:
        raise InventoryError("The workbook contains the required headers but no inventory rows.")
    return result


def _excel_datetime(value: Any, target_timezone: Any = None) -> datetime | None:
    if value is None or value == "":
        return None
    if isinstance(value, datetime):
        result = value
    else:
        try:
            result = datetime.fromisoformat(str(value).replace("Z", "+00:00"))
        except ValueError:
            return None
    if result.tzinfo:
        result = (
            result.astimezone(target_timezone)
            if target_timezone is not None
            else result.astimezone()
        ).replace(tzinfo=None)
    return result


def _excel_serial(value: datetime) -> str:
    delta = value - datetime(1899, 12, 30)
    serial = delta.days + (delta.seconds + delta.microseconds / 1_000_000) / 86_400
    return format(serial, ".15g")


def _inline_cell(reference: str, value: Any, style: int = 2) -> str:
    text = "" if value is None else str(value)
    return f'<c r="{reference}" s="{style}" t="inlineStr"><is><t xml:space="preserve">{escape(text)}</t></is></c>'


def _number_cell(reference: str, value: Any, style: int = 3) -> str:
    if value is None or value == "":
        return f'<c r="{reference}" s="{style}"/>'
    return f'<c r="{reference}" s="{style}"><v>{int(value)}</v></c>'


def _number_or_text_cell(reference: str, value: Any) -> str:
    text = clean_text(value)
    if re.fullmatch(r"[+-]?\d+", text):
        return _number_cell(reference, int(text))
    if re.fullmatch(r"[+-]?\d+\.0+", text):
        return _number_cell(reference, int(float(text)))
    return _inline_cell(reference, text)


def _date_cell(reference: str, value: Any, style: int = 4) -> str:
    date_value = _excel_datetime(value)
    if date_value is None:
        # Preserve partial or unusual date labels (for example "11/13") as
        # text instead of silently turning them into blank cells.
        text_value = clean_text(value)
        if text_value:
            return _inline_cell(reference, text_value, 5)
        return f'<c r="{reference}" s="{style}"/>'
    return f'<c r="{reference}" s="{style}"><v>{_excel_serial(date_value)}</v></c>'


def _result_style(result: str) -> int:
    if result == "MATCH":
        return 6
    if result in {"MISSING ITEMS", "EXTRA ITEMS", "AMOUNT CHANGED"}:
        return 7
    if result in {"NOT IN REFERENCE", "MISSING FROM COUNT", "MISSING IN NEW"}:
        return 8
    if result in {"ATTRIBUTE CONFLICT", "INVALID REFERENCE"}:
        return 9
    if result == "NEW ITEM":
        return 10
    return 2


def _worksheet_xml(
    headers: list[str],
    rows: list[list[Any]],
    types: list[str],
    widths: list[float],
    status_column: int = -1,
) -> str:
    header_cells = "".join(
        _inline_cell(f"{_column_name(column)}1", header, 1) for column, header in enumerate(headers)
    )
    sheet_rows = [f'<row r="1" ht="24" customHeight="1">{header_cells}</row>']
    for row_index, row in enumerate(rows, 2):
        cells = []
        for column, header in enumerate(headers):
            reference = f"{_column_name(column)}{row_index}"
            value = row[column] if column < len(row) else ""
            cell_type = types[column]
            if cell_type == "number":
                cells.append(_number_cell(reference, value))
            elif cell_type == "number_or_text":
                cells.append(_number_or_text_cell(reference, value))
            elif cell_type == "date":
                cells.append(_date_cell(reference, value))
            else:
                style = _result_style(str(value)) if column == status_column else 2
                cells.append(_inline_cell(reference, value, style))
        sheet_rows.append(f'<row r="{row_index}" ht="20" customHeight="1">{"".join(cells)}</row>')
    last_row = max(1, len(rows) + 1)
    last_column = _column_name(len(headers) - 1)
    columns = "".join(
        f'<col min="{index + 1}" max="{index + 1}" width="{width}" customWidth="1"/>'
        for index, width in enumerate(widths)
    )
    return (
        '<?xml version="1.0" encoding="UTF-8" standalone="yes"?>'
        f'<worksheet xmlns="{MAIN_NS}">'
        f'<dimension ref="A1:{last_column}{last_row}"/>'
        '<sheetViews><sheetView showGridLines="0" workbookViewId="0">'
        '<pane ySplit="1" topLeftCell="A2" activePane="bottomLeft" state="frozen"/>'
        '</sheetView></sheetViews><sheetFormatPr defaultRowHeight="18"/>'
        f'<cols>{columns}</cols><sheetData>{"".join(sheet_rows)}</sheetData>'
        f'<autoFilter ref="A1:{last_column}{last_row}"/>'
        '<pageMargins left="0.7" right="0.7" top="0.75" bottom="0.75" header="0.3" footer="0.3"/>'
        '</worksheet>'
    )

def _package_workbook(sheets: list[dict[str, Any]], title: str) -> bytes:
    overrides = []
    workbook_sheets = []
    workbook_rels = []
    for index, sheet in enumerate(sheets, 1):
        overrides.append(
            f'<Override PartName="/xl/worksheets/sheet{index}.xml" '
            'ContentType="application/vnd.openxmlformats-officedocument.spreadsheetml.worksheet+xml"/>'
        )
        state = ' state="hidden"' if sheet["hidden"] else ""
        workbook_sheets.append(
            f'<sheet name={quoteattr(sheet["name"])} sheetId="{index}"{state} r:id="rId{index}"/>'
        )
        workbook_rels.append(
            f'<Relationship Id="rId{index}" '
            'Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/worksheet" '
            f'Target="worksheets/sheet{index}.xml"/>'
        )
    style_rel_id = len(sheets) + 1
    workbook_rels.append(
        f'<Relationship Id="rId{style_rel_id}" '
        'Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/styles" Target="styles.xml"/>'
    )
    content_types = (
        '<?xml version="1.0" encoding="UTF-8" standalone="yes"?>'

        '<Default Extension="rels" ContentType="application/vnd.openxmlformats-package.relationships+xml"/>'

def validate_xlsx_package(payload: bytes, expected_sheets: int) -> None:
    try:
        with zipfile.ZipFile(io.BytesIO(payload), "r") as archive:
            required = ["[Content_Types].xml", "_rels/.rels", "xl/workbook.xml", "xl/styles.xml"]
            required.extend(f"xl/worksheets/sheet{index}.xml" for index in range(1, expected_sheets + 1))
            for name in required:
                content = archive.read(name)
                if not content:
                    raise InventoryError(f"Workbook validation failed: {name} is empty.")
                ET.fromstring(content)
    except (zipfile.BadZipFile, KeyError, ET.ParseError) as exc:
        raise InventoryError("The generated Excel workbook failed package validation.") from exc

class DuplicateEntryError(InventoryError):

def _display_entry(entry: dict[str, Any]) -> dict[str, Any]:
    row = dict(entry)
    row["broken_box"] = bool(row.get("broken_box"))
    row["item_details"] = item_details(row)
    row["calculation"] = (
        f"{row['items_per_box']:,} × {row['boxes']:,} + {row['loose_items']:,}"
        if row["items_per_box"] or row["boxes"]
        else "Loose/imported count"
    )
    return row


def _state(database_path: Path) -> dict[str, Any]:
    with connect(database_path) as connection:
        session = current_session(connection)        raw_entries = session_entries(connection, session["id"])
        identity_counts: dict[str, int] = {}
        for row in raw_entries:
            key = comparison_key(row["model"], row["ram"], row["storage"], row["color"])
            identity_counts[key] = identity_counts.get(key, 0) + 1
        entries = []
        for row in raw_entries:
            displayed = _display_entry(row)
            key = comparison_key(row["model"], row["ram"], row["storage"], row["color"])
            displayed["match_key"] = key
            displayed["identity_count"] = identity_counts.get(key, 1)
            entries.append(displayed)
        reference = frozen_reference(connection, session["id"])
        comparisons = comparison_results(connection, session["id"])
        if reference and session["workflow_status"] == "COUNTING" and raw_entries:
            comparisons = compare_reference(
                raw_entries,
                load_frozen_reference(connection, session["id"]),
                include_missing_reference=False,
            )
        total = sum(int(row["amount"]) for row in entries)
        broken = sum(int(row["amount"]) for row in entries if row["broken_box"])
        latest_values = [
            value
            for value in (
                session.get("approved_at"), session.get("submitted_at"), session.get("reference_loaded_at"),
                session.get("finalized_at"), session.get("created_at"),
                *[row.get("updated_at") for row in raw_entries[:10]],
            )
            if value
        ]
        return {
            "session": session,
            "entries": entries,
            "comparisons": comparisons,
            "sessions": session_list(connection),
            "catalog": catalog_summary(connection),
            "last_workbook": last_workbook_summary(connection),
            "reference": reference,
            "attempts": list_attempts(connection, session["id"]),
            "movements": list_movements(connection),
            "last_saved_at": max(latest_values) if latest_values else session.get("created_at", ""),
            "summary": {
                "rows": len(entries),
                "total_amount": total,
                "broken_amount": broken,
                "matches": sum(row["result"] == "MATCH" for row in comparisons),
                "issues": sum(row["result"] != "MATCH" for row in comparisons),
            },
        }

class InventoryRequestHandler(BaseHTTPRequestHandler):
    server_version = "InventoryWebApp/1.6.3"

    @property
    def app_server(self) -> "InventoryHTTPServer":
        return self.server  # type: ignore[return-value]

    def log_message(self, format_string: str, *args: Any) -> None:
        message = f"[{self.log_date_time_string()}] {format_string % args}"
        sys.stdout.write(f"{message}\n")
        logging.getLogger("inventory.http").info(message)

    def _send_bytes(
        self,
        payload: bytes,
        content_type: str,
        status: int = HTTPStatus.OK,
        headers: dict[str, str] | None = None,
    ) -> None:
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(payload)))
        self.send_header("X-Content-Type-Options", "nosniff")
        self.send_header("Cache-Control", "no-store")
        self.send_header("Referrer-Policy", "same-origin")
        self.send_header("X-Frame-Options", "SAMEORIGIN")
        for key, value in (headers or {}).items():
            self.send_header(key, value)
        self.end_headers()
        if self.command != "HEAD":
            self.wfile.write(payload)

    def _send_json(self, data: Any, status: int = HTTPStatus.OK) -> None:
        payload = json.dumps(data, ensure_ascii=False, separators=(",", ":")).encode("utf-8")
        self._send_bytes(payload, "application/json; charset=utf-8", status)

    def _read_body(self, maximum: int) -> bytes:
        try:
            length = int(self.headers.get("Content-Length", "0"))
        except ValueError:
            raise InventoryError("Invalid request length.") from None
        if length <= 0:
            raise InventoryError("The request did not contain any data.")
        if length > maximum:
            raise InventoryError(f"The uploaded data exceeds the {maximum // (1024 * 1024)} MB limit.")
        return self.rfile.read(length)

    def _read_json(self) -> dict[str, Any]:
        try:
            data = json.loads(self._read_body(MAX_JSON_BYTES).decode("utf-8"))
        except (UnicodeDecodeError, json.JSONDecodeError) as exc:
            raise InventoryError("The request contains invalid JSON data.") from exc
        if not isinstance(data, dict):
            raise InventoryError("The request must contain a JSON object.")
        return data

    def _route_parts(self) -> list[str]:
        return [unquote(part) for part in urlparse(self.path).path.strip("/").split("/") if part]

    def do_OPTIONS(self) -> None:  # noqa: N802
        self.send_response(HTTPStatus.NO_CONTENT)
        self.send_header("Allow", "GET, HEAD, POST, PUT, DELETE, OPTIONS")
        self.end_headers()

    def do_HEAD(self) -> None:  # noqa: N802
        self.do_GET()

    def do_GET(self) -> None:  # noqa: N802
        try:
            path = urlparse(self.path).path
            if path == "/api/health":
                self._send_json({"status": "ok", "version": "1.6.3"})
                return
            if path == "/api/state":
                self._send_json(_state(self.app_server.database_path))
                return
            if path == "/api/catalog":
                query = str(parse_qs(urlparse(self.path).query).get("q", [""])[0])[:120]
                with connect(self.app_server.database_path) as connection:
                    items = search_catalog_items(connection, query)
                    summary = catalog_summary(connection)
                self._send_json({"items": items, "catalog": summary})
                return
            if path == "/api/reference/last":
                with connect(self.app_server.database_path) as connection:
                    summary = last_workbook_summary(connection)
                self._send_json({"workbook": summary})
                return
            if path == "/api/reference/last/download":
                with connect(self.app_server.database_path) as connection:
                    saved = load_last_workbook(connection)
                if not saved:
                    raise InventoryError("No previously validated workbook is saved yet.")
                safe_name = re.sub(r"[^A-Za-z0-9_-]+", "_", Path(saved["source_name"]).stem).strip("_") or "Reference"
                self._send_bytes(
                    bytes(saved["organized_payload"]),
                    "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
                    headers={"Content-Disposition": f'attachment; filename="{safe_name}_Organized.xlsx"'},
                )
                return
            if path == "/api/export":
                self._export_workbook()
                return
            if path == "/api/movements":
                with connect(self.app_server.database_path) as connection:
                    movements = list_movements(connection)
                self._send_json({"movements": movements})
                return
            self._serve_static(path)
        except Exception as exc:  # pragma: no branch - central HTTP boundary
            self._handle_error(exc)

    def do_POST(self) -> None:  # noqa: N802
        try:
            parts = self._route_parts()
            if parts == ["api", "entries"]:
                self._add_entry()
            elif parts == ["api", "sessions"]:
                self._new_session()
            elif len(parts) == 4 and parts[:2] == ["api", "sessions"] and parts[3] == "activate":
                self._activate_session(parts[2])
            elif len(parts) == 4 and parts[:2] == ["api", "sessions"] and parts[3] == "finalize":
                self._finalize_session(parts[2])
            elif len(parts) == 4 and parts[:2] == ["api", "sessions"] and parts[3] == "reference":
                self._freeze_reference(parts[2])
            elif len(parts) == 5 and parts[:2] == ["api", "sessions"] and parts[3:] == ["reference", "reuse"]:
                self._reuse_last_reference(parts[2])
            elif len(parts) == 4 and parts[:2] == ["api", "sessions"] and parts[3] == "submit":
                self._submit_cycle(parts[2])
            elif len(parts) == 4 and parts[:2] == ["api", "sessions"] and parts[3] == "review":
                self._review_cycle(parts[2])
            elif parts == ["api", "compare", "reference"]:
                self._run_reference_comparison()
            elif parts == ["api", "compare", "old"]:
                self._run_old_comparison()
            elif parts == ["api", "compare", "old-reference"]:
                self._run_old_reference_comparison()
            elif parts == ["api", "organize"]:
                self._organize_workbook_copy()
            elif parts == ["api", "organize", "preview"]:
                self._preview_organized_workbook()
            elif parts == ["api", "movements"]:
                self._add_movement()
            else:
                self._send_json({"error": "API route not found."}, HTTPStatus.NOT_FOUND)
        except Exception as exc:  # pragma: no branch - central HTTP boundary
            self._handle_error(exc)

    def do_PUT(self) -> None:  # noqa: N802
        try:
            parts = self._route_parts()
            if len(parts) == 3 and parts[:2] == ["api", "entries"]:
                self._update_entry(parts[2])
            else:
                self._send_json({"error": "API route not found."}, HTTPStatus.NOT_FOUND)
        except Exception as exc:
            self._handle_error(exc)

    def do_DELETE(self) -> None:  # noqa: N802
        try:
            parts = self._route_parts()
            if len(parts) == 3 and parts[:2] == ["api", "entries"]:
                self._delete_entry(parts[2])
            else:
                self._send_json({"error": "API route not found."}, HTTPStatus.NOT_FOUND)
        except Exception as exc:
            self._handle_error(exc)

    def _serve_static(self, request_path: str) -> None:
        file_name = "index.html" if request_path in {"", "/"} else request_path.lstrip("/")
        allowed = {"index.html", "styles.css", "app.js", "favicon.svg"}
        if file_name not in allowed:
            self._send_json({"error": "Page not found."}, HTTPStatus.NOT_FOUND)
            return
        path = STATIC_ROOT / file_name
        if not path.is_file():
            self._send_json({"error": "Static application file is missing."}, HTTPStatus.NOT_FOUND)
            return
        content_type = mimetypes.guess_type(path.name)[0] or "application/octet-stream"
        if content_type.startswith("text/") or content_type in {"application/javascript", "image/svg+xml"}:
            content_type += "; charset=utf-8"
        self._send_bytes(path.read_bytes(), content_type)

    def _duplicate_count(
        self,
        existing_rows: list[dict[str, Any]],
        entry: dict[str, Any],
        excluded_id: str = "",
    ) -> int:
        key = comparison_key(entry["model"], entry["ram"], entry["storage"], entry["color"])
        return sum(
            row["id"] != excluded_id
            and comparison_key(row["model"], row["ram"], row["storage"], row["color"]) == key
            for row in existing_rows
        )

    def _add_entry(self) -> None:
        payload = self._read_json()
        validated = validate_entry(payload)
        with connect(self.app_server.database_path) as connection:
            session = current_session(connection)
            require_draft(connection, session["id"])
            if session["workflow_status"] != "COUNTING":
                raise InventoryError("This cycle count is submitted. Approve it or start a recount before editing.")
            duplicate_count = self._duplicate_count(session_entries(connection, session["id"]), validated)
            if duplicate_count and not bool(payload.get("allow_duplicate")):
                raise DuplicateEntryError(duplicate_count)
            entry_id = str(uuid.uuid4())
            now = utc_now()
            connection.execute(
                """
                INSERT INTO entries
                (id, session_id, model, ram, storage, color, items_per_box, boxes, loose_items,
                amount, area, broken_box, counted_at, updated_at, operator_name, attempt)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
                """,
                (
                    entry_id, session["id"], validated["model"], validated["ram"], validated["storage"],
                    validated["color"], validated["items_per_box"], validated["boxes"],
                    validated["loose_items"], validated["amount"], validated["area"],
                    int(validated["broken_box"]), now, now, session["operator_name"],
                    int(session["recount_attempt"] or 1),
                ),
            )
            validated.update({"id": entry_id, "counted_at": now})
            add_audit(connection, session["id"], "ADD", entry_id, "", _entry_summary(validated))
            connection.execute("DELETE FROM comparison_results WHERE session_id = ?", (session["id"],))
        self._send_json({"ok": True, "entry_id": entry_id}, HTTPStatus.CREATED)

    def _update_entry(self, entry_id: str) -> None:
        payload = self._read_json()
        validated = validate_entry(payload)
        with connect(self.app_server.database_path) as connection:
            session = current_session(connection)
            require_draft(connection, session["id"])
            if session["workflow_status"] != "COUNTING":
                raise InventoryError("This cycle count is submitted. Approve it or start a recount before editing.")
            existing_row = connection.execute(
                "SELECT * FROM entries WHERE id = ? AND session_id = ?", (entry_id, session["id"])
            ).fetchone()
            if not existing_row:
                raise KeyError("Inventory entry not found in the active session.")
            existing = dict(existing_row)
            duplicate_count = self._duplicate_count(
                session_entries(connection, session["id"]), validated, excluded_id=entry_id
            )
            if duplicate_count and not bool(payload.get("allow_duplicate")):
                raise DuplicateEntryError(duplicate_count)
            connection.execute(
                """
                UPDATE entries SET model = ?, ram = ?, storage = ?, color = ?, items_per_box = ?,
                    boxes = ?, loose_items = ?, amount = ?, area = ?, broken_box = ?, updated_at = ?
                WHERE id = ? AND session_id = ?
                """,
                (
                    validated["model"], validated["ram"], validated["storage"], validated["color"],
                    validated["items_per_box"], validated["boxes"], validated["loose_items"],
                    validated["amount"], validated["area"], int(validated["broken_box"]),
                    utc_now(), entry_id, session["id"],
                ),
            )
            validated.update({"id": entry_id, "counted_at": existing["counted_at"]})
            add_audit(
                connection, session["id"], "EDIT", entry_id,
                _entry_summary(existing), _entry_summary(validated),
            )
            connection.execute("DELETE FROM comparison_results WHERE session_id = ?", (session["id"],))
        self._send_json({"ok": True})

    def _delete_entry(self, entry_id: str) -> None:
        with connect(self.app_server.database_path) as connection:
            session = current_session(connection)
            require_draft(connection, session["id"])
            if session["workflow_status"] != "COUNTING":

                "SELECT * FROM entries WHERE id = ? AND session_id = ?", (entry_id, session["id"])
            ).fetchone()
            if not row:
                raise KeyError("Inventory entry not found in the active session.")
            existing = dict(row)
            connection.execute("DELETE FROM entries WHERE id = ?", (entry_id,))
            add_audit(connection, session["id"], "REMOVE", entry_id, _entry_summary(existing), "")
            connection.execute("DELETE FROM comparison_results WHERE session_id = ?", (session["id"],))
        self._send_json({"ok": True})

    def _run_old_reference_comparison(self) -> None:
        payload = self._read_body((MAX_WORKBOOK_BYTES * 2) + 4)
        if len(payload) < 6:
            raise InventoryError("Select both an old count workbook and a reference workbook.")

        old_size = struct.unpack(">I", payload[:4])[0]
        reference_size = len(payload) - 4 - old_size
        if old_size <= 0 or old_size > MAX_WORKBOOK_BYTES:
            raise InventoryError("The old count workbook is missing or exceeds the 25 MB limit.")
        if reference_size <= 0 or reference_size > MAX_WORKBOOK_BYTES:
            raise InventoryError("The reference workbook is missing or exceeds the 25 MB limit.")

        old_payload = payload[4:4 + old_size]
        reference_payload = payload[4 + old_size:]
        old_entries = parse_count_workbook(old_payload)
        references, sections = parse_reference_workbook(reference_payload)

        with connect(self.app_server.database_path) as connection:
            session = current_session(connection)
            results = compare_reference(old_entries, references)
            replace_comparison_results(connection, session["id"], "OLD_REFERENCE", results)

        self._send_json(
            {
                "ok": True,
                "result_count": len(results),
                "old_rows": len(old_entries),
                "reference_rows": len(references),
                "sections": sections,
            }
        )

    def _handle_error(self, exc: Exception) -> None:
        if isinstance(exc, DuplicateEntryError):
            self._send_json(
                {"error": str(exc), "code": "DUPLICATE", "duplicate_count": exc.count},
                HTTPStatus.CONFLICT,
            )
        elif isinstance(exc, InventoryError):
            self._send_json({"error": str(exc)}, HTTPStatus.BAD_REQUEST)
        elif isinstance(exc, PermissionError):
            self._send_json({"error": str(exc)}, HTTPStatus.LOCKED)
        elif isinstance(exc, KeyError):
            self._send_json({"error": str(exc).strip("'\"")}, HTTPStatus.NOT_FOUND)
        elif isinstance(exc, ValueError):
            self._send_json({"error": str(exc)}, HTTPStatus.BAD_REQUEST)
        else:
            traceback.print_exc()
            self._send_json(
                {"error": "The application encountered an unexpected error. Check the server window for details."},
                HTTPStatus.INTERNAL_SERVER_ERROR,
            )


class InventoryHTTPServer(ThreadingHTTPServer):
    daemon_threads = True
    allow_reuse_address = True

    def __init__(self, address: tuple[str, int], database_path: Path):
        self.database_path = database_path
        super().__init__(address, InventoryRequestHandler)


def parse_arguments() -> argparse.Namespace:
    parser = argparse.ArgumentParser(description="Inventory Count Web App")
    parser.add_argument("--host", default="127.0.0.1", help="Local bind address")
    parser.add_argument("--port", type=int, default=8765, help="Local port")
    parser.add_argument("--data", type=Path, default=DEFAULT_DATABASE, help="SQLite database path")
    parser.add_argument("--open", action="store_true", help="Open the app in the default browser")
    return parser.parse_args()


def main() -> int:
    args = parse_arguments()
    database_path = args.data.expanduser().resolve()
    init_database(database_path)
    log_path = database_path.parent / DEFAULT_LOG.name
    logging.basicConfig(
        filename=log_path,
        level=logging.INFO,
        format="%(asctime)s %(levelname)s %(message)s",
    )
    try:
        server = InventoryHTTPServer((args.host, args.port), database_path)
    except OSError as exc:
        print(f"Could not start the Inventory Web App on port {args.port}: {exc}", file=sys.stderr)
        return 1
    url = f"http://{args.host}:{server.server_address[1]}/"
    print("Inventory Count Web App")
    print(f"Open: {url}")
    print(f"Database: {database_path}")
    print("Press Ctrl+C to stop the app.")
    if args.open:
        threading.Timer(0.8, lambda: webbrowser.open(url)).start()
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print("\nStopping Inventory Count Web App...")
    finally:
        server.server_close()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

function escapeHtml(value) {
  return String(value ?? "")
    .replaceAll("&", "&amp;")
    .replaceAll("<", "&lt;")
    .replaceAll(">", "&gt;")
    .replaceAll('"', "&quot;")
    .replaceAll("'", "&#039;");
}

function formatNumber(value) {
  if (value === null || value === undefined || value === "") return "—";
  return numberFormat.format(Number(value));
}

function formatDifference(value) {
  if (value === null || value === undefined || value === "") return "—";
  const number = Number(value);
  return number > 0 ? `+${numberFormat.format(number)}` : numberFormat.format(number);
}

function formatDate(value, includeTime = true) {
  if (!value) return "—";
  const date = new Date(value);
  if (Number.isNaN(date.getTime())) return value;
  const options = { year: "numeric", month: "short", day: "numeric" };
  if (includeTime) Object.assign(options, { hour: "numeric", minute: "2-digit" });
  return new Intl.DateTimeFormat(undefined, options).format(date);
}

function formatEntryTimestamp(value) {
  if (!value) return "—";
  const date = new Date(value);
  if (Number.isNaN(date.getTime())) return value;
  const time = new Intl.DateTimeFormat("en-US", {
    hour: "numeric",
    minute: "2-digit",
    hour12: true,
  }).format(date);
  const day = new Intl.DateTimeFormat("en-US", {
    month: "2-digit",
    day: "2-digit",
    year: "numeric",
  }).format(date);
  return `${time} · ${day}`;
}

function savedLabel(value) {
  if (!value) return "✓ Saved automatically";
  const date = new Date(value);
  if (Number.isNaN(date.getTime())) return "✓ Saved automatically";
  return `✓ Saved automatically · ${new Intl.DateTimeFormat(undefined, { hour: "numeric", minute: "2-digit" }).format(date)}`;
}

function restoreFormDraft() {
  const key = draftKey();
  if (!key || appState.restoredDraftFor === key) return;
  appState.restoredDraftFor = key;
  try {
    const payload = JSON.parse(localStorage.getItem(key) || "null");
    if (!payload?.entry) return;
    const fields = {
      model: "#model", ram: "#ram", storage: "#storage", color: "#color",
      items_per_box: "#itemsPerBox", boxes: "#boxes", loose_items: "#looseItems", area: "#area",
    };
    Object.entries(fields).forEach(([name, selector]) => {
      if (payload.entry[name] !== undefined && payload.entry[name] !== null) $(selector).value = payload.entry[name];
    });
    $("#brokenBox").checked = Boolean(payload.entry.broken_box);
    if (payload.entrySearch) $("#entrySearch").value = payload.entrySearch;
    appState.issueOnly = Boolean(payload.issuesOnly);
    if ($("#issuesOnly")) $("#issuesOnly").checked = appState.issueOnly;
    if (payload.panel && document.getElementById(payload.panel)) showPanel(payload.panel, false);
    calculateAmount();
    renderEntries();
    renderComparisons();
    const hasDraft = [payload.entry.model, payload.entry.color, payload.entry.ram, payload.entry.storage].some(Boolean) ||

    }
  } catch (_) {
    localStorage.removeItem(key);
  }
}

async function request(url, options = {}) {
  const response = await fetch(url, options);
  const contentType = response.headers.get("content-type") || "";
  const payload = contentType.includes("application/json") ? await response.json() : null;
  if (!response.ok) {
    const error = new Error(payload?.error || `Request failed with status ${response.status}.`);
    error.status = response.status;
    error.payload = payload;
    throw error;
  }
  return payload;
}

function updateExpectedUnitSummary() {
  const current = $("#currentCountValue");
  const difference = $("#liveDifferenceValue");
  if (!current || !difference) return;

  const perBox = Math.max(0, Number.parseInt($("#itemsPerBox").value || "0", 10) || 0);
  const boxes = Math.max(0, Number.parseInt($("#boxes").value || "0", 10) || 0);
  const loose = Math.max(0, Number.parseInt($("#looseItems").value || "0", 10) || 0);
  const counted = (perBox * boxes) + loose;
  current.textContent = formatNumber(counted);

  const expected = appState.selectedCatalogItem?.reference_quantity;
  if (expected === null || expected === undefined || expected === "") {
    difference.textContent = "—";
    difference.className = "";
    return;
  }

  const delta = counted - Number(expected);
  difference.textContent = formatDifference(delta);
  difference.className = delta === 0 ? "difference-match" : delta < 0 ? "difference-under" : "difference-over";
}

async function loadModelSuggestions(query) {
  if (appState.catalogRequest) appState.catalogRequest.abort();
  appState.catalogRequest = new AbortController();
  try {
    const result = await request(`/api/catalog?q=${encodeURIComponent(query)}`, {
      signal: appState.catalogRequest.signal,
    });
    if ($("#model").value.trim() !== query) return;
    renderModelSuggestions(result.items || []);
  } catch (error) {
    if (error.name !== "AbortError") hideModelSuggestions();
  }
}

async function saveEntry(allowDuplicate = false) {
  const payload = { ...entryPayload(), allow_duplicate: allowDuplicate };
  const editing = Boolean(appState.editingId);
  const url = editing ? `/api/entries/${encodeURIComponent(appState.editingId)}` : "/api/entries";
  try {
    setBusy(true, editing ? "Saving changes…" : "Adding count…");
    await request(url, {
      method: editing ? "PUT" : "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });
    resetEntryForm(!editing);
    await loadState();
    clearFormDraft();
    focusCountEntry();
    $("#model").focus();
    toast(editing ? "Entry updated" : "Count added", "Your database was saved automatically.", "success");
  } catch (error) {
    if (error.status === 409 && error.payload?.code === "DUPLICATE" && !allowDuplicate) {
      setBusy(false);
      if (window.confirm(`${error.message}\n\nAdd this as another count row?`)) {
        return saveEntry(true);
      }
      return;
    }
    toast("Could not save the entry", error.message, "error");
  } finally {
    setBusy(false);
  }
}

async function deleteEntry(entryId) {
  const entry = appState.data.entries.find((row) => row.id === entryId);
  if (!entry || !window.confirm(`Remove this count row?\n\n${entry.item_details} | ${entry.color} | ${formatNumber(entry.amount)}`)) return;
  try {
    setBusy(true, "Removing count…");
    await request(`/api/entries/${encodeURIComponent(entryId)}`, { method: "DELETE" });
    if (appState.editingId === entryId) resetEntryForm(false);
    await loadState();
    toast("Count removed", "The session database has been updated.", "success");
  } catch (error) {
    toast("Could not remove the entry", error.message, "error");
  } finally {
    setBusy(false);
  }
}

function resultClass(result) {
  if (result === "MATCH") return "match";
  if (["MISSING ITEMS", "EXTRA ITEMS", "AMOUNT CHANGED"].includes(result)) return "warning";
  if (["ATTRIBUTE CONFLICT", "INVALID REFERENCE"].includes(result)) return "conflict";
  if (result === "NEW ITEM") return "info";
  return "error";
}

async function runComparison() {
  const mode = $("#comparisonMode").value;
  if (!appState.comparisonFile) {
    toast("Select an Excel workbook", "Choose the comparison source before continuing.", "error");
    return;
  }
  if (mode === "old-reference" && !appState.referenceFile) {
    toast("Select a reference workbook", "Old Count vs Reference Sheet requires both workbooks.", "error");
    return;
  }
  if (mode !== "old-reference" && !appState.data.entries.length) {
    toast("No current inventory", "Add at least one count before comparing.", "error");
    return;
  }
  try {
    setBusy(true, "Reading and comparing workbook…");
    let body = appState.comparisonFile;
    let contentType = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet";
    if (mode === "old-reference") {
      const [oldBuffer, referenceBuffer] = await Promise.all([
        appState.comparisonFile.arrayBuffer(),
        appState.referenceFile.arrayBuffer(),
      ]);
      const payload = new Uint8Array(4 + oldBuffer.byteLength + referenceBuffer.byteLength);
      new DataView(payload.buffer).setUint32(0, oldBuffer.byteLength, false);
      payload.set(new Uint8Array(oldBuffer), 4);
      payload.set(new Uint8Array(referenceBuffer), 4 + oldBuffer.byteLength);
      body = payload;
      contentType = "application/vnd.inventory.old-reference";
    }
    const result = await request(`/api/compare/${mode}`, {
      method: "POST",
      headers: { "Content-Type": contentType },
      body,
    });
    await loadState();
    toast("Comparison complete", `${formatNumber(result.result_count)} product identities were reviewed.`, "success");
  } catch (error) {
    toast("Comparison failed", error.message, "error");
  } finally {
    setBusy(false);
  }
}

function copyIssues() {

  const text = issues.map((row) =>

    .then(() => toast("Issue list copied", `${issues.length} issue${issues.length === 1 ? "" : "s"} copied to the clipboard.`, "success"))

}

        </div>
        ${skippedDetails ? `<details><summary>Rows needing attention</summary><ul class="import-detail-list">${skippedDetails}</ul></details>` : ""}
        ${duplicateDetails ? `<details><summary>Duplicate product identities (${formatNumber(preview.duplicate_group_count)})</summary><ul class="import-detail-list">${duplicateDetails}</ul></details>` : ""}
        ${dateDetails ? `<small><strong>Date Counted:</strong> ${dateDetails}${dates.length > 8 ? " · …" : ""}</small>` : '<small>No count date detected in imported rows.</small>'}
      </div>`;
    setBusy(false);
    if (!window.confirm(`Workbook validation complete.\n\nSource rows found: ${preview.candidate_rows}\nRows that will be imported: ${preview.extracted_rows}\nRows skipped: ${preview.skipped_rows}\nUnique variants: ${preview.unique_variants}\nDuplicate source rows: ${preview.duplicate_rows}\n\nCreate the organized copy and load the autocomplete catalog?`)) return;
    setBusy(true, "Creating the organized copy…");
    const response = await fetch(`/api/organize?name=${encodeURIComponent(sourceFile.name)}`, {
      method: "POST",
      headers: { "Content-Type": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" },
      body: sourceFile,
    });
    if (!response.ok) {
      const contentType = response.headers.get("content-type") || "";
      const payload = contentType.includes("application/json") ? await response.json() : null;
      throw new Error(payload?.error || `Request failed with status ${response.status}.`);
    }
    const workbook = await response.blob();
    const disposition = response.headers.get("content-disposition") || "";
    const matchedName = disposition.match(/filename="?([^";]+)"?/i)?.[1];
    const fallbackStem = sourceFile.name.replace(/\.(?:xlsx|xlsm)$/i, "") || "Inventory";
    const downloadName = matchedName || `${fallbackStem}_Organized.xlsx`;
    const downloadUrl = URL.createObjectURL(workbook);
    const link = document.createElement("a");
    link.href = downloadUrl;
    link.download = downloadName;
    document.body.appendChild(link);
    link.click();
    link.remove();
    window.setTimeout(() => URL.revokeObjectURL(downloadUrl), 1000);
    const rowCount = Number(response.headers.get("x-organized-rows") || 0);
    const variantCount = Number(response.headers.get("x-catalog-variants") || 0);
    await loadState();
    toast(
      "Organized copy and autocomplete ready",
      `${formatNumber(rowCount)} row${rowCount === 1 ? "" : "s"} extracted and ${formatNumber(variantCount)} unique product variant${variantCount === 1 ? "" : "s"} loaded. The original workbook was not changed.`,
      "success",
    );
  } catch (error) {
    toast("Could not organize the workbook", error.message, "error");
  } finally {
    setBusy(false);
  }
}

  }
  try {
    setBusy(true, "Validating and freezing reference…");
    const response = await fetch(`/api/sessions/${encodeURIComponent(session.id)}/reference?name=${encodeURIComponent(file.name)}`, {
      method: "POST",
      headers: { "Content-Type": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" },
      body: file,
    });
    if (!response.ok) {
      const payload = (response.headers.get("content-type") || "").includes("application/json") ? await response.json() : null;
      throw new Error(payload?.error || `Request failed with status ${response.status}.`);
    }
    const workbook = await response.blob();
    const name = (response.headers.get("content-disposition") || "").match(/filename="?([^";]+)"?/i)?.[1] || "Reference_Organized.xlsx";
    const url = URL.createObjectURL(workbook);
    const link = document.createElement("a");

    link.download = name;

    link.click();

async function reviewCycle(action) {

  const reason = $("#reviewReason").value.trim();

    return;
  }
  if (!window.confirm(action === "APPROVE" ? "Approve this submitted count?" : "Start a new recount attempt? The prior attempt remains in history.")) return;
  try {
    setBusy(true, action === "APPROVE" ? "Recording approval…" : "Opening recount…");
    await request(`/api/sessions/${encodeURIComponent(appState.data.session.id)}/review`, {

function handleEntryKeyboard(event) {
  if (event.key !== "Enter" || event.shiftKey || event.ctrlKey || event.altKey || event.metaKey) return;
  const order = ["model", "ram", "storage", "color", "itemsPerBox", "boxes", "looseItems", "area"];
  const current = order.indexOf(event.target.id);
  if (current < 0) return;
  if (event.target.id === "model" && !$("#modelSuggestions").classList.contains("hidden") && appState.catalogMatches.length) {
    event.preventDefault();
    selectCatalogVariant(appState.catalogActiveIndex >= 0 ? appState.catalogActiveIndex : 0);
    return;
  }
  event.preventDefault();
  if (current === order.length - 1) {
    $("#entryForm").requestSubmit();
    return;
  }
  document.getElementById(order[current + 1]).focus();
  document.getElementById(order[current + 1]).select?.();
}

class IdentityRuleTests(unittest.TestCase):
    def test_non_memory_item_omits_zero_zero(self):
        entry = sample_entry(model="Cable", ram="0", storage="0", color="White")
        self.assertEqual(count_make("Cable", "0", "0"), "Cable")
        self.assertEqual(item_details(entry), "Cable")
        self.assertEqual(comparison_key("Cable", "0", "0", "White"), "CABLE|WHITE")

    def test_broken_box_is_displayed_but_not_part_of_identity(self):
        normal = sample_entry()
        broken = sample_entry(id="entry-2", broken_box=True, amount=2, area="Shelf B")
        self.assertIn("Broken Box", item_details(broken))
        self.assertEqual(
            comparison_key(normal["model"], normal["ram"], normal["storage"], normal["color"]),
            comparison_key(broken["model"], broken["ram"], broken["storage"], broken["color"]),
        )
        group = group_entries([normal, broken])[0]
        self.assertEqual(group["amount"], 25)
        self.assertEqual(group["broken_amount"], 2)
        self.assertEqual(group["source_rows"], 2)

    def test_partial_zero_is_rejected(self):
        with self.assertRaises(InventoryError):
            validate_entry(
                {
                    "model": "Phone", "ram": "0", "storage": "256 GB", "color": "Black",
                    "items_per_box": 1, "boxes": 1, "loose_items": 0, "area": "A",
                }
            )

    def test_amount_formula(self):
        result = validate_entry(
            {
                "model": "Phone", "ram": "8 GB", "storage": "256 GB", "color": "black",
                "items_per_box": 10, "boxes": 4, "loose_items": 3, "area": "A",
            }
        )
        self.assertEqual(result["amount"], 43)        self.assertEqual(result["color"], "Black")

    def test_organizer_splits_combined_memory_and_omits_zero_zero(self):
        self.assertEqual(
            split_model_memory("Phone X 8+256"),
            ("Phone X", "8 GB", "256 GB"),
        )
        self.assertEqual(split_model_memory("Cable 0+0"), ("Cable", "", ""))
        self.assertEqual(
            split_model_memory("Tablet Z", "12 GB", "512 GB"),
            ("Tablet Z", "12 GB", "512 GB"),
        )

    def test_recount_keeps_prior_attempt_and_opens_empty_current_attempt(self):

        thread = threading.Thread(target=server.serve_forever, daemon=True)
        thread.start()
        base = f"http://127.0.0.1:{server.server_address[1]}"

        def post_json(path, payload):
            request = urllib.request.Request(
                f"{base}{path}", data=json.dumps(payload).encode(), method="POST",
                headers={"Content-Type": "application/json"},
            )
            with urllib.request.urlopen(request) as response:
                return json.load(response)

        try:
            created = post_json("/api/sessions", {"name": "Recount Test"})["session"]
            reference_request = urllib.request.Request(
                f"{base}/api/sessions/{created['id']}/reference?name=Reference.xlsx",
                data=reference_workbook_bytes(), method="POST",
                headers={"Content-Type": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"},
            )
            with urllib.request.urlopen(reference_request) as response:
                response.read()
            entry = {
                "model": "Phone X", "ram": "8 GB", "storage": "256 GB", "color": "Black",
                "items_per_box": 10, "boxes": 2, "loose_items": 0, "area": "Bin 4",
            }
            post_json("/api/entries", entry)
            self.assertEqual(
                post_json(f"/api/sessions/{created['id']}/submit", {})["workflow_status"],
                "RECOUNT_REQUIRED",
            )
            post_json(
                f"/api/sessions/{created['id']}/review",
                {"action": "RECOUNT", "reviewer": "Supervisor A", "reason": "Physical verification required"},
            )
            with urllib.request.urlopen(f"{base}/api/state") as response:
                recount_state = json.load(response)
            self.assertEqual(recount_state["session"]["recount_attempt"], 2)
            self.assertEqual(recount_state["entries"], [])
            self.assertEqual(recount_state["attempts"][0]["decision"], "RECOUNT")

            entry["loose_items"] = 3
            post_json("/api/entries", entry)
            second = post_json(f"/api/sessions/{created['id']}/submit", {})
            self.assertEqual(second["workflow_status"], "APPROVED")
            with connect(self.database) as connection:
                attempts = connection.execute(
                    "SELECT attempt, status FROM cycle_count_attempts WHERE session_id = ? ORDER BY attempt",
                    (created["id"],),
                ).fetchall()
                captured_rows = connection.execute(
                    "SELECT attempt, amount FROM entries WHERE session_id = ? ORDER BY attempt",
                    (created["id"],),
                ).fetchall()
            self.assertEqual([(row["attempt"], row["status"]) for row in attempts], [(1, "RECOUNT_REQUIRED"), (2, "APPROVED")])
            self.assertEqual([(row["attempt"], row["amount"]) for row in captured_rows], [(1, 20), (2, 23)])
        finally:
            server.shutdown()
            server.server_close()
            thread.join(timeout=2)
